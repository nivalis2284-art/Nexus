# 网页搜索与阅读

为 Nexus Agent 提供网页搜索、公开网页阅读和 GitHub 公开仓库目录及源码读取。安装 ZIP 后在插件管理中加载；首次加载会创建插件独立 Python 环境并从 Python 包源安装依赖，需要联网。

默认使用免密钥 DDGS 搜索；在插件设置选择 Tavily 后，可免密钥使用或填写自己的 Tavily API Key。设置保存后后续调用立即生效。搜索词会发送给所选服务及其上游搜索引擎；免费搜索可能受网络、地区、上游限制或页面变化影响。Tavily 免密钥模式有服务商限额。

宿主当前以明文显示插件设置，并将 API Key 明文保存在本地插件设置文件中；请只在可信设备使用。插件不会把 Key 作为模型工具参数或返回结果展示。

网页阅读支持公开 HTTP(S) 文本、HTML、JSON 和 XML，网页链接会随正文返回；长页面可分段读取。GitHub 工具支持公开仓库的目录和文本文件及指定分支、标签或提交。此插件不登录账号、不操作浏览器，也不支持需要 JavaScript 渲染才能出现的内容；这类任务交给独立浏览器控制插件。公开 GitHub API 有访问限制。

网页和搜索结果来自外部，可能不准确；Agent 应核实来源并在回答中给出链接。插件拒绝读取本机和内网地址。

本插件通过依赖使用 DDGS、Beautiful Soup、HTTPX 和 MCP Python SDK，分别遵循其各自开源许可；本插件代码采用 MIT 许可。
