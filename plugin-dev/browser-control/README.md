# 浏览器控制

让 Agent 在可见的 Microsoft Edge 窗口中打开网页、检查页面、点击、输入、切换标签页和截图。用户可以直接在浏览器中接管操作、登录或完成验证。网页搜索与阅读由独立的“网页搜索与阅读”插件提供。

首次启用时 Nexus 会安装 Playwright 等 Python 依赖，需要网络连接。插件使用电脑上已安装的 Microsoft Edge，无需另行下载浏览器。浏览器数据保存在插件数据目录，各会话或任务使用独立的浏览器资料；截图保存在 Nexus 根目录的 `Cache/screenshots/`。

Agent 可使用 `browser_control` 操作、`browser_screenshot` 查看当前标签页。页面元素引用来自最近一次 snapshot，页面发生变化后应重新 snapshot。关闭插件会关闭其浏览器进程。用户也可以随时手动关闭浏览器。

浏览器操作可能改变网站数据，敏感操作应先征得用户同意；插件无法从任意网页控件可靠识别所有会产生外部影响的操作。截图需要支持图片的模型，并在模型配置中启用多模态。
