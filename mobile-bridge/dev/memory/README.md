# 记忆插件 0.1.0

为 Nexus 所有者的唯一主交流提供主题级记忆。仅使用公共插件接口，不修改宿主。安装包的制作不会安装或启用插件。

## 安装与首次配置

由所有者自行在 Nexus 插件管理导入 ZIP 并加载，打开「记忆管理」。首次加载读取现有记录建立基线，不提炼已有历史；只采集之后新增内容。停用期间的新增内容在重载时补采。

分别配置 OpenAI 兼容提炼服务和嵌入服务的 API 地址、模型、密钥。地址通常以 `/v1` 结束，也可填写完整的 `/chat/completions` 或 `/embeddings` 路径。密钥留空不变，勾选清除才移除。密钥保存在插件数据目录的独立 `credentials.json`，不会通过设置读取返回。

确认本地 IANA 时区，例如 `Asia/Shanghai`。未确认时区不执行每天定时；事件时间按配置时区解释。未配置模型可先采集，提炼等待配置。真实云端调用只会在用户加载插件并配置后发生。

首次加载准备独立 Python 环境，安装 `sqlite-vec` 和 `tzdata`，不向宿主安装依赖。要求 Python 3.12、公共主交流接口 v1、插件独立服务及页面支持。Windows 上的原生扩展兼容性须在实际机器确认。

## 三层流程

1. **采集与提炼**：压缩检查点保存后采集其覆盖的原始消息；也支持定时、手动采集。快照先入库，同一模型首轮按主题选择片段，程序逐字提取，第二轮提炼粒子，再由程序校验、提交。
2. **保存与管理**：SQLite 分开保存来源账本、临时快照、粒子、原文和嵌入索引。完成提交才清理快照；原文与主交流独立。粒子编辑后标记人工修订，保持 ID 和原文不变。
3. **召回**：新增用户输入触发被动语义检索，结果只进入本次模型请求；主动工具先检索粒子，需要时展开原文。主动展开的原文会进入主交流上下文，不提供独立回忆 Agent。

压缩采用**成功后**采集：当前 Nexus 保存检查点后仍保留底层原文，不需要压缩前钩子。压缩失败由其他采集入口覆盖。插件不读取隐藏推理或协议续接字段，只捕获完整文字、工具调用和结果及附件元数据；不复制附件二进制、不执行 OCR。

### 粒度

按完整主题保存值得未来使用的压缩结论，合并重复讨论，优先最终决定、有效约束及必要理由。保留对象、条件、否定、时间与不确定性；不逐句改写、不强制每次生成粒子。过程细节保存在原文。模型选文仍可能遗漏或误读，应通过手动搜索、编辑纠错和展开检查。

### 去重与恢复

优先用 `ling_input_id`、`message_id`、`tool_call_id` 和必要父消息标识建立来源身份，并结合内容指纹登记唯一版本。登记与快照保存同事务。相同正文的不同来源不合并。无原生标识的旧式记录通过完整记录指纹及重复次序辅助匹配，不能保证所有删除／重排场景下绝对无歧义。

批次分为待整理、待提炼、处理中、失败、完成。首轮选择结果持久保存，失败可从页面重试；已完成批次不重复提交。过大的单条消息或工具交换不会截断，保留并提示调整批次上限。关闭服务时未完成作业下次继续；失败作业需要手动重试。

### 原文与删除

原文库仅保留粒子实际绑定的材料单元，包括选择的背景；多个粒子可共用片段。快照清除后不能找回未选中材料。删除主交流不删除记忆；但采集之前已删除的内容无法恢复。

编辑正文不会改原文，原文只能解释最初来源，不能自动证明人工修订后的说法。删除粒子不连带清理原文，页面提供确认后清理无引用原文。新旧冲突记忆不自动覆盖或合并。后续提炼不会修改现有人工修订粒子。

## 页面与工具

页面默认语义搜索，可切换精确词句搜索；空查询浏览粒子并分页。搜索结果支持直接编辑正文和事件时间、删除、展开原文。保存失败保留草稿。正文编辑后旧向量立即移除，重新嵌入期间仍可精确搜索。需要时可补建失败向量或重建全部索引。

主 Agent 获得只读工具：

- `memory_search(query, mode="semantic", limit=5)`：语义或精确检索。
- `memory_get(particle_id)`：按 ID 读取。
- `memory_expand(particle_id)`：读取关联原文。

工具通过公共只读工具适配器调用本地 MCP 服务，避免把检索误判成写操作。MCP 服务本身也声明同名工具；`memory_admin` 仅用于插件桥接，不向模型暴露。

被动注入缓存以用户输入和记忆版本为依据，避免每个工具步骤重复检索。失败会显示缺失说明，不冒充没有记忆。语义相似不代表事实真实或当前有效。第一版不处理后台工作、多人或项目隔离。

## 默认配置

- 压缩采集开启，间隔采集 60 分钟；也可选每天指定时间或关闭。
- 新快照到达后后台处理；也可选每天、间隔处理或关闭。
- 批次输入上限 24,000 字符；按照完整消息／工具交换分批。
- 被动注入开启，最多 5 条，格式化后总计不超过 3,000 字符。
- 余弦相似度门槛 0.5，可调整；并非适用于所有模型的质量保证。
- 启动补采一次，错过的定时任务不逐次重放。

## 标准粒子 v1

字段：`schema_version`、`id`、`content`、`kind`、`role`、`source`、`provenance`、`event_time`、`expandable`、`created_at`、`updated_at`、`manually_edited`。

- `kind`：`dialogue` / `tool_result` / `document`。
- `role`：`user_statement` / `assistant_statement` / `tool_output` / `reported_statement`。
- `source`：可读 `label`、实际 `plugin_id` 和 `tool_name`；未知为 null，不编造。
- `provenance`：长期原文的 `source_id`、`segment_ids`、来源表达时间 `occurred_at`。
- `event_time`：事件的大致 `{start,end}` 范围，格式 `YYYY-MM-DDTHH:MM`，按配置时区解释；未知或不适用为 null。来源表达时间不是事件发生时间。
- 身份、来源关联和管理时间由程序生成；来源角色按主要原文类型确定。

`memory.sqlite3` 位于 `<NEXUS_HOME>/plugins/memory/`。向量是可重建索引，保存模型标识、维度和正文版本。更换嵌入模型需重建，不能混用不同模型向量；嵌入失败不阻止粒子入库或快照清理。

## 验证与交付边界

使用临时数据、模拟提供商和真实 stdio MCP 验证；不安装或启用日常 Nexus。自动化不能证明实际提炼质量。未调用真实云端模型，未进行 Windows 实机验证；相似度门槛及提炼提示词需结合所选模型小样本确认。
