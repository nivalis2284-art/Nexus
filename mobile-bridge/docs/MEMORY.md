## 使用

由所有者自行从 Nexus 的插件管理导入 ZIP、加载并打开「记忆管理」。加载时准备独立环境，安装 sqlite-vec 与 tzdata；宿主 Python 环境不增加依赖。

首次启用将已有主交流登记为基线，不提炼历史；只处理之后新增的完整消息。分别设置 OpenAI 兼容提炼和嵌入服务的地址、模型及密钥，并确认本地时区。可用“立即采集”“立即处理”检查新内容。

支持压缩后采集、间隔或每天定时采集；处理计划独立。后台用同一模型两轮完成主题级提炼，程序提取原文并事务绑定保存。粒子、长期原文及本地向量索引保存在插件自己的 memory.sqlite3 中。

页面默认语义检索，可切换精确检索。搜索结果可编辑正文与事件时间，修订保持 ID 和原文引用，旧向量立即失效并安排重新生成。保存失败保留草稿。支持原文展开、粒子删除及确认后清理无引用原文。

主交流可使用 memory_search、memory_get、memory_expand。被动注入只进入临时请求上下文，不向聊天历史追加召回结果。主动展开的原文会进入主交流。

删除主交流上下文不会删除已形成记忆及保留原文。清除处理完成的快照后，未选中的材料不再由记忆库保留。未采集就被删除的内容不能恢复。第一版不包含附件二进制提取、后台工作记忆、多人接入或记忆团。
