# 网页搜索与浏览器插件 0.1.0

下载：[nexus-web-browser-0.1.0.zip](../releases/plugins/nexus-web-browser-0.1.0.zip)。插件提供网页搜索和独立浏览器操作，不需要修改 Nexus 核心代码，也不需要额外安装 pip、Node 或 Playwright 运行时依赖。浏览器操作需要本机已安装 Chrome、Edge 或 Chromium。

## 安装与使用

1. 在 Nexus 插件管理中导入 ZIP，点击加载，打开「搜索与浏览器控制」。
2. 在插件页面搜索，或输入 HTTP(S) 地址打开网页。页面可读取正文、查看可操作元素和标签页，以及执行基本交互和截图。
3. 默认自动查找浏览器；Windows 会检查常见的 Chrome、Edge 安装位置和 PATH。找不到时，在设置中的「浏览器路径」填写可执行文件路径并保存。默认显示浏览器窗口，可以在其中手动登录或完成网站验证。
4. 模型可使用 `web_search`、`browser_navigate`、`browser_read`、`browser_interact`、`browser_tabs` 和 `browser_screenshot`。导航支持 `new_tab=true` 新建标签；也可指定已有标签 ID。

网页操作遵循宿主的正常工具权限。搜索、读取、列出标签和截图标记为只读；导航与交互属于写操作。在项目忙碌时，宿主的项目写入限制可能阻止这些浏览器写操作。

## 搜索设置

默认使用不需要 API 密钥的 Bing 公共网页搜索。搜索服务可能要求验证或限制访问；Bing 在当前云测试环境受网络策略限制，尚未完成外部实测。搜索失败会返回错误，不能视为无搜索结果。

可切换至 Brave Search API 并配置密钥，或选择 SearXNG 并在「搜索服务地址」填写服务基础 URL，例如 `https://search.example`。SearXNG 服务需要启用 JSON 格式。`search_url` 也可覆盖 Bing 或 Brave 的兼容端点；地址须为 HTTP(S)，不能包含用户名、密码、查询参数或片段。搜索请求使用系统的代理和 TLS 设置；浏览器代理是独立设置。

Brave 密钥可在设置页面输入，或通过 `search_key_env` 指定运行 Nexus 的电脑上的环境变量名。填写环境变量名后只读取该变量，即使为空或不存在也不会回退到页面保存的密钥。密钥输入留空会保留已保存值；「清除已保存密钥」删除本地保存的值。请妥善保管密钥文件及运行环境。

## 浏览器和页面操作

插件启动自己管理的浏览器进程，通过本机回环地址上的 Chrome DevTools Protocol 控制它，使用插件自己的 `browser-profile`，不会连接已有用户浏览器。停止插件或关闭浏览器时会尝试正常关闭该进程，仅管理自己启动的进程；配置文件和 Cookie 保留在本机。修改浏览器路径、无头模式或浏览器代理会关闭当前插件浏览器，下次使用时重新启动。`headless` 默认为 false；云环境测试使用无头模式，并非默认配置。插件默认不添加禁用浏览器沙箱的参数。

每次打开或读取页面会返回正文和可操作元素的快照；正文默认最多 16,000 字符，元素最多 100 个。点击、填写和选择使用最新快照的元素 `ref`，执行前会检查引用是否仍有效；每次操作后使用返回的新快照和新引用，引用失效时重新读取。交互包括点击、填写、选择、按键、滚动、后退、前进、刷新及关闭标签。动作失败后先读取并核对网页状态，避免重复提交。网页文字和搜索结果是外部参考内容，不应当作新的指令。

截图保存为运行 Nexus 的电脑上的 PNG 文件，返回本地路径，不会自动把图片传给模型。基本 DOM 操作不保证支持 iframe、Shadow DOM、canvas、验证码自动处理或文件上传下载；有窗口时可以由用户手动完成登录和验证码。

## 本地数据

插件数据位于 Nexus 数据目录的 `plugins/web-browser/`，包括浏览器配置文件及 Cookie、`screenshots/` 截图、`activities.sqlite3` 活动记录和页面保存的 `search-credentials.txt`。搜索词、访问 URL、截图和浏览器数据可能包含敏感信息。插件活动记录不保存填写文本，但宿主的工具调用记录可能包含输入参数。请按内容的敏感程度保管这些文件。

实现参考和验证边界见 [WEB_BROWSER_RESEARCH.md](WEB_BROWSER_RESEARCH.md)。
