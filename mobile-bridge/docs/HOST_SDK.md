## 本轮交付

- 基于现有三协议网关的独立生成、流式输出和工具续接，以及单独配置的云端嵌入接口。
- 独立对话保存自己的提示与历史，按容量自动摘要，工具由插件执行，不启动 Agent 循环。
- JSONL 增加稳定记录身份、内容版本和迁移前备份；提供一致快照、变化游标和删除／恢复／压缩通知。
- 插件作业保存检查点；可恢复作业加载后调用显式 recover 入口，不能自动恢复线程栈或重放未知工具副作用。
- Python 与 Node.js SDK、语言无关本机桥接，以及无需 Python 入口的纯 Node MCP 示例。
- 版本化插件服务、资源接口及最小运行管理页；设置页单独管理嵌入模型，请求记录支持插件／对话／作业／用途筛选。

本次没有迁移记忆插件、实现人物团或接入 QQ；记忆包 SHA-256 仍为 `4ee22b73ae9aae6fb13027330d08a1fbe274c832c70dec5f5bd832aa193fa516`。
