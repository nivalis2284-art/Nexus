# 0.1.0 验证记录

## 实测通过

验证宿主提交：`b73ff103a1bbc53f978487d859cfe9bbde411a87`。

### 第三方安装与端到端通信

从该提交导出未修改的宿主测试副本，使用独立数据目录、本地模拟模型服务和真实 HTTP/SSE：

- 从发布 ZIP 导入手机插件及 SDK 示例，经宿主插件管理加载成功。
- SDK 示例通过公开插件入口调用本机主交流 HTTP 接口，能读取实际主交流标识和运行状态。
- 未配对访问被拒绝；错误配对码被拒绝；有效码可用一次；解除配对后旧凭据失效。
- 手机协议提交文字后，主交流接收成功；复用同一请求编号重试没有重复执行，只发生一次模型请求。
- 实际收到了四段 SSE 正文输出，最终组成 `你好，手机。`，并在后续快照中读到完整持久记录。
- 重新获取快照时主交流标识保留。
- 停用插件后宿主完成资源清理。

这些操作没有读取 Nexus 私有管理器或全局运行状态，没有修改宿主实现。

### 插件与 SDK 针对性测试

10 项 Python 检查通过：插件配对、鉴权、保存、转发、流式及停止行为，以及 SDK 本机地址/路由限制与请求参数契约。包括停用时主动中断上游阻塞读取的测试。

### 安卓构建与逻辑

- 原生 Java 界面，最低 Android 8.0/API26、目标 API35。
- 使用 Google 官方 Android 平台与构建工具；下载按官方仓库清单校验。
- 编译、资源链接、DEX 打包成功，APK 对齐与 v2/v3 签名校验通过。
- 五项 JVM 消息投影检查通过：流式与已保存检查点合并、原始记录不变、完成记录显示、仅思考状态、空状态。
- 代码复查修复了跨连接代次刷新丢失、配对/发送期间 Activity 生命周期交接等问题。生命周期修复尚待真机操作复测。

## 未验证

- 安卓手机实际安装、布局、软键盘、滚动、锁屏/旋转、Wi-Fi 切换和 Windows 防火墙下的实际局域网互通。
- 真实外部模型服务：集成测试使用本地模拟提供商，验证的是接口、流式传输与持久化。
- 宿主后续版本兼容性；本版适配的是现有主交流 HTTP 契约，并非官方承诺稳定的远程 API。

云端没有 Android 模拟器/KVM，不将 APK 构建通过或 JVM 检查通过称为真机验收。首版发布用于真机试用；发现设备侧问题应以复现情况继续修正。

## 第三方开发结论

现有插件系统可以完成本次局域网手机聊天接入。手机消息沿用宿主主交流处理逻辑，回复沿用宿主实时流和记录；没有新增第二套模型执行器或聊天数据库。宿主 facade 缺少专门的主交流输入/实时订阅方法，通过公开本机 HTTP 接口完成适配，升级时需重验。
