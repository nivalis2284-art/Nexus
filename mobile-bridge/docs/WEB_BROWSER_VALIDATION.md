# 网页搜索与浏览器插件验证记录

验证日期：2026-10-28。插件：`web-browser` 0.1.0。使用说明见 [WEB_BROWSER.md](WEB_BROWSER.md)。

## 针对性验证

29 项测试覆盖搜索适配、模型工具接口、活动记录、配置与凭据，以及实际 Chromium 操作；Python 静态检查和页面 JavaScript 语法检查通过。

- 搜索：本地 HTTP 服务验证 Bing HTML、Brave、SearXNG 的请求参数与结果解析，覆盖链接解码、去重、广告排除、验证页面、合法空结果、错误响应、凭据不随重定向转发、大小和超时限制。包含“搜索 CAPTCHA 主题不应被误判为验证页面”的回归。
- 浏览器：实际 Chromium 验证导航、文本填写、选择、点击、Backspace、Enter 提交表单、后退、延迟导航、新标签、关闭最后标签后重新打开、截图、Cookie 持久化和进程退出。
- 快照：验证密码和隐藏输入值不出现在返回数据中，文本输入值可用于核对；旧引用和已移除元素会失败，滚动后可访问长页面后部的控件。
- 后端：验证工具注册及只读标记、作用域记录、失败不重放、活动日志写入失败时的处理、设置立即返回新值、密钥权限与环境变量优先级、停止后列标签不重新启动浏览器、重启时标记中断操作。

## 未修改 Nexus 上的完整闭环

从提交 `f5c5347488783a3677146012aa14ab78139c5e01` 的 `git archive` 创建宿主副本，通过 Nexus 插件管理 API 导入发布 ZIP、加载并配置。本次实现没有修改宿主代码。

本地模拟模型通过 Nexus 正常工具调用路径依次完成：`web_search` → `browser_navigate` → 填写姓名 Ada → 点击提交 → `browser_screenshot`，共 5 次工具调用、6 次模型请求。网页由实际 Chromium 打开和操作，逐步检查真实页面状态，并验证最终 PNG 文件签名。

另验证停用、加载及宿主重启后设置和活动记录保留，插件加载和状态查询不启动浏览器，也不自动重放此前的操作。

## 管理页面验收

实际 Chromium 通过：设置保存及刷新后持久化、未保存草稿保留、搜索、从结果打开、读取元素、填写、点击、截图、标签列表和关闭浏览器。页面 JavaScript 异常为 0；关闭后再次刷新状态不会重新启动专用浏览器。截图已在工作区检查。

## 边界

测试使用本地搜索服务、网站及模拟模型，没有证明公网搜索服务或任意网站均可用。当前云网络策略未允许 Bing，因此未实测 Bing 公网搜索；外部 Brave、SearXNG、真实模型选择工具的效果、Windows／macOS 实机及长期运行均未验收。

浏览器测试在 Linux 容器中使用已安装的 Chromium 和测试专用启动脚本；该脚本的容器参数不进入发布插件。用户运行不需要测试脚本、Node、Playwright 或额外 pip 包，需要本机浏览器。插件不自动处理验证码，不提供完整 iframe、Shadow DOM、canvas、文件上传下载或视觉模型浏览能力。

发布包只含插件程序、页面与说明；测试、依赖环境、浏览器运行资料、截图和凭据留在暂存目录。未运行宿主全量回归。
