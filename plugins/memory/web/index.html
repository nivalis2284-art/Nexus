长期记忆

这里管理灵用来回忆过去的记忆库。先确认连接和当前状态，再导入或构建记忆；平时可以搜索事件与记忆团，查看召回记录并给出反馈。

从灵导入资料

导入会先保存灵的一份会话；构建会再把它整理成事件和记忆团。会话编号留空时，使用当前灵会话。导入完成后需要执行构建，构建运行期间页面每 2 秒查询状态。

构建会整理当前已导入的资料；资料较多时可能需要等待。
