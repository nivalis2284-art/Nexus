Nexus 手机接入

手机和电脑连接同一局域网，继续同一段「灵」的交流。

1 · 连接电脑

读取连接信息…

在安卓 APP 的连接设置中输入电脑的局域网地址。若没有自动显示，请使用 Windows 的 ipconfig 查看 Wi-Fi / 以太网 IPv4 地址。允许 Windows 防火墙在专用网络接收此端口。

2 · 配对手机

配对码五分钟内有效，成功使用后失效。仅在你信任的局域网内配对。

监听设置

0.0.0.0 表示监听电脑所有 IPv4 网卡。保存后，在插件管理中重新加载插件生效。

第一版支持文字消息、实时回复和重新连接恢复。审批操作仍在电脑端完成。HTTP 传输适用于可信局域网，请勿做公网端口映射。
