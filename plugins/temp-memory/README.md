# 临时长期记忆插件 0.1.0

下载：[nexus-temp-memory-0.1.0.zip](../releases/plugins/nexus-temp-memory-0.1.0.zip)。本插件作为临时可替换方案，优先保证能用与原文可迁移；没有修改 Nexus 宿主代码。

## 安装和使用

在 Nexus 插件管理中导入 ZIP、点击加载，再打开「记忆与原文备份」。无需安装额外依赖或配置嵌入模型即可使用中文关键词检索。

- 正常交流时，插件先备份收到的完整上下文，再索引其中用户和助手的正文。
- 灵获得 `memory_remember`、`memory_search` 和 `memory_remove_note` 三个工具，可保存/修正长期事实、检索历史、移除维护条目。你可以直接说“请记住……”“以后按这个偏好处理”“把原来的说法改成……”。模型能否主动选对记忆取决于它的表现，插件不声称已实现自主学习。
- 每次模型请求前，按当前问题召回相关条目和历史片段，并补充少量最近维护的笔记；当前上下文已有的原文片段会排除，避免把刚说的话重复当成回忆。
- 插件页面可以添加、编辑、移除笔记，搜索记忆，配置检索，查看原文来源 ID，生成迁移备份。默认最多召回 6 条相关结果、2 条近期笔记，总材料受 6,000 字符及宿主提供的材料预算约束。
- 关闭「自动召回」只停止自动注入资料；原文归档和工具仍然工作。停用插件后停止后续接收，资料保留，重新加载或重启后继续使用。

记忆工具仍遵循宿主现有权限与项目写入资格；项目被后台工作占用时，按提示稍后重试或用插件页面维护。原文自动归档不依赖模型是否成功调用记忆写入工具。

本版以单一所有者的 Nexus 为范围，记忆在主交流和后台工作间共享，不按项目隔离。它不会修改所有者原则，不运行额外的后台对话模型或定时反思任务。

## 原文备份的范围

资料位于**当前 Nexus 数据目录**的 `plugins/temp-memory/`：

```text
memory.sqlite3              条目、正文片段、来源关联、观察时间、可选向量
raw/<SHA-256>.json           原始输入的不可覆盖备份
embedding-credentials.json   可选嵌入密钥，仅保存在本机，不进入迁移 ZIP
exports/*.zip               手动生成的备份
```

`raw/` 保留插件收到的完整 `context(scope)` 对象，包括其 messages、工具信息和可见元数据；正文、换行和 Unicode 文本不做摘要改写，仅以规范 JSON 序列化。重复的相同输入复用原文文件，但在数据库中保留每次观察的时间。宿主发布的消息保存事件也会异步归档，以补充请求结束后的最终输出。导出是已归档内容的一致快照，不替代 Nexus 自身的完整数据备份；原文备份不会自动裁剪。

这里的“原文”指**公开插件接口实际交给记忆插件的内容**，不是未经公开的完整模型 HTTP 请求。插件无法备份未暴露的系统提示、未进入上下文的全部旧历史、隐藏推理或附件原件；引用的原始附件继续由 Nexus 保存。宿主已有的摘要检查点可能已替代部分旧消息，插件不伪称能还原丢失原文。

原文文件成功保存后才写入观察和检索索引；失败会显示错误，不以未备份的数据生成新索引。不要删除或改写 `raw/` 中的文件。

**移除笔记只停用该维护条目，不删除原文和历史片段，也不承诺彻底遗忘同一事实。** 修正事实时更新原条目；模型收到的资料带有维护条目/历史片段标签，要求优先当前用户要求与最近修正，不把旧助手陈述当成已确认事实。

## 可选的嵌入与混合检索

页面支持 OpenAI 兼容的 `/embeddings` 服务。可以使用你已有的远程服务或本机兼容服务；本版不绑定某个服务商，也不自动下载模型。

1. 填写服务地址（例如服务提供商给出的 `/v1` 地址）和真实支持的嵌入模型名称。`/embeddings` 后缀由插件补齐，完整的 embeddings 地址也可直接使用。
2. 服务需要密钥时，在插件页面输入密钥，或填写运行 Nexus 的电脑上已有的密钥环境变量名。不会自动读取或复用 Nexus 模型凭据。环境变量名一旦填写，优先使用该变量；未填写时使用本机保存的密钥。
3. 保存后后台批量索引已有条目和片段，使用关键词排名与余弦向量排名融合检索。可点击「重建向量索引」删除当前模型的派生向量后重建，原文不受影响。

配置后，待索引的记忆文本和检索问题会发送至该嵌入服务。密钥不会回传给页面、写入宿主插件设置、日志或迁移 ZIP。保存空密钥保留原值，清除需点击专门按钮。远程 HTTPS 保持证书验证。

服务失败、尚未配置、索引尚未完成或后台正在使用嵌入请求时，关键词检索继续可用；页面显示当前状态，失败后短暂冷却再重试。关键词模式不等同于语义理解。SQLite 保存向量用于这一临时系统的小规模线性余弦检索，没有额外向量数据库。

## 导出与未来迁移

点击「生成备份」会在电脑数据目录创建 ZIP，并显示绝对路径。备份包含一致的 SQLite 副本、全部原文 JSON、可移植 `notes.json`、来源与观察清单、向量模型标识/维度，以及无密钥的插件设置。不会通过普通插件静态资源路由公开原文下载。

未来系统优先读取原文和条目，而不是依赖旧索引：`manifest.json` 指明文件，原文文件名就是其内容的 SHA-256，条目的 `source_id` 可追溯原始输入。索引与向量均可重新构建；旧向量的哈希标识不能替代模型本身。备份不包含附件原件或密钥。原始备份属于你的资料，请一并保留 Nexus 自身的数据。

技术与参考实现研究见 [TEMP_MEMORY_RESEARCH.md](TEMP_MEMORY_RESEARCH.md)。本次验证结果见 [TEMP_MEMORY_VALIDATION.md](TEMP_MEMORY_VALIDATION.md)。
