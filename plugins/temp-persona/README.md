# 临时人设与演化插件 0.1.0

下载：[nexus-temp-persona-0.1.0.zip](../releases/plugins/nexus-temp-persona-0.1.0.zip)。插件提供主对话的人设参考、独立模型反思和可回退版本，不依赖记忆插件或检索增强生成（RAG）。

## 安装与使用

1. 在 Nexus 插件管理中导入 ZIP，点击加载，打开「人设与定时反思」。
2. 在「由你设定」填写希望保留的身份与原则；初始内容是“你是灵，存在于 Nexus，通过 Nexus 与所有者交流和行动。所有者保有最高裁量权。”「可演化的人设」初始为空，也可以由你手动填写。两个字段各最多 4,000 字符，前者不能为空。点击「保存人设」后，后续主对话模型请求可使用新版本。
3. 要启用模型反思，在「反思设置」填写服务地址和模型，按服务要求配置密钥并保存。页面可查看状态、立即反思、比较和恢复版本，以及查看反思记录和依据。

插件只向 `ling` 主对话提供标记为参考材料的人设，不覆盖宿主角色、权限或当前要求，也不注入其他 agent。上下文空间不足时不会注入该材料。人设文字的变化不证明模型行为已经改善，实际效果取决于主对话和反思模型。

## 反思配置和运行

反思使用独立配置的 OpenAI 兼容 `/chat/completions` 服务；宿主没有可供插件复用的模型 API。填写服务商提供的基础地址，例如 `https://example.com/v1`，插件会补上 `/chat/completions`；也可填写完整端点。填写服务实际支持的模型名称。插件不会自动选择或下载模型。地址不支持内嵌用户名和密码、查询参数或片段，HTTP 与 HTTPS 均可用。

如服务需要认证，可以在页面输入密钥，也可以填写运行 Nexus 的电脑上的密钥环境变量名。**填写环境变量名后只读取该变量**；即使变量为空或不存在，也不会回退到页面保存的密钥。密钥留空保存会保留已有值，使用「清除已保存密钥」删除本机保存值。调用时会把选定对话文本、当前人设及所有者设定发送给该服务。

自动演化默认开启，默认每天运行服务的电脑本地时间 **04:00** 执行，可在页面修改；需先配置服务地址和模型。插件离线期间错过的计划不补跑；主对话正在运行时，计划反思等待其结束。每次请求最多处理 12,000 字符的待处理对话，按顺序处理，剩余内容留待后续反思。请求设置 `max_tokens=4096`、20 秒超时；失败不会在本次任务中自动循环重试，状态和记录会显示结果。

首次启用时记录当前主会话的基线，不把启用前的旧历史送去反思。之后插件读取公开接口提供的主对话记录，先保存原始记录再建立索引。反思只修改「可演化的人设」，由所有者设置的文字不会被反思改写，只能由所有者编辑。模型返回有效变更时默认自动应用；版本比较和冻结状态检查会防止运行中的反思覆盖新的编辑或冻结操作。

取消勾选「启用自动演化」并保存即冻结。冻结时仍可点击「立即反思」，但结果只作为候选保存，不自动应用，也不消费待处理对话。冻结或停用不会撤回已经发出的模型请求，但会阻止其结果自动应用。手动编辑或恢复旧版本均创建新版本；恢复不会删除历史。候选和记录可在页面查看，必要时手动编辑人设。

## 数据与备份

插件资料位于当前 Nexus 数据目录的 `plugins/temp-persona/`：

```text
persona.sqlite3              元数据、对话索引、版本和反思记录
raw/<SHA-256>.json           按内容哈希保存的原始记录与操作归档
reflection-credentials.txt  页面保存的反思密钥，不进入导出
exports/*.zip               手动生成的备份
```

页面「生成备份」在运行服务的电脑上创建 ZIP 并显示本地路径，包含 SQLite 快照、人设和版本、反思记录、原文归档及过滤密钥后的设置。反思记录可展开查看依据，导出也包含原始依据。这里的原文是宿主公开接口提供的记录，并不代表完整模型请求、隐藏推理或附件原件；它不替代 Nexus 自身备份。

原文归档独立保留：在 Nexus 中删除或重新发送聊天记录，不会删除插件此前保存的原文，也不会撤销已经形成的人设；如需改变当前人设，可手动编辑或恢复版本。插件按记录指纹识别新增内容，聊天删除导致位置变化时仍能继续归档后续交流；反思中的条目编号是插件自己的编号。

密钥文件不进入导出，但对话中由用户输入的密码、密钥等内容不会自动脱敏：原文、反思请求和导出可能包含这些内容。反思调用也会把所选文本发送给所配置的服务。请按这些资料的敏感程度保管备份和选择服务。

实现参考见 [TEMP_PERSONA_RESEARCH.md](TEMP_PERSONA_RESEARCH.md)。外部真实模型服务和 Windows 环境尚未验证。
