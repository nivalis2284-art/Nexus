# Nexus · 灵 · 独立前端预览

从 `H:/下载/redesign/` 的视觉稿接力，覆盖当前 `nexus/web/` 的页面、窗口、功能模块与配置项。**不连接后端、不写正式前端**；所有数据在浏览器内模拟。

## 打开

- 双击 `start-preview.bat`，浏览器访问 <http://127.0.0.1:8777/>。
- 或在仓库根目录执行：

  ```powershell
  .venv\Scripts\python.exe -m http.server 8777 --bind 127.0.0.1 --directory nexus-preview
  ```

- 直接双击 `index.html` 也可以：全部是本地静态资源，没有模块加载或跨域请求。

## 主题与动效

### 主题色

两套主题，每套由「主色 + 强调色」两色组成，均提供浅色与深色两套：

| 主题 | 主色 | 强调色 | 关系 |
| --- | --- | --- | --- |
| 灵青 · 朱砂 | 灵青 | 朱砂 | 暖色互补（约 156°） |
| 浅蓝 · 淡紫 | 浅蓝 | 淡紫 | 冷色邻近（约 35°，靠明度差拉开） |

配色原则：暖色套用互补色制造冷暖对比；冷色套用邻近色保持安静，再用明度差让强调色仍能分辨。强调色只用于待决定、提醒与朱印，避免互相抢眼。浅色下文字色满足 4.5:1 左右对比，深色下改用亮色主色 + 深色 `--on-primary` / `--on-accent`，彩色面上的文字不靠猜。冷色套同时替换纸、墨、灵岛为冷色中性，不只是换强调色。

### 动效速度

- 快 ×0.72 / 适中 ×1 / 慢 ×1.35，统一作用于页面切换、消息入场、灵岛形变、折叠区、弹窗、流式节奏与悬停反馈。
- 弹簧曲线本身不变，只缩放时长；减少动效时仍全部降级。

### 动效细节

- 形变由阻尼谐振子生成的 `linear()` 弹簧曲线驱动；减少动效时全部降级。
- 流式文字逐片段追加，光标跟字尾；结束时交叉淡入完整 Markdown。
- 消息列表增量渲染，只在末尾追加节点；阶段内的新步骤就地插入。
- 新回复的 Markdown 块逐段浮现；发送键有波纹，后台回报到达时左侧短暂留一道墨线；空态光球缓慢浮动。
- 请求栏显隐用 FLIP 让交流区滑移；页面切换为旧页退场、新页逐组件登场。
- 上下文页单独编排：标题下落、概览浮入、量表分段生长与百分比递增、页签墨迹滑动、指令行/角色卡/组装段依次入场。
- 折叠区、弹窗、菜单、文件预览都有真实的进出场；灵岛保留宽度/高度形变与液滴飞入。

## 数据与重置

- 消息、工作、请求、设置、上下文、技能、主题色与动效速度保存在 `localStorage` 的 `nexus-preview-v1`。
- 右上角预览控制的「重置预览数据」会清除本地状态并刷新。
- 插件功能页使用本地 `srcdoc` 演示页，不读取真实插件文件。

## 文件

- `index.html`：页面骨架、图标、对话框。
- `css/ling.css`：从上传原稿继承的视觉与弹簧基础。
- `css/app.css`：新页面、窗口、状态与动效修订。
- `css/theme.css`：两套主题、明暗覆盖、动效速度与界面设置样式。
- `js/core.js`：工具函数、弹簧、演示数据、Markdown、持久化。
- `js/shell.js`：导航、灵岛、请求栏、场景、主题。
- `js/chat.js` / `work.js` / `context.js` / `skills.js` / `plugins.js` / `settings.js` / `dialogs.js`：各功能面。
- `vendor/`：项目已有的 marked、DOMPurify、highlight.js。
- `assets/`：IBM Plex Sans 与 Noto Sans SC 子集。

## 检查

需要本机 Chrome 与已启动的 8777 服务：

```powershell
node check.cjs       # 主流程、页面、对话框、夜间、手机截图
node behavior.cjs    # 发送/停止/审批/附件/插件选择/重发撤销
node motion.cjs      # 页面交叉淡入、折叠高度、弹窗退场、灵岛残留
node mobile.cjs      # 移动端溢出与减少动效
node themecheck.cjs  # 主题切换、明暗、速度倍率与持久化
```

截图输出到仓库根目录 `.artifacts/nexus-preview/`。

## 边界

本轮只做前端样式与交互预览：不调用模型、不执行工具、不安装插件、不读写正式 Nexus 数据。真实执行结果、请求记录与插件页面均为演示状态；正式前端 `nexus/web/` 未改动。
