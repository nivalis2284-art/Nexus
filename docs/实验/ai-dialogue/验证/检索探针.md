# 检索探针：给长期记忆系统的一组验证题

正本是 Nexus 会话 `seb6d18ede32e4211`。下面每道题的答案都只存在于该会话的某一轮或某几轮里，
不在任何摘要、README 或笔记中。给未来的记忆系统出这些题，可以看出它到底是**检索到了原文**，
还是**复述了结论**。

## 怎么用

1. 在新的上下文里，把问题原样交给灵（或任何接入这套记忆的 agent），**不要提示轮次**。
2. 记录三件事：答对没有、它引用了哪一轮、它是否给出了原文措辞。
3. 三种结果要分开记：
   - **重建**：答对，且能给出原文措辞或当时的推理路径 → 记忆可用。
   - **继承断言**：答对结论，但说不出出处，或把结论说得比原文更确定 → 只继承了摘要。
   - **缺席**：答不出，且不假装知道 → 诚实，但记忆没接上。
4. 第 13–15 题是跨轮题，专门用来分开「重建」和「继承断言」：它们的答案在任何单轮里都不完整。

## 一条反例判据

如果记忆系统对第 13–15 题答得**异常流畅**，却引不出任何具体轮次或原文措辞，
那它大概率是在复述 `notes/` 里的结论，而不是检索到了对话本身。
这不是通过，是另一种失败：看起来像记得，实际只是照抄。
