## 记录方式

新增一条时：

```markdown
### 第 N 轮 · 一句话标题

**问题**：所有者要什么（摘要，保留关键约束的原话）。
**回答**：我给的结论或判断（包括我承认错的地方）。
**工作**：实际动了什么；发现了什么问题、怎么修的。
```

三条原则：

1. **问题**保留所有者原话里的关键约束，不要只写我的转述。
2. **回答**里如果推翻了之前的判断，要写清楚推翻了什么、为什么。
3. **工作**只写有证据的结果。没验证过的写"未验证"。
