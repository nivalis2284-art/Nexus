# 预览与迁移

## 独立性与来源

制作基准为 `b62b7b1`。`来源清单.json` 保存正式资源路径与来源检查点，独立副本与原文件保持可追溯关系。正式前端不会通过引用读取本目录；本目录不会通过 `../../nexus/web` 读取正式资源。

渲染脚本、样式和动效以快照复制保留现状。三个有意变化：core关闭偏好持久化、pivot关闭在线字体补充、插件展示请求改为本地 `N.previewFetch`。未包含正式 `api.js`、SSE和正式boot启动逻辑；`启动.js` 只初始化预览场景。页面脚本仍保留现有客户端展示校验和事件处理，不代表复刻后端业务状态机。

## 模拟交互约定

| 动作 | 演示结果 | 不执行的真实操作 |
|---|---|---|
| 发送 | 乐观气泡、思考、工具样本、定时回复 | 不调用模型或工具 |
| 停止 | 停止样本计时，保留当前文字 | 不控制后台进程 |
| 连续补充 | 展示排队提示 | 不模拟完整任务调度器 |
| 编辑／删除／撤销 | 修改／还原内存样本 | 不写会话数据库 |
| 指令／角色／摘要保存 | 更新内存文字 | 不改提示词文件 |
| 工作推进／审批 | 改变演示状态或移除对应请求 | 不执行命令、写文件或启动任务 |
| 设置与模型配置 | 修改样本，展示校验和反馈 | 不保存密钥、不连接服务 |
| 插件启停／导入／设置 | 修改显示状态、提示或样本字段 | 不加载程序、不解压ZIP、不调用第三方服务 |
| 文件夹选择 | 返回明确标注的虚构目录 | 不打开系统目录选择器 |
| 附件／图片 | 浏览器读取选中文件、预览 | 不上传；场景重置释放预览URL |
| 运行状态／介绍／功能页 | 返回内置样本或本地iframe | 不访问真实插件 |
| 下次操作失败 | 延迟后报演示错误，保留输入，可重试 | 不制造真实网络故障 |

样本状态保存在内存，刷新重置。场景选择重新建立数据，清理定时演示、打开的弹窗及临时附件URL。主题和速度在切场景时保留，但刷新恢复星枢黑夜／标准速度。背景动画持续，不因切场景重新创建中枢。

## 修改设计的工作流程

1. 从README和覆盖清单找到对应场景，先拍当前布局与关键状态。
2. 只修改独立资源中必要的参数、结构或样式，保留现有可访问性与交互含义。
3. 重开相同 `page/scene`，验证变化前后。动效用同一速度档、同一内容比较；不要仅凭“有动画”判定流畅。
4. 检查短／长／空内容、错误、窄屏以及减少动态效果；没有具体失败或新风险时停止扩大测试。
5. 更新规范、样张、参数附录和覆盖入口，提交给用户审阅具体预览。
6. 用户确认后，按映射把设计差异迁往正式前端，不复制预览数据与工具。

## 迁移时的对应关系

| 预览中的修改 | 正式迁移目标 | 必须保留的正式行为 |
|---|---|---|
| `预览资源/css/*` | 同名 `nexus/web/css/*` | 原主题覆盖与断点顺序 |
| `预览资源/js/core.js` 的设计helper | 正式core同名函数 | 正式偏好存储；不迁入预览的save/load空函数 |
| `预览资源/js/pivot.js` | 正式pivot对应几何与动效段 | 正式字体策略；只迁移经过审阅的设计变化 |
| 页面脚本中的HTML/CSS类 | 正式同名脚本的渲染函数 | 稳定节点身份、阅读锚点、保存反馈与数据接入 |
| `预览资源/js/plugins/host-sdk/plugin-pages` 的展示段 | 正式相应展示段 | 真实fetch与生命周期；不要迁入previewFetch |
| `页面模板.html` 的UI片段 | 正式index中对应片段 | 原资源路径、脚本顺序、后端启动脚本 |
| 工具栏、场景、样本、本地交互、组件库布局 | **不迁移** | 这些只属于设计站 |

迁移是有选择的代码差异，不是整份副本覆盖。复制版的core与插件模块存在刻意改动；整文件覆盖会破坏正式数据和连接。

## 如何更新快照

这份交付不自动跟随正式前端。正式设计有明确更新时，由维护者核对新基准和差异，再手动同步必要的资源与展示代码，重做本地适配，更新来源记录。`更新参数索引.py` **只重建独立资源的参数附录**，不会复制正式代码，更不会写回正式前端。

## 验证方式

预览运行仅依赖Python标准库和现代浏览器。可使用 `检查预览.py` 运行定向浏览器验证；需要已有Python Playwright环境和浏览器，测试工具不是预览运行依赖。浏览器无法运行时，必须如实报告未验证，不能只通过静态检查宣称动效合格。

正常验收包含：静态资源成功、无外部／业务请求、六页与组件库可打开、基本本地操作、场景重置、四主题和窄屏、弹窗高度上限、阅读与输入稳定、灵岛无尺寸过冲、主题切换背景持续。实体手机帧率、第三方真实插件、真实模型与后端行为留给正式集成验证。
