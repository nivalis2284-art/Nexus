# 页面与组件接入模板

先读 [README](README.md) 了解运行方式，再读 [DESIGN](DESIGN.md)。[页面模板.html](页面模板.html) 已包含整页场景和组件状态库，不调用真实后端。以下代码均应先在独立副本使用。

## 新增同风格页面片段

```js
container.innerHTML = `<div class="page">
  <header class="page-head" data-s>
    <div><h1>${N.esc(title)}</h1><p>${N.esc(description)}</p></div>
    <button class="btn ghost" type="button">刷新样本</button>
  </header>
  <div class="example-stack">
    ${records.map(item => `<section class="card example-card" data-s>
      <h2>${N.esc(item.title)}</h2><p>${N.esc(item.text)}</p>
    </section>`).join('')}
  </div>
</div>`;
```

```css
.example-stack { display:grid; gap:var(--card-gap); }
.example-card { padding:var(--card-padding); }
.example-card h2 { font-size:var(--text-title); }
.example-card p { margin-top:var(--row-gap); color:var(--ink-2); }
```

页面导航已调用入场编排；不要在 render 结束时再对同一批卡片调用一次。第一层可见结构标记 `data-s`，父卡片参与时内部行不重复编排。

## 表单和按钮

```html
<div class="fields">
  <label class="field"><span>名称</span><input name="name" required></label>
  <label class="field"><span>类型</span><select><option>示例选项</option></select></label>
</div>
<p class="sheet-error" role="alert"></p>
<div class="save-bar">
  <button class="btn ghost" type="button">取消</button>
  <button class="btn solid" type="submit">保存</button>
</div>
```

动作接预览内存事件；失败保留输入。复制源组件时保留 type、label、aria 状态、错误节点、禁用与忙碌反馈，不能只复制外观。

## 四档弹窗

```html
<dialog class="sheet" data-size="compact" aria-labelledby="sample-title">
  <div class="sheet-body">
    <header class="sheet-head"><h2 id="sample-title">选择示例</h2></header>
    <p>短内容收紧，长内容内部滚动。</p>
    <footer class="sheet-foot"><button class="btn solid">完成</button></footer>
  </div>
</dialog>
```

用 `N.openDialog(dialog)`／`N.closeDialog(dialog)` 打开关闭。小／中小／中／大分别是 `small/compact/medium/large`；宽 480/640/880/1120px，高度上限 60/70/80/88dvh。动态创建的 dialog 需要绑定 cancel 与遮罩关闭行为；固定 HTML 中的 dialog 已由公共工具处理。

## 动效接入

```js
N.enterItems(elements, viewport); // 页面560ms，主要分组70ms错峰，组内40ms／最多160ms
N.enterItems(elements, viewport, { profile: 'content' }); // 局部420ms、16px位移
N.enterItems(elements, viewport, { profile: 'float' });   // 浮层12px、最多4px短暂模糊
N.cascade(panel);                // 局部内容明确替换
N.anim(element, [
  { opacity:0, transform:'translateY(16px)' },
  { opacity:1, transform:'none' }
], { duration:N.DUR.enter, easing:N.EASE_ENTER });
```

`N.anim` 默认使用 `N.EASE_MOVE`，已乘速度系数，不要再乘一次。直接使用原生 `element.animate` 时才手动使用 `N.motionScale()`。`N.exitItems` 对可见项按0／30／60ms短错峰退出，`N.cancelMotion` 清理这一轮入退场；新动作从当前可见状态接续。稳定同步更新不播放整页入场；尺寸形变不要使用过冲曲线。持续循环沿用原规则。

## 添加预览状态

样本在 `演示数据.js`，本地行为在 `本地交互.js`，场景入口在 `启动.js`。展示性节点放入 `组件库.js`，预览工具自身的样式放入 `演示站.css`；不要把演示工具的 CSS 混入正式组件样式。每次新增状态，同步覆盖清单与文档中的测试入口。
