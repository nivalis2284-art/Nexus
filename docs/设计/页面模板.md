# 前端页面与组件接入模板

先读 [DESIGN.md](DESIGN.md)。[页面模板.html](页面模板.html)是实际加载仓库 CSS、JS 参数的静态组件样张，可直接用浏览器打开；它不调用后端、不产生业务数据。

## 现有页面里新增一组卡片

保留现有 `renderXxx()`、API 和事件委托。按下面结构写正文，数据文本用 `N.esc()`；不要复制整套主题或创建新的页面切换器。

```js
view.innerHTML = `<div class="page">
  <header class="page-head" data-s>
    <div><h1>${N.esc(title)}</h1><p>${N.esc(description)}</p></div>
    <button type="button" class="btn ghost" data-act="refresh-example">刷新</button>
  </header>
  <div class="example-stack">
    ${records.map(record => `<section class="card example-card" data-s>
      <h2>${N.esc(record.title)}</h2>
      <p>${N.esc(record.description)}</p>
    </section>`).join('')}
  </div>
</div>`;
```

```css
.example-stack { display: grid; gap: var(--card-gap); }
.example-card { padding: var(--card-padding); }
.example-card h2 { font-size: var(--text-title); }
.example-card p { margin-top: var(--row-gap); font-size: var(--text-body); }
```

`example-` 改为对应业务前缀。刷新按钮必须接现有 API，并处理错误。不要把模板中的占位动作当成已实现功能。

## 表单与操作区

```html
<div class="fields">
  <label class="field"><span>字段名称</span><input name="name" required></label>
  <label class="field"><span>另一字段</span><input name="detail"></label>
</div>
<div class="save-bar">
  <button type="button" class="btn ghost">取消</button>
  <button type="submit" class="btn solid">保存</button>
</div>
```

优先使用 `.field`、`.fields`、`.btn`、`.save-bar`、`.sheet` 及已有编辑弹窗。状态由请求真实结果决定；失败保留输入，危险操作沿用现有确认流程。

## 弹窗四档

```html
<dialog class="sheet" data-size="medium" aria-labelledby="example-dialog-title">
  <div class="sheet-body">
    <header class="sheet-head"><h2 id="example-dialog-title">编辑示例</h2></header>
    <!-- 复用现有字段和操作按钮 -->
  </div>
</dialog>
```

`small`：480px 宽、最高 60dvh，适合确认和简短操作。`compact`：640px 宽、最高 70dvh，中小档，用于项目选择等紧凑列表。`medium`：880px 宽、最高 80dvh，用于编辑表单、插件介绍和运行状态。`large`：1120px 宽、最高 88dvh，用于预览、插件功能页和放大的管理面板。四档高度都随内容收紧，不强制拉伸；超出上限时才在内部滚动。保留至少 16px 屏幕边距，不得在业务 CSS 中覆盖宽高。打开／关闭复用 `N.openDialog`／`N.closeDialog`；[样张](页面模板.html)提供四档静态预览。

## 入场与局部更新

导航切页已由外壳调用 `N.stagger(view)`，页面渲染函数无需再调用一次。首层可参与入场的标题、卡片标记 `data-s`；卡片内部已有父卡片参与时，不再编排子项。

面板内容明确替换后使用 `N.cascade(panel)`，不要额外传入本页自定的间隔或时长。常规同步更新不重新播放入场。自定义布局用 `N.enterItems(elements, viewport)`，仍遵守可见项、240ms、24ms、上限 8 项的规则。

## 新组件确实需要独立样式时

颜色取现有语义色；几何与间距取 `tokens.css`。单次的布局组合可以写业务 CSS，不能为一处特殊情况创建通用组件框架。布局以真实内容和手机宽度验证，主从面板才使用约 62／38；表单、工具栏和文字阅读不强套黄金比例。
