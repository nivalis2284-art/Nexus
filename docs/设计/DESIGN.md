# Nexus 前端设计规范与快照边界

本目录用于**先预览设计，再迁移到产品**。现状基准为 `b62b7b1`（2026-11-01）；页面与组件用虚构数据演示，不要求复刻后端业务。入口见 [README](README.md)，细项见 [覆盖清单](覆盖清单.md)。

## 设计语言

保留「灵玉／星枢 × 白昼／黑夜」、常驻可交互中枢、不透明卡片和追光。默认星枢黑夜。两套主题共用圆角、间距、字阶、正文结构和动效节奏；区别是颜色、材质与背景场景。

灵玉使用温润绿、金晶环轨与玉质中枢；星枢使用冷蓝紫、寒星微芒与球形中枢。界面是工作与阅读场景，视觉重点应是内容、真实状态和操作，不增加没有状态依据的闪光、呼吸或无限循环。

## 尺度与布局

| 角色 | 固定规则 |
|---|---|
| 基础网格 | 4px；常用 4、8、12、16、20、24、32、40、48、64、80、96px |
| 主卡片 | 20px 圆角；桌面内边距 24px、手机 16px |
| 弹窗／输入舱 | 24px 圆角 |
| 普通控件 | 12px 圆角；小标签 8px、行内代码 4px、内嵌表面 16px |
| 同级卡片／分组 | 桌面 24px／32px；手机 16px／24px |
| 控件间距／行间距 | 8px／12px；内嵌布局桌面 16px、手机 12px |
| 管理页 | 最大宽 960px，复用 `.page`；页面左右留白桌面 32px、手机 16px |
| 阅读轴 | `--measure:680px`；输入舱外宽加 44px，由内边距对齐文字 |
| 主从布局 | 插件宽屏约 38.2%／61.8%；对等表单使用 1:1，不强套黄金比例 |

头像、圆形按钮与导航胶囊按其形状使用 50% 或 999px。图标光学校正、细线、开关轨道和背景几何允许明确的 1／2px 等例外，不扩展成一套新的间距尺度。

## 字体、颜色与表面

- 标题使用 `--font-display`；阅读正文 `--font-reading`；控件 `--font-sans`；代码、真实路径与数字测量使用 `--mono`。本地字体和许可随包保留。
- 字阶：caption 12、UI 14、body 16、title 20、heading 24、page 桌面 32／手机 24、metric 40px。界面行高 1.5，长正文按现有 Markdown 与 `.ling-body` 规则。
- 颜色取语义变量：`paper` 背景、`card` 主表面、`raised` 内嵌面、`ink/ink-2/ink-3` 信息层级、`line/line-2` 边界、`jade` 主操作、`danger` 危险操作。
- 卡片不透明。追光由共享实现绘制 2px 边界，直边和圆角保持同厚，不覆盖内容或另加一层背景色。
- 沿用 `--sh-1/2/3` 层级。主题只改变材质含义，不改变组件几何。

## 弹窗和关键组件

| 档位 | `data-size` | 宽度上限 | 高度上限 | 常见用途 |
|---|---|---:|---:|---|
| 小 | small | 480px | 60dvh | 确认、项目创建／重命名 |
| 中小 | compact | 640px | 70dvh | 项目选择 |
| 中 | medium | 880px | 80dvh | 编辑、技能、提供商、MCP、钩子、介绍、运行状态 |
| 大 | large | 1120px | 88dvh | 文件预览、功能页、插件管理放大 |

四档高度均随内容收紧，超过上限后内部滚动，两侧至少 16px。标题、正文与操作的结构沿用已有组件，不由某个页面自行覆盖宽高。

- 插件内嵌管理面板固定 `min(640px,72dvh)`；标题和放大按钮固定，正文内部滚动。放大为大档弹窗，移动同一个面板并保存草稿与滚动位置。
- 插件状态行：左侧在途／运行态／能力，右侧紧凑排列启用标签与开关；下方左侧重载／停止在途，右侧介绍／卸载。窄屏按组换行。
- 消息正文至时间 8px，时间至操作 4px；时间 12px，图标 16px、点击区 32px、组内间距 4px。对齐 SVG 外框，不只对齐按钮盒子。
- 提供商模型行：标签至输入 8px，输入高 44px；模型之间和新增区分隔线上下各留 `--inner-gap`，避免父级 gap 与 margin 叠加。

## 动效与交互约束

| 场景 | 标准档 |
|---|---:|
| 按下／小反馈 | 96ms／240ms |
| 单批退场／完整退场 | 160ms／220ms，操作区→主体→标题，0／30／60ms |
| 卡片／可见消息／弹窗入场 | 560ms |
| 局部内容／菜单 | 420ms |
| 页面位移／主要分组间隔 | 标题与工具16px，卡片24px、scale(.99)；70ms错峰 |
| 组内错峰／时间窗 | 40ms；多项均摊到160ms内，主要分组启动窗280ms |
| 隐藏／恢复界面 | 320ms |
| 新流式文字 | 200ms |
| 主题柔边波纹 | 850ms |

页面使用 `N.stagger`，面板使用 `N.cascade`，自定义可见项使用 `N.enterItems`。标题、工具与内容分组编排，新页可见内容约0.8–1秒落定。不要根容器与子项叠加同一轮淡入，不给屏幕外历史排队入场。取消固定八项截断，按可见区域和时间窗组织密集内容。

有限过渡的入场／移动／退场分别使用 `N.EASE_ENTER=cubic-bezier(.22,0,.2,1)`、`N.EASE_MOVE=cubic-bezier(.4,0,.2,1)`、`N.EASE_EXIT=cubic-bezier(.4,0,1,1)`。灵岛展开560ms、收起220ms；宽、高、圆角、顶部与窄屏宽度上限同步插值，无尺寸过冲。标题70ms后进入，主要内容140ms后进入，底部操作210ms后进入，组内另有短错峰。

按钮、开关和滑块允许轻微回弹；原有导航物理采样轨迹不再叠加缓动。粒子、轨道、加载圆环与扫光等持续循环保持原曲线与周期。卡片与面板轻缩放；灵岛、弹窗和菜单内容交接可用最多4px短暂模糊，阅读正文不新增模糊。

流式文字短缓冲显现，稳定段落复用，结束后原位收束。用户上翻后保留阅读锚点；多行输入在布局外测量，只在高度变化时更新。系统“减少动态效果”取消位移与错峰，保留稳定状态与必要反馈。

## 修改与迁移原则

参数唯一入口是预览副本的 `tokens.css` 与主题语义色。新例子复用现有类和 helper；确需调整规则时同步规范、样张和参数附录。**现状里仍存在组件局部硬编码参数，附录会明确记录；不得将它们误认为共享规范。**

不增加新框架、动画库、第三方图标或在线资源。先在独立副本验证，用户审阅后只迁移相关设计改动；详见 [预览与迁移](预览与迁移.md)。
