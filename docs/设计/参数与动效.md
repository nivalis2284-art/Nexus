# 参数与动效

本册给出参数的用途与修改方式；精确声明、主题覆盖条件、来源行号在附录中。附录记录的是**声明**，同一变量在四个主题或断点下出现多次属于正常覆盖。

## 1. 参数分层与读取顺序

| 层级 | 独立副本 | 修改含义 |
|---|---|---|
| 共享尺度 | `css/tokens.css` | 间距、圆角、字阶、尺寸档位、时长；修改会影响所有页面 |
| 基础结构 | `css/ling.css` | 外壳、主交流、控件、字体与部分局部几何 |
| 业务布局 | `css/app.css` | 工作、上下文、设置、插件等页面的布局与状态 |
| 主题材质 | `css/theme.css` | 四套语义色、背景与追光；不自行重设几何 |
| 插件宿主 | `css/plugin-pages.css` | `.hui-*` 与插件弹窗；继承共享参数 |
| iframe | `css/plugin-ui.css`、`js/plugin-ui.js` | 独立文档中的宿主语义色与控件同步 |
| 预览工具 | `演示站.css` | 只用于预览工具和组件库，不迁入正式前端 |

CSS 加载顺序与正式页面保持：tokens → ling → app → theme → plugin-pages。局部选择器和断点可能覆盖前面的声明，不能只搜索到第一个值就认定它是最终值。浏览器计算样式用于验证最终结果。

| `--card-padding / --card-gap` | 桌面 24px；≤760px 为16px |
| `--group-gap` | 桌面32px；手机24px |
| `--inner-gap` | 桌面16px；手机12px |
| `--row-gap / --control-gap` | 12px／8px |
| `--page-gutter / --page-width` | 桌面32px／960px；手机gutter16px |
| `--r-inline/tag/ctrl/inner/card/sheet` | 4/8/12/16/20/24px；pill999px |
| `--r-bubble` | 20px 20px 8px 20px，用户消息尾角 |
| `--text-*` | 12/14/16/20/24/32/40px；手机page24px |
| `--leading-ui / --leading-body` | 1.5／1.75；组件可有明确阅读行高 |
| `--control-height / --control-height-sm` | 40／36px；模型字段44px是明确的组件专用几何 |

语义色、字体、阴影、圆角、间距和动态变量的全部覆盖见 [CSS变量](参数附录/CSS变量.md)。具体边框、padding、宽高、grid、定位、过渡与动画声明见每份 [组件样式附录](参数附录/组件样式-app.md)，不是全部数值都应提升成全局 token。

## 3. 主题与材质

根元素使用 `data-palette="cool|jade"` 和 `data-theme="day|night"`。状态颜色依照语义变量，不在组件里另造一组主题。

| 语义族 | 应用于 |
|---|---|
| paper / paper-2 / card / raised | 页面、次级背景、主表面、内嵌面 |
| ink / ink-2 / ink-3 / ink-4 | 正文、说明、元信息、弱状态 |
| line / line-2 | 边界和滚动条；不是正文文字色 |
| jade / jade-hi / jade-deep / jade-soft | 主操作、强调、状态与轻背景 |
| cinnabar / danger / busy | 需要决定、危险、处理中 |
| island / island-2 / i-ink-* | 灵岛的深色表面与文字层级 |
| sh-1/2/3 | 普通表面、交互抬升、浮层 |
| mx / my / spot-on | 每个追光表面的局部指针坐标与可见性 |

颜色、渐变与阴影的具体色值按四套 selector 在附录逐项列出；预览切换主题后可直接用开发者工具查看最终取值。不能将灵玉某段正文加竖线或额外缩进来表达主题差异。

## 4. 动效时序与 helper

基础时长：fast96、micro160、base240、content420、move560、enter560、exit220ms；fade320、text200、theme850ms。标题和工具16px、卡片24px并scale(.99)入场；主要分组70ms错峰，启动窗280ms；组内40ms错峰，多项均摊到160ms窗内。只编排可见项，不再固定截断到八项。

五档标签为快／较快／标准／较慢／慢，对应 UI 键 `0.5/0.75/1/1.25/1.5`，实际乘数为 **0.68/0.84/1/1.16/1.32**；不要把标签数字直接当乘数。`N.anim` 自动乘系数并处理减少动态效果；原生 `.animate` 的调用点才手动乘。

| 场景 | 触发与制作 | 结束／打断 |
|---|---|---|
| 页面导航 | 旧页按操作／主体／标题0／30／60ms启动，每批160ms；再进入新页 | 新页根容器不叠加第二轮淡入，快速导航废弃旧回调 |
| 页面／卡片入场 | `N.enterItems` 默认page：560ms，16／24px，分组70ms、组内40ms | `_enterMotion` 从当前可见状态接续；屏外不排队，新页约0.8–1秒落定 |
| 局部内容替换 | `N.cascade(panel)` 或content profile：420ms、16px | 数据同步不反复重播 |
| 灵岛尺寸 | 宽／高／maxWidth／圆角共同560ms、`N.EASE_MOVE`；顶部与内容缩放单独使用settle弹簧，收起220ms | 从当前可见状态接续；结束清理ghost、临时宽度及弹簧动画；宽高无过冲 |
| 导航滑块 | `N.moveInk`处理当前几何和目标；dock进度系数7、拉伸比例.4／上限.65、张力2，加强惯性尾段；普通tab位置用按距离增大阻尼的弹簧、宽高单独平稳插值 | 导航物理采样不叠加缓动；普通tab回弹保持在轨道留白内 |
| 弹窗与菜单 | 外壳560／420ms、透明度0→1、scale(.96／.97)；显示前建立动画并以backwards填充起始帧；入场位移与缩放用settle弹簧，透明度单独使用单调缓动；float profile内部12px、最多4px模糊，标题／内容／操作70／140／210ms开始 | 关闭220ms，外壳变换及透明度均用EXIT单调收走；中途重开取消旧动画并从当前状态接续；减少动态效果直接显示，结束清理临时状态 |
| 主题切换 | 850ms柔边波纹；旧／新背景均继续更新 | 完成后清理旧层和临时命名；无ViewTransition或减少动态效果直接更新 |
| 隐藏界面 | 320ms透明度，保留布局，inert阻止焦点穿透 | 恢复阅读位置，隐藏期间不累计待重播文字 |
| 流式正文 | 后续内容约120ms追随，Markdown最多30次/秒，新增片段200ms | 结束下一帧补齐，不整体替换；稳定段落和代码容器复用 |
| 发送衔接 | 先测输入与可见消息，再完成布局，位置560ms衔接；新气泡延后140ms、显现420ms | 不等待动画结束才提交；空态副本220ms退出，不复制中枢 |
| 构成条 | 560ms／70ms，变换从左端增长、`N.EASE_MOVE` | 不使用尺寸过冲；连续刷新不出现多层残影 |
| 上下文占用数字 | 进入上下文页时`N.countUp`从0递增至百分比，560ms×速度系数，复用现有三次减速曲线 | 刷新／页内标签切换不从0重播；缺测显示短横线；减少动态效果直接显示目标值 |
| 工作组折叠 | 外壳展开560ms／收起220ms，条目在展开70ms后开始420ms局部错峰 | 外壳与条目动作重叠，快速反向从当前高度继续 |

有限过渡使用 `EASE_ENTER=cubic-bezier(.22,0,.2,1)`、`EASE_MOVE=cubic-bezier(.4,0,.2,1)`、`EASE_EXIT=cubic-bezier(.4,0,1,1)`。`N.anim`默认MOVE；弹簧和导航已采样的非线性轨迹不重复叠加缓动。共享settle刚度490、阻尼24，首个过冲约13%，随后快速衰减；常用按钮与开关释放420ms、按下96ms。弹窗／菜单位移与缩放、灵岛顶部与内容缩放可使用弹簧；页面及灵岛宽高仍使用无过冲曲线。持续循环保留原`EASE_OUT=cubic-bezier(.22,1,.36,1)`、匀速旋转和现有物理推进，不随本轮改动变速。具体入口见[JS动效与局部参数](参数附录/JS动效与局部参数.md)。

## 5. 布局、断点与非共享参数

- 所有媒体查询、特性分支和关键帧位置见 [断点与关键帧](参数附录/断点与关键帧.md)。760px 是共享token的手机档，但某些组件还有640、980、1100等自身断点；不应只测试一个阈值。
- 主交流输入高度上限200px；附件最多8个，图片5MiB、文档25MiB。它们是既有交互阈值，不是视觉尺度，也不在本次随意更改。
- 内嵌插件管理面板640px/72dvh、滚动区max-height、预览图片上限、导航偏移等是组件专用参数，见具体CSS声明。
- 背景参数属于几何和物理运动：Canvas DPR最高2，星点数依面积、最低60；灵玉三层环带有自己的数量、半径、倾斜和角速度，不能按4px间距表重写。
- SVG 的 viewBox、渐变、路径、点位和 HTML 内联参数见 [HTML与SVG几何](参数附录/HTML与SVG几何.md)，与源代码相互对应，不把路径数值误当作布局间距。
- 星点初始分布和角度有随机性，场景内容与回复节奏可重复，粒子初始像素位置不承诺完全一致。验收应检查连续性和形状，不做每个星点的逐像素比对。

## 6. 参数修改的操作顺序

先确定修改的是共享尺度、主题材质、局部组件还是背景几何 → 在独立副本修改一处源头 → 检查所有调用方 → 四主题与桌面／手机定向验证 → 运行 `python 更新参数索引.py` 更新本地附录 → 更新本册与对应样张。

附录索引来自声明定位，不是CSS优先级计算器或JS语义解析器；最终计算值仍应实测。移除过时参数时先检查真实使用位置，不能因为样张没有显示就删除正式实现。
