# Nexus 独立设计演示站

这是一份**可交互的前端设计快照**。它保留 Nexus 的页面布局、组件、主题和动效，以虚构数据演示状态；不连接 Nexus 后端、不运行模型或插件，不读写真实项目。

## 启动与浏览

1. Windows 双击 [启动预览.bat](启动预览.bat)，需要本机已有 Python 3。无需启动 Nexus，也不需要安装项目依赖。
2. 脚本仅在 `127.0.0.1` 的空闲端口提供本目录静态文件，并打开 [页面模板.html](页面模板.html)。不要直接用 `file://` 双击 HTML：字体、iframe 与异步资源应通过静态地址加载。
3. 右下角“设计预览工具”默认收起；展开后切换页面、场景、主题和速度，打开组件状态库。
4. 普通导航、灵岛、设置、开关、表单、编辑、复制、附件选择等可以直接操作。刷新页面恢复样本。
5. 终端按 Ctrl+C 停止服务。命令行可执行 `python 静态预览.py --no-browser`，只启动服务而不打开浏览器。

URL 支持可复现入口，例如 `页面模板.html?page=chat&scene=stream`。`gallery=dialogs` 直接打开弹窗样张；`tools=1` 展开工具，`tools=hidden` 隐藏工具方便截图。所有链接应保留静态服务分配的实际端口。

## 文件分工

- `预览资源/css`：独立样式快照，修改设计参数优先找 `tokens.css`。
- `预览资源/js`：正式前端渲染与动效脚本副本。`core.js` 关闭偏好持久化，`pivot.js` 关闭在线字体，插件展示请求改用本地函数。
- `预览资源/演示数据.js`：可替换的虚构样本。
- `预览资源/本地交互.js`：演示状态变化、定时回复与保存反馈；不发送 HTTP 业务请求。
- `预览资源/启动.js`：预览工具栏、场景选择和清理。
- `预览资源/组件库.js`：集中展示状态及插件宿主组件。
- `预览资源/演示站.css`：只影响演示工具和样张的布局。
- `参数附录`：全部 CSS 变量声明、组件样式、断点、关键帧、JS 参数入口和图标目录。按目标文件查阅，避免把全部附录塞入上下文。

## 验证与限制

随包 `检查预览.py` 提供定向浏览器检查，需要已有的 Playwright Python 环境；它不是运行预览的依赖。参数修改后执行 `python 更新参数索引.py`，只更新本目录参数附录。

本地保存、任务推进、审批、文件夹选择、插件导入、模型回复都是演示。路径和服务地址使用示例值，API Key 不会被发送或保存。选中的本地附件只在本页读取并预览，不上传。未验证真实模型、实际插件执行或实体手机帧率。

本地字体子集随包提供，生僻字可能使用系统回退字体；不为补字联网。第三方许可保留在 `预览资源/assets` 与 `预览资源/vendor` 中。
