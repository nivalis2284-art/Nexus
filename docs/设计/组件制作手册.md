# 组件制作手册

查阅方式：先在组件状态库打开对应分组，再查本册的结构和约束；具体声明逐项见 [参数附录](参数附录/CSS变量.md)。正式源码映射与副本的关系见覆盖清单。这里记录“如何制作”，不是重新定义一套 UI。

## 1. 原子控件与表单

| 组件／类 | 制作方式与参数 | 状态与注意事项 |
|---|---|---|
| 主／次按钮 `.btn.solid/.ghost` | 使用 button 与明确动作名；高 40px，复用 `--r-btn` 和主题色 | hover／active／focus／disabled；提交按钮明确 type |
| 小按钮 `.btn.sm` | 高 36px；组内 gap 8px | 不通过随机 margin 让个别按钮凑位置 |
| 图标按钮 `.ic-btn` | 现有圆形几何、SVG `N.icon`，有 aria-label | 视觉图标与命中区区分；不要以 Unicode 代替 |
| 消息操作 `.msg-tools` | 32px 点击区、16px 图标，操作间隔 4px | 悬停和 focus-within 显示；时间与操作分行 |
| 开关 `.switch` | button、role=switch、aria-checked；44×26px，20px 滑块、3px 初始偏移 | 开／关／禁用／忙碌。改变 checked 状态而不是新增另一套样式 |
| 普通字段 `.field` | label 包含名称和控件，标签间隔 8px | 说明和错误节点独立；错误保留值，禁用不靠颜色猜测 |
| 等列字段 `.fields` | 两列 minmax(0,1fr)，按原断点改单列 | 子项 min-width:0，长选项不撑破容器 |
| 模型字段 `.model-row/.model-limit` | 模型、上下文、输出都有标签；输入 44px | tok 单位在输入内右侧，数值留 padding；同组输入基线一致 |
| 多行输入 textarea | 用现有字阶、行高、边界和焦点环 | 主交流使用布局外测量；普通表单不能因自动伸缩挤掉保存入口 |
| 单选／复选 | 用原生 input 及 label，组有描述 | 键盘行为保留；批量选择支持 indeterminate |
| 分段选项 `.tabs/.seg/.perm` | 外壳和指示器的 padding、offset 成套设置 | role、aria-selected/checked 与 active 一致；复用 `N.moveInk` |
| 标签 `.pill/.pstate` | 小字号与语义色，胶囊或 8px 圆角按来源类使用 | 启用／关闭／忙碌／错误要有文字；标签不是按钮 |

最小开关：

```html
<button type="button" class="switch" role="switch"
        aria-checked="false" aria-label="启用示例"></button>
```

不要给 label 中被点击的控件在同一次默认激活期间不断重建；优先复用节点或用独立包装和明确 aria-label。

## 2. 表面、卡片与滚动

| 组件 | 结构与取值 | 制作与验收 |
|---|---|---|
| 主卡片 `.card` | 相对定位、不透明 `--card`，20px 圆角 | 复用边界与阴影，不增加背景蒙版 |
| 内嵌区 `--raised` | 16px 圆角、内部间距档位 | 按主次组织，不把每行都套成主卡片 |
| 交互卡 `.lift` | 悬停轻移、点击缩放来自原共享 CSS | 只给实际可交互对象；键盘可访问 |
| 折叠 `.ctx-sec`、details | summary 有名称、说明与方向图标 | summary 与外壳共用卡片圆角；保留 open 状态 |
| 追光 | 共享 selector 的 ::after；2px 原生边框区域 | 指针位置按表面单独保存；圆角与直边同厚，不遮挡内容 |
| 固定管理面板 | 外壳 flex column，头部 flex:none；正文 flex+min-height:0+overflow:auto | 验证滚动的是正文；短／长插件不改变外壳高度 |
| 长代码／表格 | 容器 overflow-x:auto；阅读正文 overflow-wrap | 不用全页横向滚动容纳局部内容 |
| 路径与标题省略 | min-width:0、overflow:hidden、text-overflow | 路径可用 title 查看全值；长正文不能被单行省略 |
| 自定义滚动条 | thin、语义 line-2 色、透明轨道 | 不出现原生白色轨道；短内容不强制留一条假进度 |

## 3. 会话与 Markdown

- 用户结构为 `.msg.msg-user > .bubble + 附件 + .msg-foot`。助手结构为 `.ling-head + .ling-body + .msg-foot`。助手首图标与正文左轴、用户末图标与气泡／时间右轴对齐。
- 正文通过 `N.md` 解析并清洗，再 `N.decorate` 添加代码工具栏和高亮。不能为预览放弃清洗链路，也不能整段直接插入未清洗 HTML。
- Markdown 标题、列表、引用、表格和代码拥有不同阅读间距；普通正文没有整条竖线。引用线是引用块自身的结构。
- 流式阶段复用段落与代码容器；未闭合代码围栏仍按增长中的代码块显示，结束后补齐操作和用时。短片段淡入不等于永久为每个字符建节点。
- `.phase` 汇总思考与工具，`.step` 展示可展开细节。输出交接时保持已显示内容；用 mock 定时数据观察外观，不将延迟当成真实模型性能。
- 附件包含名称、体积、类型、下载／预览；大图适配窗口，不让图片加载改变已暂停跟随时的阅读位置。

## 4. 弹窗、菜单与反馈

四档弹窗均使用 `.sheet` 与 `data-size`。普通表单内容放 `.sheet-body`；介绍／功能页使用固定 `.sheet-head` 和滚动内容区；文件预览使用 `.fp-head/.fp-body`；插件管理移动原面板。宽高数值见 DESIGN，不复制一组硬编码值。

公共 `N.openDialog/N.closeDialog` 管理进入退出。关闭期间不重复触发退出；Esc、遮罩与关闭按钮应得到一致结果，结束后焦点返回有意义的入口。动态样张需要自己接 cancel 和遮罩，不能假设初始化时的批量事件绑定会自动覆盖新节点。

`.menu` 由 `N.menu(anchor, items)` 打开，位置根据锚点和视口计算，内容是可访问操作项。`.usage-pop` 是用量说明，不作为新的页面。`.toast` 与灵岛短通知提供轻量反馈，错误说明可恢复路径，不无限叠加。

审批卡有归属、操作名、理由、参数、允许／拒绝；提问卡有问题、选项、自由输入与提交。操作中防止重复提交，失败时恢复可用入口。预览只删除对应内存卡片。

## 5. 背景、灵岛与主题

- 背景使用 aura、Canvas 粒子和 SVG 中枢；复用 `pivot.js` 的时间推进。主题变化不重建全部粒子或重置角度／缩放。
- 空态的中枢定位与常驻背景定位衔接；长按和拖动影响偏转、光效与释放波纹。隐藏界面后应仍能操作中枢。
- 灵岛紧凑为胶囊，总览／详情为 24px 圆角；尺寸变形单一进度，无过冲。窄屏 max-width 也参与动画，避免先变窄再垂直缩。
- 主题切换使用实时旧背景层和柔边波纹；不是冻结一张背景截图。旧层在完成／取消后销毁。
- 减少动态效果取消粒子运动或位移，但不破坏页面、消息、焦点和内容可用性。

## 6. 插件宿主组件制作

这些是设计组件类型，不是要求第三方插件采用同一业务模型。预览的 `Preview.hostView` 给出可运行样本。

| 类型 | 设计职责 | 必须展示的细节 |
|---|---|---|
| section | 主内容分组 | 标题、说明、内边距、子组件间距 |
| row / column | 横向／纵向组合 | gap、换行、min-width、窄屏重排 |
| text | 正文 | 换行、语义色、长内容 |
| badge | 状态 | 紧凑边界、文字与色彩 |
| code | 代码或 JSON | 等宽、留白、内部滚动 |
| button | 动作入口 | 主次、禁用、加载和确认 |
| field | text / textarea / number / select / switch | label、help、error、readonly、输入值保留 |
| list | 条目与操作 | 标题、正文、辅助信息、空态 |
| table | 列和操作 | 表头、单元格、长内容、窄屏滚动 |
| pagination | 页码切换 | 当前页／总页数、首末页禁用 |
| notice / errors / dialog | 反馈与编辑 | 状态通知、字段错误和中档弹窗 |

同源 iframe 例子使用 `plugin-ui.js` 同步宿主主题与现有 token；它展示嵌入设计，不代表第三方自绘页面已被统一。

## 7. 修改后的最小核对

同一组件至少比较两主题昼夜、桌面与手机；交互组件再检查焦点、禁用和错误；布局组件检查空／短／长内容；动效检查重播、打断、结束与减少动态效果。找到实际失败再扩大验证，不为假想场景添加新框架或兜底层。
