# 页面与状态

本册解释整页如何组织。所有入口均相对静态服务下的 `页面模板.html`；可在 URL 后加 `?page=页面&scene=场景`。样本定义在 `预览资源/演示数据.js`，切换在 `启动.js`，渲染使用 `js` 目录内的副本。不是正式接口文档。

## 公共外壳

桌面左侧 `.dock` 为页面胶囊，顶部 `.island` 为工作状态入口，`.stage > .view` 是页面容器。管理页面由 `.page` 限制宽度；主交流使用单独阅读轴。窄屏通过现有断点将导航收为手机胶囊与菜单入口，不额外设计另一种导航风格。

导航改变当前页面，旧页退出后新页按可见组件进入；主题与背景不销毁。隐藏界面只隐藏内容、灵岛和普通提示，保留导航与背景。再点眼睛、Esc 或页面导航恢复。灵岛可从紧凑态进入工作总览，再进入任务详情；模态层阻止点击后面的页面并管理焦点。

预览右下角工具栏是演示辅助，不属于正式设计。它只选择场景、主题、速度、失败反馈和重播；截图时可用 `tools=hidden`。

## 主交流 `page=chat`

| 场景 | 观察内容 | 操作与期望 |
|---|---|---|
| empty | 欢迎语、中枢、建议、居中的输入舱 | 输入并发送；欢迎语退出、输入舱衔接到会话位置，中枢不重新挂载 |
| conversation | 用户气泡、时间与操作、思考／工具、助手 Markdown | 悬停或 Tab 显示操作；编辑打开中档，删除影响内存且可撤销 |
| stream | 思考→工具→正文、停止按钮、文字渐显 | 定时样本自动运行；点击停止后保留已显示内容，完成时正文原位收束 |
| attention | 主交流审批／问题与工作请求 | 允许／拒绝或选择／填写回答后对应卡片消失；不操作真实工具 |
| details | 附件、图片、关联工作入口、结果卡、步骤列表、已压缩标签 | 打开文件／图片与工作详情，比较特殊内容对阅读轴的影响 |
| error | 失败说明、待处理输入、排队与重启后待确认 | 删除提示只移除对应内存项；失败不会清空前面的回复 |
| long | 长历史、标题／列表／表格／代码 | 上翻后新增内容不抢回底部；“最新”恢复跟随；屏外消息不排队入场 |

### 布局与关键细节

- `.conversation` 是唯一历史滚动容器，顶部和底部遮罩避免文字直接撞上悬浮层。
- 用户气泡限制在阅读轴内并靠右；`.msg-foot` 两行表示时间和操作。助手头像与时间在正文前，用时和复制／删除在正文后。
- 思考和工具属于 `.phase`，细项是 `.step`；折叠状态与消息节点复用，不因每次文字增长重建全文。
- `.composer` 包含目标标签、附件区、输入、多行扩展、模型与思考强度、上下文占用、唯一发送／停止按钮。
- 每次输入只更新测量高度，不能先设 auto 再撑回。输入超过高度上限后自身滚动。
- 附件选取与拖放仅在浏览器读取；文档和图片用不同的链接／预览。文件预览使用大档。
- 底部用量弹层将总 token 与上下文占用区分；上下文没有测量值时显示短横线。

**制作入口：** `js/chat.js` 中的 `buildMsg/renderChat/enterChat`，CSS 的 `.msg/.bubble/.ling-body/.composer`。迁移时保留稳定消息身份、草稿、滚动锚点及事件委托，不能以整体 innerHTML 替换流式会话来实现动画。

## 工作 `page=work`

`overview` 展示进行中、排队、子工作、等待决定、暂停、完成、取消与归档。`empty` 展示安静的等待状态。`progress` 依次改变进展文字、验证步骤与完成状态。

- 主列表分进行中／已挂起／已结束／已归档，后几组可折叠；折叠标题保留数量与说明。
- `.work-item` 含状态图标、标题、状态标签、摘要、模型／时间／路径及操作。整卡支持键盘打开，嵌套操作不误触整卡。
- 子工作用父子提示而不是新的一套卡片。完成与归档只改变状态和可用动作，不改变主要对齐轴。
- 点击工作通过灵岛详情显示目标、进展、下一步、时间、范围、步骤／验证、工作记录、子任务与待决定项。
- 详情记录只读；“在主交流中补充”将目标带回输入舱。演示中的进度计时不执行实际任务。

**制作入口：** `js/work.js` 的 `workCard/renderWork/detailHTML`。状态视觉取 `N.stateLabel` 与现有状态类，不能用颜色替代全部文字提示。

## 上下文 `page=context`

`system` 展示指令与来源；`history` 展示摘要和未压缩历史；`locked` 展示运行中禁用编辑；`empty` 展示无测量值和空数据。

- 顶部概览显示总占用百分比、窗口与三段构成。进入页面时百分比从0缓动至目标值，标准560ms并随速度档位缩放；刷新或切换页内标签不重播，缺测仍显示短横线，减少动态效果时直接显示目标值。构成条是**已用内容内部比例**，不是把每一段当成模型窗口的比例。
- 标签页共享滑块与计数。所有者指令逐条编号、编辑／删除；角色为三张次级卡片；来源为只读折叠区。
- 摘要卡片显示覆盖范围和正文，编辑在通用弹窗保存。历史以一轮为单位，复选框、全选、删除数量与运行锁定状态保持一致。
- 删除和撤销只模拟当前样本，长段落自然换行。构成条以统一无过冲时序出现，不在每次数据刷新时重播整页。

**制作入口：** `js/context.js` 的 `systemPanel/historyPanel/renderContext`。维护原有 tab、选择与折叠状态；不要把只读来源画成可编辑表单。

## 技能 `page=skills`

`overview` 同时展示个人、项目、内置及同名覆盖；`empty` 展示创建入口；`error` 增加读取失败卡片。

- `.skill-grid` 在宽屏多列、窄屏重排。标题可使用代码字形，但描述仍是界面正文。
- 来源、是否生效、是否只读是不同维度：项目覆盖的个人技能需要明确提示；内置技能只能查看。
- 查看／编辑共享中档弹窗，包含来源、slug 名称、摘要和 Markdown 正文。无效名称与空摘要保留输入并解释错误。
- 删除有确认和退场，失败时不留下半透明的不可用卡片。

**制作入口：** `js/skills.js` 的 `renderSkills/openEditor`。保留可编辑性与焦点语义，不给只读技能开放保存。

## 插件 `page=plugins`

`overview`、`empty`、`loading`、`error`、`requests` 分别覆盖管理、空列表、加载、错误和请求记录。

- 宽屏左侧列表／右侧管理约38.2%／61.8%；980px及以下管理区上下排列，761–980px列表保持横向浏览；760px及以下列表逐项纵排，每项占满一行，不以裁出下一项代替重排。列表状态与选中边界独立。
- 右侧面板固定上限区域，标题与放大入口在上，内部滚动正文。状态标签靠左，启用开关在同一行右侧；操作分组在下一行。
- 放大移动同一面板到大档弹窗，关闭恢复草稿与阅读位置；不另外生成一份设置表单。
- 介绍和运行状态均为中档。运行状态含能力／依赖、服务、作业、独立对话、最近调用；这些只使用样本。
- 功能页有宿主渲染和 iframe 两种例子。宿主组件类型全部在组件库中展示；iframe 使用本目录本地示例。
- 请求页包含筛选、列表、选中、参与原因、材料与最终 JSON。选中详情与“空选择”是两个设计状态。
- 上传和更新只展示文件选择与反馈，不解压执行 ZIP；启用、加载中、收尾中、失败要保持操作的可用性与说明。

**制作入口：** `js/plugins.js` 的 `pluginsPane/detailPane/requestsPane`，`plugin-pages.js` 的宿主组件，`host-sdk.js` 的运行状态。设计预览的直接请求只进入 `N.previewFetch`。

## 设置 `page=settings`

`overview` 展示完整设置；`empty` 未配置；`error` 显示 MCP 连接错误。工具栏的“下次操作失败”用于检查保存失败时的布局。

- 界面设置包含速度五档、速度示例、昼夜分段切换、两主题色盘卡片，保持几何一致。
- 提供商列表有配置状态和编辑入口。中档表单包含名称、协议、Base URL、模型名／上下文／最大输出／图片支持、增删模型与 API Key。
- 每个模型和新增区使用一致分隔线与留白。手机模型名单独一行，两个数值字段对半，开关和删除另行排列。
- MCP 同时展示 stdio／HTTP、已连接／停用／错误、工具数、重连和编辑。系统服务用状态提示区分用户服务。
- 钩子为独立中档弹窗，含宿主与插件来源、订阅、可用性、开关和错误；权限分段控制与说明保持一组。
- 保存中禁用相应按钮，失败保留字段，成功提供简短反馈。预览中的地址不可用于真实连接，刷新即重置。

**制作入口：** `js/settings.js` 的 `renderSettings/renderProviderModels/openProvider/openMcp/openHooks`。动效、分隔线与字段尺寸的调整应同时检查桌面和手机。
