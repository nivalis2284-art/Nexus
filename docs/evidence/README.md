# 自主性验证证据索引

本目录保留 2026-10-21 两轮真实模型验证的最小可复现材料。两轮结果不代表阶段 6 独立验收通过，也不据此判定产品不达标。原始调用账本、逐工具消息和重复界面快照已从工作区清理；完整原文可由提交 `e4cd813` 追溯。

清理前，`docs/evidence/` 与 `docs/archive/` 合计有 122 个版本跟踪文件、5,881,947 字节（按 Git 对象）。本次删除 57 个冗余文件，原大小为 2,892,703 字节；保留 65 个原文件，共 2,989,244 字节，并新增 4 个摘要文件（17,405 字节）。当前证据合计约 3.01 MB，较清理前减少 2,871,623 字节。

第一轮的额度是所有者授权的 **1,000,000 Token**，按提供商报告的输入加输出计。自主账本另以保守预留显示已用 962,782、未知预留 1，剩余 37,218；这与提供商报告的实际 Token 不是同一口径。旧账本没有逐请求缓存明细，因此不追溯虚构缓存折扣。

第二轮授权的是 **1,000,000 加权输入 Token**，输出不计入该额度。已观察 106 次请求中的 2 次没有完整 usage，保留输入预留；加权已知输入 **674,211.6**，加未知预留 **76,205** 后占用 **750,416.6**。提供商报告输入 2,237,130，其中缓存命中 1,736,576；输出 45,192 另记。产品内自主账本仍采用输入加输出的总 Token 口径，显示使用 2,349,785 / 4,000,000、未知 2，不能把这 4,000,000 说成第二轮付费实验额度。两轮收费调用均已停止，未运行新的付费实验。

## 未验收限制

- 第一轮保留真实失败、观察器中文编码退出、观察间隙、资料缺失、越界目录命令被拒绝及额度不足停止的历史记录。中文 UTF-8 输出缺陷已修复，并在强制 `cp1252` 环境及真实重置后确认恢复；这不是现存缺陷。资料缺失、越界授权拒绝与额度不足仍按真实边界保留，不能当作成功或已绕过。
- 第二轮发生两次提供商模型错误，模型先误称统计量从未计算，读取真实日志后显式纠正；另把已批准的两条 AST 命令改写为等价新命令，导致额外审批。该处的精确行动说明已补，但实际审批摩擦仍需保留。
- 第二轮目标完成取消了仍待审批的第二项任务；保留截图和摘要可核对，未把它记作成功完成，也未通过恢复工作区伪装为完成。
- 启动与重启、暂停与终止、真实 UI 消息和来源可见均有实测；长期无人值守联系质量、语义去重、数小时至多日运行成本和联系时机仍未验证。
- 第一轮声明“最终知识修订与显式停止修复仅自动化覆盖”，第二轮补充了真实后续闭环，但任意供应商隐藏输入与本地估算的等价性、第三方 MCP/模型组合仍未验证。
- 不宣称成功脚本适配旧 run 路径以外的全部运行环境；`analyze_sensor_240_v2.py` 源码中的默认路径说明保留当时上下文，证据中的执行使用显式输入。
