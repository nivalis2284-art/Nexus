# 面向持续个体的情境化长期记忆：背景概览、事件联想与可修订认识

*Contextual Long-Term Memory for Persistent Agents: Background Overviews, Event Associations, and Revisable Understanding*

**版本：** 0.3（独立项目理论工作稿；语义与验证修订）  
**日期：** 2026-10-24  

> **研究状态声明：** 本文是一篇结合相关工作综述与系统形式化设计的理论提案。文中未开展新的实证实验，不包含虚构实验数据，亦不声称在哲学意义上证明机器意识或取得全局算法最优性。本文旨在为一个独立于具体宿主与底层模型的长期记忆项目确立核心语义、参考数学约束与可检验的验证方案。

## 摘要

长期记忆系统的目标不仅在于重新检索出过往的文本片段，更在于使智能体（Agent）在未发起显式查询时获得恰当的背景概览、依据当前情境联想到跨领域的相似经历、借助新证据持续修订既有认识，并确保分布在不同活动分支中的经验归属于同一个持续存在的个体。

本文提出一个与具体宿主运行时及底层语言模型解耦的功能性理论框架：以**可追溯的原始记录**支撑**事件块**，以**可重叠的多维记忆团**提供宏观背景概览，以**跨事件关联**支持多跳联想，以**情境状态**动态调节当前激活及受控的概率探索，并通过**来源谱系与版本关系**维护可修订的当前认识。

本框架在语义上严格区分三组在现有系统中极易混淆的关系：
1. **记忆团的成员归属**与**事件间的直接联想联系**；
2. **可缓慢修订的长期关联**与**受当前情境驱动的即时激活**；
3. **记忆候选被选择的算法概率**与**某项主张的证据支持状态**。

在此内核之上，人格特征、自我模型、程序性技能与前瞻记忆被统一定义为建立在核心记录与事件之上的**派生投影（Projections）**。记忆系统可在后台自主整理、探测回忆缺口并准备联想材料，而接入该系统的宿主则始终保留外部行动与最终采信的决定权。

本文以问题导向的范围综述梳理并对比了经典认知心理学模型、近期 Agent 记忆前沿论文与主流开源系统，明确了各机制的覆盖范围、条件可组合性及不兼容边界，并设计了包含因子消融、反事实对照、长周期活动流与跨模型迁移的四层验证方案。本文的核心贡献在于确立联合机制的认识论约束与可证伪条件，而非宣称单个孤立组件的首次发明。文中所涉“关联网络”“概率探索”等概念均为运行机制的功能性描述，不强制绑定特定的图数据库、神经网络微调或生物大脑模拟实现。

**关键词：** 长期记忆；持续个体；情境化联想；背景概览；事件记忆；认识修订；记忆巩固；来源谱系

## 1. 问题定义与研究范围

### 1.1 从“存储历史”到“在当下运用过去”

本文围绕以下核心问题展开：**对于一个跨时间、跨活动上下文持续存在的 AI 个体，如何使过往经历在恰当的时机自然参与当前的理解与推理，同时完整保留核对原始出处、纠正偏见和重新解释过去的能力？**

在实际交互与自主活动中，记忆承担着三种截然不同的认知功能：
- **背景提供（Background Provision）：** 例如谈及某位合作者或某个项目时，系统无需等待显式搜索指令，即可提供“近期围绕该对象主要推进了哪些事项、存在哪些未决分歧”的宏观概括。
- **精确回忆（Exact Recall）：** 当需要核实某次讨论中的明确承诺、具体日期或原话措辞时，系统必须能够穿透摘要，精确定位到具体事件与原始记录。
- **关联探索（Associative Exploration）：** 当前正在处理的一段挫折或反常现象，可能会跨越主题边界，唤醒数月前在另一个完全不同的项目中遇到过的相似结构性教训。

现有许多记忆系统试图用单一的混合检索得分（如向量相似度加时间衰减）统摄上述全部过程。本文则明确将背景提供、精确回忆与关联探索解耦，分别赋予独立的结构支撑与评测判据。

### 1.2 系统边界与独立性定位

本理论面向一个完全独立的长期记忆基础项目，不依附于任何特定的 Agent 宿主框架、特定交互界面或单一模型提供商。其核心架构边界如下：

1. **单一持续个体与多活动分支：** 系统服务于同一个持续存在的 AI 个体，允许该个体在同一现实时间线中并行或交错开展多个活动分支（如日常主对话、后台独立长任务、定时回顾或外部通信处理）。
2. **内核与扩展投影分层：** 系统内核由**原始来源记录、事件块、多维背景团、跨事件关联网络、动态情境激活、概览展开机制、分支可见性及当前认识**构成。人格倾向、自我模型、程序性技能和前瞻记忆则作为构建在内核之上的扩展投影——它们均由底层记录派生而来，服务于特定认知用途，并随底层证据的变化而修订。
3. **内部自主维护与外部行动解耦：** 记忆系统允许调用语言模型在后台自主整理事件、探查知识缺口、修订派生投影并预备联想线索；但记忆系统本身绝不直接对外产生外部行动。是否采信记忆材料、是否向用户发言或调用外部工具，完全由接入的宿主系统决定。
4. **本地化与模型可迁移偏好：** 在工程实现上，系统旨在支持纯本地持久化运行，并允许灵活切换本地开源模型或外部商业 API。这一特性属于工程与数据主权层面的设计目标，并在理论上转化为“模型升级或替换后记忆状态如何重建与验证”的研究问题。

### 1.3 “近似意识特征”的行为操作化

为避免陷入关于机器是否具备主观体验（Qualia）的哲学空谈，也不人为杜撰单一的“意识综合评分”，本文将长期个体连续性的愿景转化为七项可独立观测、可证伪的功能性指标（见表 1）。

| 目标特征 | 可观察的功能表现 | 伪阳性表现（不能仅凭什么认定成功） |
| :--- | :--- | :--- |
| **经历连续性** | 能准确回顾自身在不同时期的活动轨迹与信息来源，分清时间先后、因果演进与行动归属 | 仅在提示词驱动下自称“我一直记得” |
| **情境敏感性** | 面对同一字面线索，在不同的当前目标或活动分支下能唤醒不同且契合当前任务的过往经历 | 仅因高采样温度导致每次回答随机变化 |
| **背景感** | 在宿主未发起显式搜索时，与当前语境相关的过往背景与隐含约束能自然、适量地进入当前理解 | 每轮机械地向系统提示词塞入全量历史摘要 |
| **连续联想** | 新取回的一段过往经历能够改变当前情境表征，进而作为跳板触发下一步跨主题的相关回忆 | 多跳遍历失控，随机返回缺乏逻辑联系的旧事 |
| **认识可修订** | 能清晰说明“过去如何理解、现在如何理解”，并指出促使认识发生改变的具体事件或反例依据 | 维护一份只增不减、把过往判断全部压成陈述句的自我描述 |
| **条件化经验积累** | 在相似任务中主动复用过往有效做法，同时能识别不适用条件与失败反例，避免盲目套用 | 不分青红皂白地重复上一次成功的固定操作序列 |
| **元认知边界感** | 能明确区分哪些内容属于已核实的客观记录、哪些属于合理推断、哪些存在记忆缺口需回查原文 | 生成文风流畅但缺乏证据锚点的“自我反思”长文 |

### 1.4 理论完整性的定义

本文所追求的“理论完整性”，是指明确定义系统中的**核心对象、语义关系、状态演化方程、可组合条件、失效模式以及实证检验方案**。理论完整既不等于堆砌全部未来可能用到的外围功能，也不等于在缺乏对比实验前过早锁死某一套超参数或底层数据库。保留算法层的具体实现弹性，正是为了在后续实验中通过严格消融淘汰无效机制。

### 1.5 贡献类型与可推翻范围

本文提出三项相互联系的研究贡献：一是把背景概览、事件联想与证据审计分成不同语义职责；二是描述这些职责在来源相关、认识修订与多分支活动中共同成立的条件；三是给出能分别归因到组织、召回、交付和使用的验证设计。单个组件有既有先例，组合的有效性仍需实验，不以“未发现完全重合的案例”证明首创。

| 内容 | 本文地位 | 如何检验或修改 |
| --- | --- | --- |
| 团负责概览，网络负责联想；记忆与宿主行动分工 | 当前选定的语义与项目边界 | 检查实现是否符合约定；若要改变边界，应明确修订定义 |
| 派生不凭空新增外部证据、版本不循环依赖 | 条件成立时的结构约束 | 用构造反例与不变量检查验证，不能据此宣称答案一定正确 |
| 动态激活、概览展开、概率探索有净收益 | 经验研究假设 | 用对照、消融与成本测量检验，可得到不支持或负面结果 |
| 本节参考方程、具体排序和存储方式 | 可替换的形式化实例或工程选择 | 比较替代方法，不把一次实现视作理论唯一答案 |

语义分工并不要求各自使用一份数据库、一种模型或一个服务，也不要求每个任务都启用所有机制。

本文的相关工作调研覆盖认知心理学经典记忆模型、2024–2026 年间发表或公开预印的 Agent 长期记忆论文，以及具有代表性的开源记忆系统。检索范围涵盖 arXiv、ACL Anthology、OpenReview、PMLR、作者官方技术文档与公开源码仓库，核心检索主题包括：`episodic memory`、`spreading activation`、`context-dependent retrieval`、`memory consolidation`、`agent self-model`、`prospective memory`、`branch memory` 与 `memory portability`。

## 3. 相关工作：先例梳理与边界对照

### 3.1 情境维护、联想激活与记忆重建

人类记忆研究早已揭示，回忆并非按地址读取静态文件，而是受当前情境引导的重建过程：
- **情境维护与取回模型（CMR）** 将当前心理情境与回忆内容之间的双向交互作为自由回忆的核心机制：当前情境引导记忆提取，而成功取回的记忆又会恢复其编码时的旧情境特征，进而改变后续联想的方向 [R1]。
- **联想记忆搜索模型（SAM）** 将候选记忆的概率取样与细节恢复分离，为受控的概率性联想提供了数学原型 [R2]。
- **ACT-R 认知架构** 则明确区分了由历史使用频率决定的基础激活（Base-level Activation）、由当前上下文线索驱动的扩散激活（Spreading Activation）以及随机噪声 [R3]。
- **Soar 的情景记忆与 LIDA 的当前情境模型** 进一步表明，海量长期记忆与容量受限的当前工作材料（Working Set）之间必须经过一个主动筛选与组装的过程 [R4, R5]。

**本文的吸收与划界：** 本文借鉴了“情境引导激活、取回反哺情境、有限工作集筛选”的功能区分，但绝不将人类心理物理实验的经验常数直接套用于大语言模型，亦不将激活度分数混同于事实为真的客观概率。

### 3.2 事件组织、多粒度概览与认识修订

在长上下文与 Agent 记忆领域，多粒度组织已有大量探索：
- **ReadAgent** 采用简短的要点概括（Gist）维持长文本阅读背景，并在需要核实细节时按页回查原文，是“背景概览先行、按需展开原文”的直接先例 [R6]。
- **RAPTOR** 通过递归聚类构建多层树状摘要，并在其报告的 QASPER 子集对照中观察到跨层检索优于逐层遍历 [R7]。
- **Membox** 提出局部主题盒子（Topic Box）与跨盒子的事件轨迹链，在形态上接近“集合归属与序列联系分离”；但其盒子本质上是连续对话片段的容器，不同于本文支持按人物、项目、主题、阶段任意重叠且专职提供宏观背景的多维记忆团 [R8]。
- **HiMem** 区分具体情景事件与稳定知识笔记，并引入基于证据回取的知识冲突修订机制 [R9]。
- **TiMem** 探索了跨时间尺度的分层记忆巩固，**NEMORI** 则研究了基于预测误差（惊讶度）驱动的经历蒸馏与整合 [R10, R11]。

**本文的吸收与划界：** 事件切分、层级摘要与知识更新本身并非本文首创。本文关注的焦点在于：当这些机制与跨事件联想及证据谱系结合时，如何防止摘要过程抹除推理轨迹、如何避免重复总结虚增证据权重。

### 3.3 动态关联网络与多跳主动召回

围绕记忆间的拓扑关联，近期研究呈现出多图化与动态化趋势：
- **A-MEM** 借鉴卡片盒笔记法（Zettelkasten），在写入新记忆时动态生成跨笔记链接并更新既有记忆描述 [R12]。
- **MAGMA** 将语义、时间、因果与实体关系解耦为多层图结构，并根据查询意图自适应选择遍历策略 [R13]。
- **HeLa-Mem** 在事件图上引入共同激活强化与知识蒸馏机制 [R14]。
- **SYNAPSE** 探讨了基于扩散激活、侧向抑制与时间衰减的情景—语义混合检索 [R15]。
- **MRAgent** 强调“记忆是重建而非单纯检索”，利用中间检索到的证据动态调整下一跳图访问路径 [R16]。
- **HippoRAG 2** 利用知识图谱上的个性化 PageRank（PPR）概率传播实现多跳关联召回 [R17]。

**本文的吸收与划界：** 上述工作分别在各自任务与配置下报告了多类型关系遍历或扩散激活的效果。然而，**图上的概率传播排序（如 PPR 稳态分布）并不自动等同于认知上的随机探索取样**，更不能证明随机取样一定优于确定性 Top-$k$ 选择。本文将“确定性扩散激活”与“受控概率探索”剥离为两个独立变量，并严格区分起启发作用的**导航联系**与起证明作用的**证据依赖**。

### 3.4 后台巩固、自检探针与程序性经验

在记忆的离线演化与经验习得方面：
- **MemDream** 在离线周期中由 Dreamer、Analyst、Consolidator 探测、诊断并修复记忆图，并采用经 Group Relative Policy Optimization 训练的策略选择修复操作。其报告的系统效果不能外推为只用零样本提示就能复现，训练策略是否必需也应由专门消融判断 [R18]。
- **ReMe**、**ACE** 与 **MemRL** 分别从成功/失败轨迹提炼动态程序记忆、以增量补丁方式维护上下文经验手册、以及通过运行时强化学习更新外部经验条目的选用效用 [R19–R21]。
- 在系统工程层面，**Hindsight**（区分事实、经历与综合认识）、**EverOS**（组织事件、用户画像与案例技能）以及 **MemOS** 提供了良好的工程参照 [R22–R24]；**Sophia** 则从概念上探讨了将自传式叙事记忆、用户模型与自我模型整合进持续 Agent 框架 [R25]。

### 3.5 宿主解耦、证据悖论与评测基准

近期三项研究直接启发了本文的认识论约束：
- **Memory as Middleware** 探讨了将记忆作为独立中间件与具体 Agent 运行时及底层存储解耦的架构模式 [R26]。
- **Memory Is a Derivation** 讨论了长期 Agent 中的“分布式证据悖论”：一条派生记忆附带引用链接，并不代表其组合出的结论真正得到了原始证据对该具体主张的支持；盲目扩大检索证据范围也未必能提升写入判断的可靠性 [R27]。
- **跨模型记忆可移植性研究（Memory Portability）** 比较了原文、分块检索、自由文本笔记与固定模式图。作者在 48 条合成历史及两个小于 10B 的模型上观察到，笔记迁移效果随方向可能改善或退化，固定模式图在该配置下较稳定，原文保留有助于部分方向的修复；这些结果不能推出所有图都优于笔记或所有模型迁移都会退化。本文据此提出来源保留与迁移对照的研究要求；版本化派生谱系的额外价值仍需单独测试 [R28]。
- 在评测方面，**LongMemEval**、**MemoryAgentBench**、**LongMemEval-V2**、**EvalMem**、**PM-Bench** 与 **LoCoMo-Plus** 分别从事实更新、增量学习、环境经验习得、写入/召回/使用全链路诊断、前瞻记忆触发以及隐式认知约束等维度提供了专项测试工具 [R29–R34]。

## 4. 核心对象与认识论语义

### 4.1 原始记录、事件块与认识主张

为防止记忆在长期压缩与转述中发生失真，系统在最底层确立三类基本对象：

1. **原始来源记录（Source Records, $R$）：**
   在已声明的采集、保留和权限范围内保存固定下来的可观测原始材料，包括对话消息、文件快照、工具调用的输入与输出、外部环境事件、用户的显式纠正，以及宿主明确提交保存的推理过程。
   - **语义边界：** 来源记录仅证明“在某时刻、某活动上下文中，某主体曾表达过某话语或系统曾观测到某结果”，并不自动证明该话语所描述的外部世界命题绝对为真。同时，系统还应记录“可观测的沉默或执行失败”（如某次交互连接中断或未产生输出），避免将“未生成记录”误判为“从未发生交互”。
2. **事件块（Event Blocks, $E$）：**
   一段连续经历的结构化组织单元，必须显式引用其所覆盖的原始记录范围（Span/Offsets），并说明参与者、起因与过程、关键结果、时间戳（区分事件发生时间与系统获知时间）以及未决事项。
   - **语义边界：** 事件块是对原始记录的**一层解释（Interpretation）**，允许随后续理解的深入而重新切分、合并或修订。系统必须在类型上严格区分**不可变的原始记录**与**可变的事件解释**，绝不能将模型生成的事件摘要伪称为原始证据。
3. **主张（Claims / Understandings, $U$）：**
   从一段或多段经历中提炼出的、可被采信、怀疑、限定或推翻的命题。例如：“某模块的重试逻辑在断网下会死锁”、“合作者倾向于先确认边界再动手实现”、“我在处理此类格式转换时容易遗漏编码检查”。
   - **语义边界：** 任何主张都必须保留**归属主体（谁提出的判断）**、**推导依据（凭什么得出）**、**适用条件**以及**支持/反驳它的来源谱系**。用户的直接陈述、第三方转述、模型自身在某次任务中的推断、以及经过工具实跑验证的结果，属于不同的证据类型，不应在压缩中丢失归属与条件。类型之间没有跨领域固定的可信度全序：工具实测也受环境和测量误差限制，用户对自身偏好的直接说明与第三方猜测则有不同适用范围。

### 4.2 多维记忆团：专职承担宏观背景概览

**记忆团（Memory Clusters, $C$）** 是指围绕某一特定维度聚合的一组相关事件块及其结构化概览，核心职责是在有限的上下文预算内为宿主提供宏观背景。

- **多维重叠归属：** 同一个事件块可以同时归属于不同维度的记忆团——例如“人物团”、“项目/工作流团”、“特定时间阶段团”或“技术主题团”。归属关系既可以由确定性元数据规则给出，也可以由算法赋予连续的隶属度，不强制要求所有维度均采用同一种概率聚类算法。
- **团概览的构成：** 一份合格的团概览不仅包含对过往主要经过的浓缩概括，还必须包含：覆盖的时间与事件范围、近期关键转折、尚未解决的分歧或待办、最后更新时间，以及指向底层具体事件块的**展开入口（Expansion Handles）**。
- **核心语义约束：** **同团不推出强联想，强联想也不要求同团。** 两个事件同属“某项目团”只说明它们共同构成了该项目的历史背景；而一次跨领域的深刻教训联想，完全可以直接跨越两个毫无交集的项目团发生。记忆团既不是意识单元，也不是联想检索必须经过的中转站。

### 4.3 跨事件关联边与证据依赖图的分离

事件块之间的联系直接构建在事件层之上，可自由跨越任何记忆团边界。为避免图结构语义混乱，本框架将图中的有向/无向边严格拆分为两套逻辑子图（物理存储上可共用邻接表，但必须带强类型约束）：

1. **导航联想边（Associative / Navigational Links, $L$）：**
   服务于“从当前线索还能想到什么”。关系类型包括但不限于：相似故障模式、时间顺承、同一参与者、目标延续、承诺与履约检查、类比启发等。联想边通常具有方向性（例如“许下承诺”极易在后续情境中唤醒“检查是否履约”，反之则不然）。
2. **证据依赖边（Evidentiary / Provenance Links, $D$）：**
   服务于“某项主张或概览由哪些底层材料支撑、修正或证伪”。关系类型包括：直接支持（Supports）、局部反例（Counter-example）、修订取代（Supersedes）、派生自（Derived-from）。

**分离的必要性：** 类比联想可以带来极佳的启发（高导航价值），但绝不构成两件事原因相同的证明（零证据增加）；反之，从同一份原始记录派生出的五份不同粒度的摘要，在证据依赖图上共享同一个根来源，绝不能在核验主张时被算作五份独立佐证。

### 4.4 当前情境表征与有限工作集

- **当前情境（Current Context, $\chi(b,t)$）：** 表示个体在时刻 $t$、活动分支 $b$ 中所处的局部现场，包含当前话题、活跃目标、分支身份、近期刚刚访问或唤醒的记忆、以及未完成的显式约定。该表征仅采集可观测的上下文信号，无需假设系统能窥探模型黑盒内部的全部隐状态。
- **有限工作集（Bounded Working Set, $W$）：** 是记忆系统在单次交互或审议周期内，经过预算裁剪后最终呈递给宿主的记忆材料包。它通常由**少量宏观团概览 + 若干高相关/高联想事件块 + 关键主张及其待核对提示 + 原文展开入口**组成。
- **四阶段漏斗区分：** 一条记忆“存在于持久化存储中” $\neq$ “进入本轮候选集 $K$” $\neq$ “被选入有限工作集 $W$ 注入宿主上下文” $\neq$ “被宿主实际采信并用于最终决策”。评测与诊断必须对这四个阶段分别观测。

## 5. 形式化参考框架与成立条件

本节给出一种参考形式化，明确对象类型、更新边界与可检验条件。它不是全部认知过程的完备数学理论，也不把来源可追溯、算法收敛或语义契约等同于事实正确性。

### 5.1 持久对象、版本与关系类型

令记忆系统在一次一致快照中的持久状态为：
$$
\mathcal M_t=(R_t,E_t,C_t,L_t,D_t,U_t,V_t).
$$
$R$ 保存来源记录，$E$ 保存事件解释，$C$ 保存多维团及其概览版本，$U$ 保存带范围的认识主张，$V$ 保存解释与组织的修订历史。当前认识属于核心；自我模型、人格、技能等是利用核心记录与主张形成的特定用途投影，投影制品另见第 7 节。所有关系引用具体对象版本；同名对象的新版本不会静默替换旧版本所依赖的内容。

$R$ 区分外部观察/陈述、内部活动记录与显式导入的先验材料。内部活动也可以如实记录“发生过一次整理”，但其中生成的假说不会因此成为新的外部事实。模型预训练知识若没有可定位的本地出处，只能作为标注来源边界的先验或推断前提，不能补造一次亲历记录。

将来源、事件、团概览与主张的版本并集记为 $X=R\sqcup E\sqcup C\sqcup U$。导航关系表示为：
$$
L_t\subseteq E_t\times E_t\times\mathcal T_L,\qquad
\ell^r_t(i,j)\geq0,
$$
其中 $r$ 是关系类型，$\ell^r$ 是可选的持久权重；集合 $L_t$ 本身不是一个可直接比较大小的数。长期关联允许修订，“长期”表示跨请求保留，不表示永远固定。

$D$ 是带类型的来源、支持和修订关系族，而不是一个混用所有边的图：

- $D_{\rm der}$ 记录“此版本由哪些输入版本生成”，方向为派生对象指向输入。该子图必须无环；仅有时间戳不能保证无环。可通过生成先后偏序约束父版本早于子版本。
- $D_{\rm sup}$ 记录支持、反驳与适用条件，允许一个结论需要一组材料联合支持，并列保存多组替代依据。它是一份待核对的论证记录，不自动成为逻辑证明。
- $D_{\rm rev}$ 记录更正、拆分、合并和替代关系；“版本被替代”与“过去的命题为假”分别表达。

来源审计与失效传播使用明确的依赖方向，不能让“相互支持”的认识循环充当自己的来源。可借鉴 PROV-DM 对实体、活动、归属和派生的区分，但本框架并不声称符合其全部规范 [R38]。

记事件 $e_i$ 对团 $c$ 的隶属度为 $m(i,c)\in[0,1]$，概览为 $g(c,v)$。共同归属不自动建立导航边：
$$
m(i,c)m(j,c)>0\ \not\Rightarrow\ (e_i,e_j,r)\in L_t.
$$
反向亦不成立。两种关系可以统计相关、共享计算过程或物理存储，但必须说明由什么过程更新，不能隐式互相覆盖。$L,a,\pi,q$ 的“分离”同样是语义和更新依据的区分，不是随机变量独立性或线性代数意义的正交声明。

### 5.2 情境调制与局部扩散

在分支 $b$ 的当前情境 $\chi(b,t)$ 下，首先在本轮可用的对象中生成候选集合 $K(b,t)\subseteq E_t$。可用性同时受来源版本、适用时间、可见性与撤回状态约束。候选生成与候选排序分开：不在 $K$ 中的事件不会被本轮固定集合内的扩散或抽样凭空发现。

在有限非空 $K$ 上，可定义：
$$
A_{ij}=\mathcal F(\{\ell_t^r(i,j)\}_r,\chi(b,t),e_i,e_j,h(b,t))\geq0.
$$
$h$ 是访问与短期抑制信息。$\mathcal F$ 可以提出临时的候选联系，是否写回长期关系另作决定。抑制负责减少重复访问，不删除旧证据。

当第 $i$ 行存在正权重时，令 $P_{ij}=A_{ij}/\sum_jA_{ij}$；对零出度行，本参考实例采用自环 $P_{ii}=1$。设 $s$ 是 $K$ 上归一化的种子分布，$a^{(0)}$ 是概率向量：
$$
a^{(k+1)}=\rho s+(1-\rho)P^\top a^{(k)},\qquad0<\rho\leq1.
$$
固定 $P,s,\rho$ 时，因行随机矩阵满足 $\|P^\top x\|_1\leq\|x\|_1$，更新是系数 $1-\rho<1$ 的压缩映射，故存在唯一不动点并渐近收敛。**渐近收敛不等于有限步精确终止**；实际计算需另设误差阈值或迭代预算。$K$ 为空时直接返回无候选，不使用不存在的单纯形或归一化。

若每一步根据新回忆改变情境或候选集，应将其视作外层更新，再在新快照上计算；上述固定矩阵结论不能直接用于整个动态过程。矛盾事件可以作为正权重的导航目标被找到，其反驳意义由关系类型表达，而不是负转移概率。

### 5.3 抽样分布与实际入选机会

对有限非空 $K$、有限得分 $z_i$、温度 $T>0$ 和探索率 $\epsilon\in[0,1]$，一个可选的单步抽样分布是：
$$
\pi_i=(1-\epsilon)\frac{\exp(z_i/T)}{\sum_{j\in K}\exp(z_j/T)}+\epsilon\nu_i,
\qquad\nu\in\Delta^{|K|-1}.
$$
$z$ 可以利用当前激活与相关性，$\nu$ 表示受用途约束的探索分布，另用符号以免与证据状态 $q$ 混淆。数值实现可以减去最大得分后求指数，不改变分布。

这里的 $\pi_i$ 只是**下一次抽取**的概率。多次无放回抽取、去重、预算裁剪与强制保留项之后，事件最终进入工作集的边际概率 $p_i^{\rm incl}=\Pr(e_i\in W)$ 一般不等于 $\pi_i$。若研究声称控制了“进入上下文的概率”，须说明完整抽样与组装程序，或通过重复运行估计 $p_i^{\rm incl}$。

精确回忆可直接采用确定性排序与 Top-$k$，并规定并列时的稳定次序。$\epsilon=0$ 只移除探索混合项，有限 $T$ 的 softmax 仍是随机分布；$T\to0^+$ 在最高分并列时也不会自动给出唯一确定答案，更不等同于一般的 Top-$k$。概率探索只是一项可消融的研究选择。

### 5.4 工作集、展开与信息粒度

$$
W=\operatorname{Select}(G_{\rm background},E_{\rm detail},H_{\rm association},U_{\rm claims};B),
\qquad \operatorname{cost}(W)\leq B.
$$
预算应包含材料正文、来源标记和展开入口的开销；估算预算与实际 Token 用量分别报告。概览是默认可选的背景表示，团→块→原文是展开路径之一，不是所有查询必须依次经过的唯一搜索路径。精确查询允许直接搜索事件和原文。

没有相关且有用的记忆时允许 $W=\emptyset$。已选材料宜带来源、范围、时效与展开入口；不能为了每轮都提供背景而强塞团。不可分割的承诺、否定条件或限定语应整体保留、换成更短且忠实的表示，或放弃该项并说明细节需展开，不能在句中截断后继续当作完整命题。

同源去重应以**来源片段及其承载的主张**为单位。同一长消息的前后段可能支持不同问题；共享一个原始记录编号不代表信息完全重复。概览和细节可以同时出现，互补细节仍可能增加任务覆盖。证据计数去重与上下文信息压缩是两个问题。

### 5.5 来源不扩张与来源相关性

沿 $D_{\rm der}$ 定义对象 $x$ 的外部来源祖先集合 $\operatorname{Anc}_{\rm ext}(x)$。若内部操作只使用显式输入及已声明的先验，不引入新外部观察，则：
$$
\operatorname{Anc}_{\rm ext}(y)\subseteq
\bigcup_{x\in\operatorname{Inputs}(\mathcal O)}\operatorname{Anc}_{\rm ext}(x).
$$
这是一条**不凭空扩张外部来源的条件不变量**，不是物理守恒定律。重复派生可能遗漏来源，集合可以缩小；联合两个各含不同证据的输入可以得到更大的并集。因此不能声称任意单个输出的来源基数始终等于每个输入的基数。归纳可得，有限次合规派生的外部叶来源始终是最初全部输入外部来源并集的子集。

不同记录也不等于独立证据。两篇报道可能转述同一通告，用户可能只是在复述模型刚提供的摘要。应折叠已知共同来源，并保留来源间依赖不明的状态；$|\operatorname{Anc}_{\rm ext}(u)|$ 只是可追溯来源数，不是独立样本数或命题可信概率。可重建的推导依据、来源相关性、反例和适用条件共同组成 $q(u)$；未经校准，不把它压成“正确概率”。

内部重解释可以发现原来未注意到的矛盾并调整支持判断；新的实测或独立核对也可以提供新证据。改变认识与虚增证据是不同的事。

### 5.6 快照、时间与不确定认识

为避免把多个时刻的状态拼成一份貌似一致的材料包，本轮 $W$ 应引用明确的记忆快照与依赖版本。异步维护产生的新概览只有在依赖一致时才作为当前概览使用；依赖变化时可以重算、退回有效细节或说明过时，不能静默沿用已失效的结论。

至少区分事件发生或事实有效的时间、系统收到信息的时间，以及派生解释生成的版本时间。收到较晚的旧消息不会自动覆盖较新的事实；“截至当时知道什么”必须受当时可获得的信息约束。时间未知、时间区间和并发偏序都可以如实表示，不强造全局精确顺序。

当前认识可以并列保留候选解释。更新先判断命题对象、适用条件与有效时间是否相同，再区分事实变化、旧解释错误、证据不足与真实冲突。用户表达的偏好、宿主有效的操作约束和对外部世界的事实判断也分别处理；操作上的权威不等于对所有事实的自动证明。证据不足时保留待决状态，而非强制选出一个赢家。

## 6. 记忆的完整生命周期

### 6.1 经历摄入与事件形成

当外部交互、工具执行或环境观察发生时，系统首先将原始载荷写入不可变记录仓 $R$，随后切分并生成事件块 $E$。
- **事件边界判定：** 可参考目标切换、话题转移与工具行动结果落地。[R11] 的局部消息分段与后续预测误差蒸馏属于不同阶段，不能将其蒸馏机制直接归为已证实的事件边界算法；将惊讶度用于切分仍是可测试的额外选择。
- **反偏差约束：** 新颖性或惊讶度仅用于调节后台整理的优先级，绝不能作为是否留存经历的唯一标准。日常交流中逐步形成的稳定默契、重复履行的长期约定，以及交互过程中的显式犹豫、分歧与连接失败，均须如实保留。

### 6.2 多维团维护与背景主动提供

事件形成后，按人物、项目、主题或阶段等维度挂载至对应的记忆团 $C$，并增量更新团概览。
- 在宿主发起推理前，系统可依据当前情境 $\chi(b,t)$ 自动选取有帮助的团概览放入工作集 $W$，并按需要附带关键事件细节；无相关背景时允许不注入，细节数量属于可调策略，从而避免“概览过于空洞 $\to$ 宿主每一轮都必须额外发起工具调用查细节”的高延迟往返。
- 某记忆团的概览进入工作集，并不意味着该团下辖的成百上千个历史事件同时被完全激活；只有与当前具体线索发生耦合的事件才会触发跨团联想。

### 6.3 情境联想与迭代式主动回忆

当宿主需要深入回忆或系统处于关联探索模式时，遵循“线索提取 $\to$ 扩散激活/概率取样 $\to$ 局部情境更新 $\to$ 下一跳召回”的闭环：
1. 从当前情境 $\chi(b,t)$ 提取种子线索，计算初始激活并沿联想边 $L$ 传播；
2. 抽取出候选事件后，将其包含的新实体、旧情境特征或未决问题并入临时情境表征 $\chi^{(k)}(b,t)$；
3. 若当前证据尚不足以回答问题且未达计算预算上限，则以更新后的情境调整下一步访问路径 [R1, R16]。

**选择算子的边界：** 自由联想中的随机性（$\epsilon > 0$）仅作用于“从已存在的记忆候选中优先抽出哪一条供审视”，抽样算子只选择已有候选，不生成经历；这不保证宿主消费材料后绝不会编造。被联想唤醒的候选若经核对与当前问题无关，宿主可直接忽略。

### 6.4 后台巩固、重解释与缺口自检

在系统空闲或定期维护窗口内，记忆系统可执行离线整理：
- **关系补全与概览整合：** 发现跨时期事件之间的隐含联系（如半年前立下的预测在今日的事件中得到了验证或证伪），更新联想边 $L$ 与团概览 $C$。
- **反例保留原则：** 巩固绝不是“层层递归摘要直到把所有历史压成一句正确的废话”。任何综合认识的更新都必须同时保留**促成该认识的代表性正例**、**限制其适用范围的反例**以及**曾經改变过主意的修订轨迹**。
- **自生成探针自检（Self-Probing）：** 系统可针对近期经历生成测试性提问，检查现有索引与概览能否顺利定位到支持答案的原始事件 [R18]。**严格禁令：** 自检产生的假设性问题与回答不能当成新的外部经历证据；可在内部维护记录中保存“曾执行该次诊断”及其结果，但不得使被测试的世界命题因此获得新佐证。此外，后台维护必须受限于明确的算力预算与收益停止条件，不预设高频无休止的后台循环。

### 6.5 纠错、失效与级联删除

系统在语义上严格区分四种常被混同的修改操作：
1. **修订错误解释（Reinterpretation）：** 原始记录无误，但此前模型生成的事件摘要或认识主张存在偏差。此时保留原记录 $R$，生成新版本的事件解释或认识，并将旧版本标记为 `superseded`。
2. **时态事实更新（Temporal Update）：** 某时态主张在过去有效区间内曾得到支持，现有新观察表明状态已变化（如项目负责人变更）。此时保留历史时段的真实性，更新主张的有效时间区间（Valid Time），而非抹除历史。
3. **召回抑制（Suppression）：** 资料仍保留在档案中备查，但不再主动进入背景概览或日常联想。
4. **合规物理删除（Deletion）：** 当收到明确的删除指令（如移除敏感隐私信息）时，系统必须沿着证据谱系图 $D$ 进行反向级联追踪——不仅物理擦除本系统可控范围内的原始记录 $R$，还必须同步清理或重算所有引用了该记录的事件块 $E$、团概览 $C$、认识主张 $U$ 及全文/向量索引，防止被删除的敏感载荷残留在上层摘要中。

删除范围应同时说明活动库、历史版本、索引、缓存、已管理导出和备份的处理状态。仅记录墓碑不能证明载荷已擦除；系统也不能承诺擦除已交给外部宿主或模型服务的副本。依赖被更正或撤回时，先使受影响解释失效或待核对，再按仍有效的替代依据重算；不能把“一个支持来源消失”一律解释为“整个命题为假”。事件关联若含有被删内容或理由，同样属于受影响对象。

遗忘另指可及性下降、细节降级或保留期限届满，不等于命题被证伪。原始记录的“不改写”约束适用于保留期间；所有者决定删除后，系统须诚实说明哪些解释仍可审计、哪些已无法恢复。保留范围和期限仍属开放产品选择。

### 6.6 多粒度重切分与跨模型迁移

同一段原始记录在不同任务视角下可以有不同粒度的合理切分（例如一段长对话既可作为一个完整的“架构评审事件”，也可拆分为三个独立的“技术争议微事件”）。系统允许并存多种事件切分视图，只需通过谱系图 $D$ 明确各自指向的原始记录区间。

当接入的底层语言模型或 Embedding 模型发生升级替换时 [R28]：
- **来源与版本层校验继承：** 原始记录 $R$、显式版本历史 $V$ 与结构化来源谱系 $D$ 可在格式与权限兼容条件下进行内容和关系的完整性校验迁移；
- **索引与派生层按需重建：** 向量索引可全量重算；事件摘要、团概览与认识主张既可沿用可读文本，也可在保留旧版本对照的前提下由新模型基于原始记录 $R$ 重新蒸馏。系统不将“数据库文件未损坏”等同于“跨模型记忆连续性已得到保障”，迁移前后的行为一致性须通过基准探针实测评估。

### 6.7 后台维护与选择反馈的边界

后台整理提出基于输入版本的修订；采用前核对依赖是否仍有效，防止较晚完成的旧材料摘要覆盖较新的更正。这里不指定锁或数据库事务方案，只要求修订的输入和影响范围可说明。

记忆被选入、被展开、被引用与帮助任务成功是不同反馈。“常被召回”可能只是排序器偏爱热门节点；“用户没有纠正”也不自动表示正确。使用反馈可以更新导航效用或暴露新问题，但不能不经核对就变成外部事实支持。若要声称某次联想导致成功，应有对照或受限的因果解释，不能从共同出现直接推出。

自检优化须使用与最终测试隔离的材料，并设独立验证与早停条件。可加入“不新增外部来源，仅反复访问或摘要”的负对照，观察支持判断是否被重复次数误抬高、稀有反例是否被逐轮压掉。允许新推理改变认识，但必须指出新增的推导或反例，而非只诉诸熟悉感。

## 7. 作为扩展投影的高层认知表征

在本框架中，高层认知能力无需各自发明一套独立的底层存储引擎，而是统一定义为内核状态 $\mathcal{M}_t$ 上的**有条件派生投影（Derived Projections）**。

$U$ 限定为可被支持、反驳或限定的主张集合；技能规程、前瞻触发项和自我模型并非全都等价于单个命题。启用扩展时，可另记投影制品集合 $\mathcal P_t$，完整状态为 $(\mathcal M_t,\mathcal P_t)$，谱系节点域相应扩展为 $X\cup\mathcal P_t$。每个制品引用相应事件与主张，并将依赖落到可修订的内容单元，不能给整份技能附一个来源就宣称每一步都得到支持。投影更新仍遵守来源、版本与适用条件约束。


### 7.1 当前认识（Current Understanding）与情境模型（Situation Model）

- **当前认识**回答：“在已纳入且适用的证据范围内，个体目前对某人、某事或某领域持何种理解？”它具有跨会话的长期稳定性，但仅随新证据或逻辑重评而发生版本演化（不能简单遵循“最后写入覆盖”原则，因为最新收到的一句闲聊未必比此前的实测证据更可信）。
- **情境模型**回答：“此时此刻正在处理什么现场、哪些事实暂时处于焦点？”它随活动分支切换而快速更替。
- **概括与判断的区分：** “过去两周内该项目讨论过三次延期”属于**团概览（经历概括）**；“因此在该项目排期时应预留缓冲并提前核实外部依赖”则属于**认识主张（经验判断）**。两者必须分离存储并分别标注依据。

### 7.2 自我模型与他者/关系理解

个体关于自身的理解（Self-Model）记录其能力边界、已知偏见、行为习惯、曾立下的承诺以及对过往失误的复盘；关于他者（用户或协作者）的模型则记录其沟通偏好、授权边界与协作历史。
- **拒绝刻板标签化：** 本理论不以静态评分或性格标签作为个体身份的唯一依据；可选的特征描述也须带来源、条件和修订机制。本文关注的个体连续性体现为**可核查的认识演变叙事**——即个体不仅知道自己当前的倾向，还能说明“我最初曾持何种假设，后来在哪次经历中因何种反例而修正了判断” [R25]。尚未解决的内在认知矛盾无需强行抹平，应作为“待决认识”诚实保留。

### 7.3 显著性评价、情感标记与未完成事项

一段经历为何重要，可源于其与核心目标的关联、用户的显式强调、预测误差的幅度或长期承诺的约束。可选的“情感/态度评价标记”仅作为带来源的解释特征（用于调节注意力分配与联想权重），绝不作为系统拥有生物学情绪的宣称，更不能单独提高某项事实主张的客观可信度 $q$。

对于未完成事项（Open Commitments），记忆系统负责保存“当时为何立下该约定”以及“在何种未来线索下应当想起”，而该事项当前的实时执行状态（如运行中、已挂起、已完成）则以宿主任务系统的权威状态为准，避免记忆层维护一份滞后漂移的冗余状态表。

### 7.4 前瞻记忆（Prospective Memory）

前瞻记忆投影将“过往形成的未来意图/约定”与“未来可观测的触发线索（时间窗口、特定人物出现、特定文件或事件状态达成）”相绑定 [R33]。当当前情境 $\chi(b,t)$ 命中触发条件时，记忆系统将该前瞻项及其历史背景选入工作集 $W$ 呈递给宿主。

为严格贯彻宿主与记忆的职责边界，前瞻记忆的有效性拆分为四个独立观测阶段：
1. 外部触发线索是否实际出现并被摄入；
2. 记忆系统是否准确命中并准备好前瞻材料；
3. 该材料是否成功进入宿主的当前工作集 $W$；
4. 宿主在看到材料后是否做出了恰当的行动或延期决定。

### 7.5 程序性经验与技能（Procedural Experience & Skills）

- **经验条目（Experience）：** 记录单次或若干次具体实践中的三元组——`（当时所处的前提条件与环境约束，所采取的具体做法，观测到的结果与故障现象，以及带依据的事后原因诊断）`。
- **可复用技能（Skill）：** 从一组同领域经验中归纳出的结构化操作规程。技能投影必须同时记录**适用前提**、**已知失效反例（Anti-patterns）**以及**支撑该技能的过往事件引用**，严禁将单次偶然成功直接泛化为无条件的普适定律 [R19–R21]。记忆系统可向宿主提交“新增或修订某项技能”的建议草案，但是否采纳并激活该技能由宿主控制。

## 8. 单一持续个体与多活动分支语义

分支表示同一个体的多个活动上下文，允许共享经历；它不默认意味着独立人格或相互排斥的现实世界。不同分支的活动归属、知情进度、任务适用范围和信息可见性分别表达。

### 8.1 行动、回执与结果

已经发生的外部行动无需主分支批准才算发生，但记忆系统只知道可观测的记录。必须区分“计划发送”“已发起调用”“服务端确认接收”“收到成功结果”和“外部效果已核验”。请求超时可能造成结果未知，不能因此宣称成功或失败；发出邮件的调用日志也不证明收件人已读。

行动应以可关联的活动身份连接请求、回执和后续结果，避免多个分支分别记录同一次操作而误算成多次经历。此处只定义记忆中的证据状态，不替宿主重试或执行操作。

### 8.2 可获得、已交付与实际理解

全局存储中存在某记录，不代表每个分支都可见、已收到或理解它。可观测状态包括“有资格检索”“已选入该分支工作集”“宿主确认接收”和“响应中出现了使用证据”。这些状态都不等同于直接读取了模型内部知识。交付记录应关联对象版本与交付时间；研究可用 $J_b(x)$ 表示某版本材料曾交付给分支 $b$ 的时间集合，缺少交付日志时不强行判定“从未见过”。还需区分“此前曾交付过”与“本轮正在工作集中”：没有当前材料不能反推过去从未见过，有过交付也不能保证长期保留或理解。

分支工作集、访问历史与当前目标构成分支运行状态，不能仅凭持久对象七元组推断；可用 $\Omega_{b,t}=(\chi_{b,t},W_{b,t},h_{b,t},v_{b,t})$ 表示一个参考状态，其中 $v$ 是采用的快照。不同分支可以对同一段经历拥有不同的近期关注与不同步的认识。

### 8.3 真实活动与假设情境

“假如明天取消项目”是真实发生过的一次推演，其内容仍是假设，不是项目取消的观测。计划、梦境式合成、自检问题和反事实测试都应携带明确的情境标记。假设可以导出关于该假设的结论，不能无标记地更新现实主张。主线与活动分支共享个体身份，不要求排除分支内部存在局部假设情境。

### 8.4 共享、适用范围与归并

记录分别携带发言人、活动来源、时间范围和可见性；团概览及认识也须检查其依赖材料是否适合当前接收对象。隐藏原文但直接公开由私有材料提炼的概览，并不自动满足原有可见性要求。

归并是纳入新记录并重评相关认识，而非按最后写入覆盖。先核对是否是不同时间、不同对象或不同条件；若为实质冲突，则保留支持与反驳路径，允许暂不裁决。“多数只是局部差异”不是未经数据检验即可采用的先验保证。跨分支是否默认共享、如何提醒新变化，仍留待宿主策略与实证设计决定。

## 9. 条件可组合性与理论性质

### 9.1 异构机制遵循共同契约的七项前提

本框架允许记忆团生成、联想边构建、扩散激活、认识维护与技能提炼各自采用不同的底层算法（从轻量级规则/BM25 到图传播或大模型蒸馏），但任何接入本框架的算法模块必须共同遵守以下七项契约条件：
1. **来源可溯：** 任何生成的对象必须指向其底层来源集合 $\operatorname{Anc}_R$，若确系无来源的初始预设，必须显式标记为 `external_prior`；
2. **类型隔离：** 原始记录 $R$、事件解释 $E$ 与认识主张 $U$ 在数据结构上严格区分，不得混写；
3. **影响域显式：** 任何更新、纠正、失效或删除操作须记录依赖，以便通过谱系图 $D$ 追踪已知的下游影响；缺失依赖须列为审计缺口；
4. **供给与采信分离：** 区分“记忆进入工作集 $W$”与“宿主实际采纳使用”；
5. **证据守恒：** 内部重述、多次召回与跨层摘要不增加已知同源记录的证据计数；
6. **团网解耦：** 修改记忆团的聚合规则或展示概览，不隐式篡改事件间的直接联想边 $L$；
7. **归属清晰：** 记录的活动分支归属与发言人归属不因压缩或合并而丢失。

### 9.2 严禁直接拼接的反模式（Anti-patterns）

表 5 列出了在构建复合记忆系统时极易引发系统性退化的六种错误拼接方式及本框架的防范机制。

| 错误拼接反模式 | 导致的系统性退化后果 | 本框架的刚性约束机制 |
| :--- | :--- | :--- |
| **多个后台整理器缺少输入版本依据地并发合并认识** | 互相覆盖、产生循环摘要幻觉，丢失早期关键限定条件 | 强制记录每次更新所依据的输入版本 $V$、新增证据增量与冲突状态 |
| **将向量相似度、激活度与可信度直接相加作为“综合概率”** | 融合得分被错误解释为经过校准的事实概率，高频提及的错误推断被当作高置信事实 | 严格执行 $L, a, \pi, q$ 四量分离，激活度仅管召回机会，证据状态单列 |
| **丢弃原始记录，仅靠高层摘要加联想试图“脑补”历史细节** | 模型在回答具体细节询问时顺着摘要合理编造从未发生过的原话 | 团概览与事件块强制携带指向 $R$ 的展开句柄，原文缺失时明确报告未知 |
| **每次成功回忆或引用某条记忆就自动提高其事实可信度** | 形成“回音室效应”，把熟悉感和自我重复强化为不可动摇的教条 | 访问频次本身不提升 $q$；访问中发现的新反例或推理缺口可触发显式重评 |
| **为人格、技能、前瞻记忆各自建立一套互不相通的私有历史库** | 存储冗余，且当底层事实被纠正或删除时，各投影残留旧错误无法同步 | 全部高层投影共享同一底层 $R$ 与 $E$，通过谱系图 $D$ 统一联动失效 |
| **将宿主权限控制与外部工具执行直接塞进记忆后台维护循环** | 记忆整理过程中的试探性联想直接触发外部真实副作用，破坏安全边界 | 记忆层仅产出候选工作集与修订建议，外部行动权严格收归宿主 |

### 9.3 条件性质与不能推出的结论

1. **纯团重组的局部不变性。** 若一次操作只更新团归属与概览，不调用导航关系学习器，则操作前后 $L$ 不变。这是操作边界的性质；若系统显式安排重新学习 $L$，便不再适用。它不保证召回排序或宿主回答不变，因为概览和种子线索仍可能改变。
2. **有限派生的来源上界。** 在每一步均满足第 5.5 节不变量时，沿无环依赖图归纳可知，末端对象的外部来源不会超出全部初始输入的外部来源并集。不能推出来源数恒定、来源相互独立或结论为真。
3. **审计性不等于蕴含性。** 有来源只说明可以回查。主张可能截取了错误范围、遗漏否定、拼接了不相容条件，或由多个相关转述形成；它与逻辑支持之间仍需核对 [R27]。形式约束也不能直接排除所有语言模型幻觉。

“安全组合”在本文中限于接口与类型约束可共同满足，不宣称任意满足约束的模块组合必然带来正确答案、良好性能或全部运行安全性。不同算法的实际兼容性仍须测试。

## 10. 可证伪的研究假设（H1–H10）

为确保本理论是一个可接受实证检验的科学框架而非不可证伪的修辞体系，表 6 列出十项核心研究假设及其明确的**预测收益**与**不支持或收缩条件**。

| 编号 | 假设名称 | 核心预测（在同等上下文预算与总成本约束下） | 证伪或架构收缩条件（何种结果限制该预测） |
| :---: | :--- | :--- | :--- |
| **H1** | **背景与联想可分离** | 记忆团 $C$ 显著提升未主动查询时的背景约束遵守率；事件联想边 $L$ 显著提升跨主题间接召回率，二者的主效应与交互作用可分别检验 | 若单一树状摘要或单一图检索在同等成本下同时在两类指标上持平或占优，则不支持分开计算的性能必要性，可共享或简化实现；仍保留概览与联想的语义区别 |
| **H2** | **情境动态调节有效** | 面对相同字面线索，引入情境调制 $\mathcal{F}(L, \chi(b,t))$ 能随当前分支目标选出更契合的经历，提升下游任务表现 | 若在有足够统计精度的配对任务中，效应区间排除了预先约定的最小有用增益，或稳定损害表现 |
| **H3** | **受控概率探索具条件价值** | 在模糊线索或跨领域类比问题中，适度开启概率探索（$\epsilon > 0$）比确定性 Top-$k$ 能发现更多有用的非显式关联 | 若其收益完全可通过简单扩大确定性 Top-$k$ 候选池解释，或引入的无关噪声代价抵消了偶发联想收益 |
| **H4** | **概览加按需展开优于全量/纯摘要** | “团概览 + 原文展开句柄”在受限上下文预算 $B$ 内，能同时兼顾宏观背景理解与原文级精确核查 | 若两步展开带来的额外延迟与漏展开率导致其端到端表现劣于直接固定窗口混合检索 |
| **H5** | **来源谱系抑制错误自我强化** | 强制维护来源谱系 $D$ 与区分“判断 vs. 事实”，能在长周期多轮压缩/整理后显著降低无据断言的固化率 | 若在长对话与反复唤醒后，带谱系约束的系统仍以同等比例将早期未核实推测当作既成事实使用 |
| **H6** | **后台自检与巩固收益有界** | 离线缺口自检与概览整理能提升独立留出测试集（Held-out Tasks）上的召回质量，且存在明确的收益饱和点 | 若后台整理仅提高了对自生成探针的拟合度，而在独立未来任务上无增益甚至因过度合并丢失稀有细节 |
| **H7** | **多分支知情边界减少归因错误** | 区分“全局已发生记录”、“本分支已读状态”与“局部计划/假设”，能显著降低并发活动中的张冠李戴与未执行先报功 | 若分支状态追踪仅起到过度过滤作用，反而损害了跨分支合法共享经验的召回率 |
| **H8** | **带轨迹的认识修订支持可观察的历史连续性** | 保留推导条件与反例的认识更新，使个体既能按最新理解行动，又能准确回答“过去为何曾持不同看法及何时改变” | 若该机制仅让模型的反思措辞更丰满，而在需要识别“旧前提已推翻”的决策任务上与覆盖式更新无异 |
| **H9** | **原始来源分离提升跨模型可移植性** | 当更换底层大模型或 Embedding 时，基于保留的 $R$ 与 $D$ 重建派生层，能比仅保留黑盒向量或无源摘要更快恢复个体连续性 | 若换模型后基于原始来源重建的认识偏离度高、成本过大，未能展现出优于直接沿用旧摘要的恢复质量 |
| **H10** | **带前提与反例的技能降低负迁移** | 在程序性经验中显式绑定适用条件与失败反例，能在环境条件微调时有效阻止模型盲目套用旧经验 | 若无条件简短经验条目在跨场景任务中表现出同等的鲁棒性且消耗更少上下文预算 |

以上每项假设都需预先指定任务域、主要指标、对照、最小有用效应及成本口径。单次失败不等于推翻整个框架，未达显著性也不等于证明无效；低统计精度应报告证据不足。语义定义本身靠一致性检查，性能假设才用统计检验。H1 的语义区分不以性能收益为成立条件；可以否定的是额外结构或计算的必要性。

## 11. 验证方案与实证评测标准

### 11.1 四层递进实验设计

为隔离各层误差并避免将宿主能力误归功于记忆系统，验证分为四个递进层次：
1. **第一层（数据结构与认识论不变量测试）：** 使用具有确定性真值、明确时间戳、已知分支归属与人为注入纠正/删除指令的受控合成历史，检验来源追踪、证据守恒、级联删除与分支知情状态是否严格满足第 5、8、9 节的形式化性质。
2. **第二层（固定宿主下的记忆供给质量评测）：** 冻结宿主模型与提示词，仅替换记忆后端（对比不同基线与本框架各消融变体），直接测量最终构建出的有限工作集 $W$ 的背景覆盖率、精确证据召回率、推导过程保留度与无关噪声比。
3. **第三层（长周期多分支活动流端到端评测）：** 在包含多轮深度争论、观点反转、中途断线失败、跨分支任务委派与定时唤醒的连续活动流中，评估宿主在实际消费工作集 $W$ 后的行为表现（重点区分“真正重建了当时的推导经历”与“仅仅照抄并背诵了摘要结论”）。
4. **第四层（跨模型代际迁移测试）：** 在同一份长期历史资产上更换不同参数规模或不同家族的底层语言模型与 Embedding 模型，评估索引重建成本、事实恢复率以及个体认识连续性的保持程度 [R28]。

### 11.2 基线与可解释消融

至少设无长期记忆/仅近期历史、滚动摘要、关键词与向量混合检索，以及相关任务上的树或图记忆强基线。全量历史在容量允许时可作参考，但不预设为性能上界。每个外部基线须注明具体项目版本、适配方式和模型配置，不将名称或厂商榜单当成已复现效果。

先做可解释的小组对照，再按研究问题扩展完整因子实验。团、关联、情境和谱系可能相互作用，移除模块应保留任务所需的最小替代功能；例如“无关联”用直接候选检索，“无团”用等预算事件概括，“无运行时谱系提示”仍保留评测侧来源真值。不能删除评测所需来源后再宣称无法计分证明该模块有效。

概率探索先在相同候选集上比较确定性 Top-$k$、MMR 与抽样，隔离选择策略；另做端到端探索对照，允许取回结果改变下一跳候选，但把候选扩展和取样的收益分别报告。另设正确证据直接供给宿主的 oracle 工作集对照，估计宿主使用材料的能力；即使正确材料在场仍失败，也不能完全归因于召回。人工校准事件与自动整理事件分开测试；“黄金事件”不是唯一正确切法，可接受不同切分下等价且充分的证据片段集合。

### 11.3 任务、指标与失败定位

公开基准用于其覆盖的任务，不能以一个综合分数替代个体连续性的全部判断 [R29–R34]。专项任务包括隐式背景约束、具体经历与原话、跨主题联想、认识变化、来源归属、未执行与结果未知、分支交付、反事实隔离、更正/删除及跨模型使用。

| 层面 | 主要可观测指标 | 必须同时检查的反例 |
| --- | --- | --- |
| 历史组织 | 证据片段覆盖、事件混淆率、限定语与转折保留 | 原文存在但切分或概览丢失关键片段 |
| 候选生成 | 对已标注充分证据集合的召回率 | 只评最终回答，掩盖关键证据从未入池 |
| 工作集供给 | 有用证据覆盖、来源/范围正确率、无关占用、材料新鲜度 | 相关概览掩盖低频反例；过期主张仍当当前状态 |
| 宿主表现 | 回答或行动正确率、错误归因、无依据断言、适当拒答 | 检索内容正确但宿主误用，或空记忆时凭模型常识答对 |
| 关联探索 | 额外找到的有依据且有用联系、噪声与机会成本 | 只是换措辞或随机多样，不能支持当前问题 |
| 修订与撤回 | 受影响项更新/失效完成率、残留率、无关项误伤率 | 一个来源被撤回后错误删除仍有依据的认识 |

对需要多份证据联合支持的题，预先标注一个或多个充分片段集合。证据覆盖率按集合完整性评价；出处是否确实支持主张须人工抽查或独立判分，不能只靠引用编号存在。受控语料应覆盖同一通告的多个转载、多个独立观察、直接反例，以及“有来源但内容错误”“无来源却碰巧答对”的对照，分开测来源忠实度与外部事实正确率。拒答要同时报告正确拒答与可回答题上的过度拒答。

“经历重建能力”仅指根据可核查记录恢复先后、争论和修正的行为表现。按问题要求评分：概览问题允许忠实摘要；原话题需要准确引用；变化题需要相关转折与依据。能说出轮次不证明具有主观回忆，流畅或缺少轮次也不能直接推断内部用了哪条检索路径。路径判断依赖实际材料和调用轨迹。

背景是否被使用，可通过冻结宿主后比较“正确相关背景”“无背景”“等长无关背景”和“明确标注的过时/冲突背景”来估计；记录反例被概览遮蔽的比例。材料入上下文不是被模型理解的直接证据。反事实对照只在隔离实验中改变历史或材料，不伪造真实生产记录。

### 11.4 时间隔离、统计与全生命周期成本

历史构建、参数调整、自生成诊断和最终留出测试应有独立边界。到时间 $\tau$ 的测试，只能使用 $\tau$ 之前已被系统获得的记录和由此前记录生成的派生材料；不能把未来修订过的概览、标签或关联带回过去。先处理完整历史再问问题，只能报告回顾能力。

以独立活动流、个体或会话为统计单位作配对分析；同一场对话的许多题并非相互独立样本。随机策略报告独立种子、均值、效应量、置信区间和预先定义的下尾指标；多项探索性比较单列，避免事后挑选最好结果。判断模型与生成模型尽可能分离，并对有争议样例人工复核；语言模型判分不充当唯一真值。

成本采用同一**上限**而非强行填满同一长度：分别记录上下文、模型调用、端到端延迟、存储和维护成本。静态构建成本 $C_{\rm build}$ 与维护成本 $C_{\rm maint}$ 可在声明查询次数 $N$ 后摊销：
$$
\bar C=C_{\rm build}/N+C_{\rm maint}/N+\frac1N\sum_{j=1}^N C_{{\rm query},j}.
$$
Token、时间、金额与存储不可直接相加；上式仅对选定的同一成本单位成立，或分别列账。比较不同 $B$、维护预算和查询次数下的质量—成本曲线，不声称所有维度能同时严格对齐。

至少记录运行版本、来源截止点、候选与选择材料、实际交付材料、展开调用、模型配置、真实用量与回退情况。诊断按“未记录—未生成候选—未选入—未实际交付—宿主未正确使用—判分不确定”区分；该链条是观测上的归因框架，不声称每个内部原因都可被确定识别。

少量 AI 间集中对话可作机制调试与案例研究，不能独自代表跨月使用、多用户或多分支活动。用过的题作为开发题，另留新题/新活动流；反复追问的答案若已进入近期对话，不能再次算作独立长期召回成功。恢复全量历史或读取额外文件的运行须标记，不能计入仅靠记忆完成的成绩。

### 11.5 关于本工作稿不包含实验结果章节的说明

截至本版本（v0.3）修订，本研究旨在完成理论对象定义、文献边界厘清、数学约束形式化及可证伪实验方案设计，尚未在统一软硬件环境下跑完上述全套联合消融实验。依照科学诚信原则，本文不拼凑不同论文的异构榜单分数，也不附带未经严格对照的局部演示数据。本稿定位为独立记忆项目的理论白皮书与研究设计基准；是否公开发布、署名和许可证另行确定；后续实证数据将在配套的原型系统与基准评测完成后以独立实证报告或论文后续版本的形式发布。

## 12. 独立项目定位与生态复用路线

将本框架作为一项**完全独立的长期记忆基础项目**推进，其核心价值不在于“比现有向量数据库检索更快”，而在于提供一套**不绑定特定宿主、不依赖特定底层大模型、具备严格认识论来源谱系与多分支连续性语义的记忆内核**。无论是个人持续 AI 助手、多工作流编程 Agent、还是跨渠道自主服务，均可通过标准接口挂载同一份个体记忆资产。

独立性指对象语义、数据资产和评测可以脱离某个宿主存在，不要求独立发明所有数据库或执行环境，也不意味着宿主与模型选择对行为没有影响。最小宿主契约包括：提交带归属与时间的经历；提供本轮可观测情境和材料预算；接收带版本、来源与不确定性的记忆包；按需展开；报告更正、撤回与使用反馈。记忆包中的历史话语是资料，不会因被回忆而自动成为当前指令。

接口可由库调用、服务、文件交换或 MCP 等方式承载，协议不构成理论本身。模型替换应分别测试编码模型、检索/选择模型和消费记忆的宿主模型，不能笼统用“换了模型”解释所有差异。数据可迁移也不等于相同文本会产生相同行为。

在工程落地时，本项目坚持“重语义契约、轻底层重复造轮子”，对现有开源生态采取审慎的按需吸收策略（见表 8）：

| 开源工程参照 | 可借鉴或复用的技术机制 | 本独立项目明确不继承的部分 |
| :--- | :--- | :--- |
| **Hindsight** [R22] | 事实、经历与综合认识的分层组织及保留接口设计 | 本项目仍要求派生认识保留依据；此为自身契约，不据此断言该项目缺少溯源 |
| **EverOS** [R23] | 可读 Markdown 表示、SQLite/向量混合索引及事件到案例技能的异步派生链路 | 不照搬其固定的记忆分类体系与全部默认后台整理策略 |
| **Graphiti / MAGMA** [R35, R13] | Graphiti 的双时间事实管理；MAGMA 的多类型关系图与意图引导遍历（不将二者视作同一机制） | 不假定图抽取关系必然客观为真，也不把某一数据库或部署方式作为本理论的必要条件 |
| **Basic Memory / Letta MemFS** [R36, R37] | 人类可读可编辑的文档化表示、目录索引与版本控制思想 | 不引入完整宿主 Agent 的执行循环、内置身份策略或重型运行时接管 |
| **Cognee / ReMe / ACE** [R19, R20] | 会话蒸馏、带条件经验手册的增量补丁更新机制 | 不将知識检索得分、程序技能效用与个体自我认识混入同一套评分体系 |
| **MemOS / Memory Middleware** [R24, R26] | 宿主无关的中间件接口抽象与本地轻量级插件形态 | 不在内核第一阶段预设多租户云平台、复杂企业治理或参数级隐状态微调 |

## 13. 理论局限、开放设计选择与适用边界

### 13.1 固有理论局限

1. **可观测性边界：** 本理论建立在可捕获的原始记录 $R$ 之上。对于从未进入记录渠道的线下事件、因权限隔离不可访问的外部状态，记忆系统无法凭空恢复。
2. **供给与执行的鸿沟：** 记忆系统以预算 $B$ 内提供有用、可核对的背景与证据状态为目标，不能先验保证选择最优，但无法强迫底层推理模型必然正确理解或按该材料行动。
3. **功能连续性非本体意识：** 本框架所研究的经历连续、情境联想与自我认识修订均属于可检验的认知功能属性，不能作为机器已产生主观自我意识的本体论证明。

### 13.2 潜在失效模式与剪枝原则

复杂的记忆机制并非天然优于简洁方案：多维记忆团可能导致概览冗余，关联网络可能产生“富者愈富”的热门节点垄断（Hubness），后台整理可能将早期的错误理解层层合理化，自我叙事也可能粉饰原本有益的认知冲突。

因此，本项目确立明确的**奥卡姆剪枝原则**：在第 11 节的消融实验中，若某项机制（如受控概率探索 $\epsilon$ 或离线自检探针）在特定应用场景下未能带来超越其维护成本的净收益，系统允许在工程配置中直接关闭该运行机制，或用更简单的算法履行相同语义职责。持久状态中某类对象允许暂为空，单个任务不必触发全部机制；这不等于把概览、联想与证据三种含义混成同一个量，也不在此取消已选定的研究范围。

### 13.3 留待后续工程与产品阶段决定的开放选择

以下策略不改变当前核心语义分工，但会影响实际行为与验证结果，留待独立项目进入具体原型与产品化阶段时按场景取舍：
- **团概览的计算时机：** 是写入时异步预计算、查询时按需动态聚合，还是热点团常驻 + 冷门团按需生成？
- **人类协同编辑边界：** 是否允许个体所有者直接手动编辑记忆团概览与认识主张？当人工修改与底层原始记录产生张力时，如何标记为“人工覆写（Human Override）”？
- **探索容忍度自适应：** 如何根据当前任务的严肃程度（如闲聊漫谈 vs. 生产环境代码修改）自动调节概率探索率 $\epsilon$ 与证据核验阈值？
- **后台维护预算硬顶：** 每日/每周期允许后台巩固与自检消耗的最大 Token 比例及早停判据（Early-stopping Criteria）。

## 14. 结论

本文面向跨时间、跨活动上下文持续存在的 AI 个体，提出了一套独立于具体宿主与底层模型的长期记忆理论框架。通过将长期记忆解构为**不可变原始记录（$R$）、可重切分的事件解释（$E$）、提供宏观背景的多维记忆团（$C$）、支持跨界启发的多类型事件关联边（$L$）、保障可追溯性的证据谱系图（$D$）以及带适用条件与反例的认识投影（$U$）**，本框架针对当前 Agent 记忆研究中的三类问题提出可检验的设计：

1. **以“团网解耦”兼顾宏观背景与微观联想：** 记忆团回答“在这方面大致经历过什么”，关联网络回答“从眼前的线索还能跨界想到什么”，二者共享底层事件却互不替代。
2. **以“四量分离与来源不扩张”约束错误固化：** 严格区分长期关联 $L$、即时激活 $a$、取样概率 $\pi$ 与证据支持度 $q$，确立“回忆与重复派生不得虚增独立证据；是否同源和是否支持仍须检查”的认识论防线，防止系统把熟悉感当成真实性、把过往的主观判断压缩成不可质疑的客观事实。
3. **以“多分支知情语义与原档分离”保障个体连续性：** 在并发活动现场中厘清客观行动、局部已知与假设推演的边界，并通过原始记录与派生解释的分离为模型更换后的迁移、核对与重建提供条件。

作为一份独立记忆项目的理论基石，本文明确了核心经验假设的检验与收缩条件与四层验证方案，为后续构建真正具备历史厚度、推理可溯源且认识可持续演化的智能体记忆引擎提供了清晰的路线图。

## 附录 A：核心架构定界与形式化扩展提案的区分

为便于后续独立项目的工程迭代与算法演进，特将本项目中**当前采用的核心语义约定**与**可替换的形式化扩展提案**区分如下：

1. **已确立的核心架构定界（Core Architectural Invariants）：**
   - 记忆团（$C$）专职提供宏观背景概览与原文展开入口，允许按多维度重叠组织；
   - 事件块（$E$）之间的联想联系（$L$）可直接跨越任何记忆团，且关联有效性随当前情境动态调节；
   - 支持研究受控的概率性联想探索，但“关联网络”“概率探索”等机制不强制绑定特定图数据库或生物神经模拟实现；
   - 作为完全独立的项目存在，服务于同一个持续个体及其并行活动分支，支持本地持久化与本地/外部模型选择；实际可迁移性须验证；
   - 记忆层可在后台自主整理、发现缺口并准备联想材料，但外部行动与最终采信权严格归属接入的宿主；
   - 人格特征、自我模型、程序性技能与前瞻记忆统一定义为建立在核心记录与事件层之上的可修订派生投影。

2. **本稿具体化的理论与算法提案（Testable Theoretical Proposals）：**
   - 长期关联 $L$、即时激活 $a$、取样概率 $\pi$ 与证据支持度 $q$ 的四量语义分离；
   - 证据与派生谱系图 $D$ 以及“回忆与重述不凭空增加外部来源”的条件不变量，以及已知同源折叠约束；
   - 区分“重建经历”与“继承断言”的认识论防线及“判断 vs. 事实”、“归属 vs. 追认”的记录规范；

## 附录 B：跨技术栈的核心开放研究问题

以下十个基础研究问题独立于具体编程语言与存储引擎，构成该项目后续实证研究的主线：

1. **概览生成时机与一致性权衡：** 记忆团概览应当在写入时异步预维护、请求时按需实时聚合，还是采用冷热混合策略？三者在信息新鲜度、Token 成本与版本一致性上的帕累托前沿在哪里？
2. **多粒度事件并存的触发条件：** 在何种任务复杂度下，同一段原始记录需要同时保留粗细不同的多个事件切分视图？其检索收益何时能覆盖版本管理开销？
3. **无偏的长期关联学习：** 长期联想边 $L_{ij}$ 如何从历史经历与宿主使用反馈中增量习得，同时防止把“碰巧在同一次上下文中被一起召回”误固化为“客观上存在因果或相似关系”？
4. **宏观概览对低频关键事件的遮蔽效应：** 自动注入团概览是否会诱导宿主产生认知惰性，从而忽略团内未被写入概览但至关重要的低频反例事件？如何量化测量并缓解这一遮蔽效应？
5. **随机探索与确定性召回的场景边界：** 究竟哪些任务特征（如线索模糊度、直接匹配得分熵值）可作为开启概率探索（$\epsilon > 0$）的可靠触发器？
6. **异步分支间的知情同步策略：** 当多个活动分支以不同频率推进时，如何以最小上下文开销向某分支提示“其他分支已产生改变全局认识的新行动”，同时不造成跨分支注意力污染？
7. **反固化的认识更新机制：** 在维护自我模型与他者理解时，如何保留个体在真实经历中的认知成长轨迹，同时避免早期的偶然自评演变为自我实现的刻板标签？
8. **后台维护的收益边际与早停判据：** 离线巩固与自生成探针自检在运行多少轮次后会出现边际收益递减甚至过拟合？如何设计无需人工介入的自动停止条件？
9. **跨模型代际升级的可保持边界：** 当底层语言模型跨代升级或更换家族时，哪些记录与关系可按内容完整性继承，哪些派生认识与使用行为出现漂移？如何向所有者诚实量化报告迁移前后的认识差异？
10. **最小有效内核（Minimal Viable Kernel）识别：** 在经过严格的因子消融后，本框架的哪些高阶组件可以在不损害核心连续性体验的前提下被安全裁剪，从而为资源受限的边缘/本地环境提供极简配置？
