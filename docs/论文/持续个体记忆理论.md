*Contextual Long-Term Memory for Persistent Agents: Background Overviews, Event Associations, and Revisable Understanding*

**研究状态：**本文是一篇相关工作综述与理论提案，没有开展新实验，不包含虚构成绩，也不声称证明意识或取得算法最优性。论文的核心范围与内部后台维护边界已经由提出者确认；文体按完整理论论文组织，最终投稿或白皮书发布形式仍可调整。项目尚未命名，作者署名、许可证和公开发布尚未确定。

## 摘要

长期记忆的目标不仅是重新找到过去的文字，还包括在未主动查询时获得适当背景、根据当前情境联想到相关经历、借新证据修订认识，以及让不同活动中的经验属于一个持续个体。本文提出一个独立于具体 Agent 宿主和模型的功能性理论框架：以可追溯记录支撑事件块，以可重叠的多维记忆团提供背景概览，以跨事件关联支持联想，以情境状态调节当前激活及可选的概率探索，并以来源与版本关系维护当前认识。

本框架特别区分三组容易混淆的关系：团的成员归属与事件间联想联系、长期联系与即时激活、被想起的机会与主张受到的证据支持。人格、自我模型、程序经验和前瞻记忆被定义为建立在这些核心关系上的派生认识。记忆系统可以自主整理、检查缺口和准备联想材料，宿主保留外部行动决定权。

本文比较认知模型、近期 Agent 记忆论文和开源系统，说明现有机制的覆盖与差异，提出条件可组合的理论约束，并给出含消融、反事实对照、长期流和跨模型测试的验证方案。潜在贡献在于明确联合机制及可检验条件，而非声称单个组件首次出现。“网络”“概率云”等仅是运行行为的比喻，不限定图数据库、神经网络或生物模拟实现。

**关键词：**长期记忆；持续个体；情境联想；背景概览；事件记忆；认识修订；记忆巩固；来源追溯。

## 1. 问题与研究范围

### 1.1 从存储历史到使用过去

本文研究如下问题：对于一个跨时间、跨活动存在的 AI 个体，如何使过去在适当时机影响当前理解，同时保留核对、纠正和重新解释过去的能力？

背景概览与精确搜索承担不同功能。例如，谈起某个人时，系统可以先提供“最近主要交流过哪些事情”的概括；询问当时的明确承诺时，则必须能够定位具体事件和原话。与此同时，一段经历还可能唤起另一个主题中的相似教训。本文将这三种需要分别称为背景提供、精确回忆和关联探索，不以一种检索得分代替全部过程。

### 1.2 已确认边界

本项目面向一个持续存在的 AI 个体，允许多个活动分支；作为独立项目研究，不受 Nexus 的技术、接口或当前实现约束。记忆可以调用模型自行整理和联想，最终外部行动由接入的宿主决定。未来支持本地运行，并允许选择本地或外部模型；这些是产品偏好，不是理论成立的数学条件。

已确认的核心是：证据、事件、多维团、关联网络、动态激活、概览展开、分支与当前认识。人格、自我模型、技能和前瞻记忆作为这些核心结构之上的投影，即由记录产生、可以修订的不同用途的表示。允许后台自行整理、发现缺口、修订投影和准备联想，但不直接对外行动。

### 1.3 “近似意识特征”的操作化

本文将这一愿景转化为以下可观察目标，不设置“意识分数”：

| 目标特征 | 可观察表现 | 不能仅凭什么认定成功 |
| --- | --- | --- |
| 经历连续 | 能正确回顾自己的活动和来源，区分先后与变化 | 自称“我一直记得” |
| 情境敏感 | 同一线索在不同当前活动中唤起不同且适当的经历 | 回答每次都不同 |
| 背景感 | 未明确要求搜索时，相关过去仍能恰当地进入当前理解 | 每轮自动塞入大量材料 |
| 连续联想 | 新取回的经历能成为下一步线索 | 随机返回无关旧事 |
| 认识变化 | 能说明以前与现在的理解及变化依据 | 一份越来越长的自我描述 |
| 经验积累 | 类似活动中利用经验，同时识别不适用条件 | 重复同一套做法 |
| 自我觉察的功能表现 | 知道哪些内容已知、推测、缺失或需要核对 | 流畅的反思文字 |

这些目标可以在不复制人类认知机制的条件下研究。是否具有主观体验不是本文要判定的问题。

### 1.4 理论完整性的含义

完整理论需要定义对象、关系、变化、边界、失败情形和验证方式，不要求穷尽一切未来能力。它既不等于最小演示，也不等于一次性选定全部算法。本文刻意保留实现选择，以便以后能够检验并推翻无效机制。

## 3. 相关工作：哪些想法已有先例

### 3.1 情境、联想与记忆重建

CMR 把当前情境与回忆内容相互作用作为解释自由回忆的机制：当前情境引导取回，取回又恢复部分旧情境并影响后续回忆。[R1] SAM 将候选取样与恢复分开，为概率性联想提供理论参照。[R2] ACT-R 则区分使用历史带来的基础激活、当前线索的扩散激活与噪声。[R3]

本文借鉴这些功能性区分，但不把认知实验参数直接套到语言模型，也不认为激活度就是事实概率。Soar 的情景记忆与 LIDA 的当前情境模型提示另一点：长期记忆与当前可用工作材料之间存在选择过程。[R4–R5] 本文只借鉴有限工作集与情境组织，不引入完整认知架构或意识广播主张。

### 3.2 事件、背景和不同粒度

ReadAgent 用简短 gist 保存阅读背景，需要时回查原文，是背景优先与细节展开的直接先例。[R6] RAPTOR 组织多层聚类摘要，并研究跨层检索；它提示层级组织不必等于强制逐层搜索。[R7]

Membox 的局部主题盒子与跨盒子事件轨迹很接近“集合与联系分别组织”；但其盒子用于保留连续对话片段，不等同于本文允许任意重叠维度、主要供自动提供背景的概览团。[R8] HiMem 分开具体事件与稳定笔记，并通过证据回取修订知识。[R9] TiMem 研究多个时间粒度的巩固，NEMORI 研究经历整合与预测误差驱动的知识蒸馏。[R10–R11]

这些研究使本文不能声称事件组织、摘要层级或认识修订是新发明。需要检验的是它们组合后的独立作用及失效条件。

### 3.3 动态关联与主动搜索

A-MEM 建立笔记联系并随新记忆调整组织。[R12] MAGMA 将语义、时间、因果、实体关系分开，并根据查询意图选择遍历方式；2026 年版本标注 ACL 主会。[R13] HeLa-Mem 在事件图中研究共同激活和知识蒸馏，已有 ACL 论文与作者代码。[R14]

SYNAPSE 的近期预印本讨论扩散激活、侧抑制和时间衰减，公开摘要仍写明代码将在接收后发布，本轮未确认其公开实现。[R15] MRAgent 将中间检索证据用于调整下一步访问路径，2026 年论文标注 ICML 接收。[R16] HippoRAG 2 借图上的概率传播进行检索，但最终排序选择不能直接理解为随机回忆。[R17]

这些方法支持情境化、关系化访问的研究价值；**作者的概率排序或随机游走不自动证明随机取样优于稳定选择**。本文对概率探索的收益另设假设。

### 3.4 后台整理与经验发展

MemDream（2026-09 预印本）提出离线自探测、诊断和修复；其中包含训练后的修复策略，不能把其完整效果等同于任意模型执行提示词。[R18] ReMe 从成功与失败轨迹中提炼并修订程序经验，ACE 采用增量方式维护经验手册，MemRL 学习外部经验的使用效用。[R19–R21]

Hindsight 的经历与综合认识、EverOS 的事件与派生资料、MemOS 的多类型管理提供工程参照。[R22–R24] 这些系统已有相近组件，但它们的类型分类、作用域和模型边界并不完全一致。Sophia 将叙事记忆、用户与自我模型纳入持续 Agent 框架，是功能性连续性的概念参照，作者自身也将其描述为主要概念性研究。[R25]

### 3.5 独立性、来源和评测

Memory as Middleware（2026-09，论文注明有条件接收）讨论将记忆与宿主及存储解耦。[R26] Memory Is a Derivation 指出：有引用不代表组合后的结论得到支持；扩大证据范围也不必然让写入判断可靠。[R27] 模型迁移研究在受控小规模历史中观察到表示与写入模型的耦合，提示保留原始来源的重要性，不能外推为所有固定结构都更优。[R28]

LongMemEval、MemoryAgentBench、LongMemEval-V2 和 EvalMem 分别提供更新、增量学习、环境经验与流水线诊断的测试角度。[R29–R32] PM-Bench 则将未来条件触发下的意图回忆单独评测。[R33] 它们共同支持分项测量，但没有一项能够单独验证本文全部连续性目标。

## 4. 核心对象与语义

### 4.1 记录、事件和主张

**来源记录**保存可观察材料：消息、文件、工具输入输出、外部事件、用户纠正以及宿主选择记录的反思。来源记录能证明有人说过或系统观察到某内容，不自动证明内容在世界中为真。本文不要求取得模型未公开的内部思考。

**事件块**是一段经历的组织单位，引用来源范围，说明参与者、过程、结果、时间与未决事项。它是对记录的解释，可以重新切分或修订。稳定来源与可变解释必须可区分，不能把生成摘要称为不可变原始证据。

**主张**是可被接受、怀疑、更新或否定的内容。例如“任务已完成”“某人偏好简短回答”“我在此类任务上经常漏掉验证”。主张应保留适用条件与支持来源；明确陈述、转述、模型推断和受控实验结果不混同。

### 4.2 团只承担背景概括

记忆团在本文中指一批相关事件及其概览，服务于有限上下文中的背景提供。同一事件允许属于人物团、项目团、时间团、主题团等不同集合。归属可以是明确规则，也可以带程度，不要求所有团采用概率聚类。

人物归属、时间范围与主题相似不是同一种判断：同一人的两次不同话题交流仍可共团；主题很相似的两次事故也可能属于不同项目。团允许重叠，但事件不必复制。

团概览应表达覆盖范围、主要经过、当前关键变化、未决分歧、更新时间和细节入口。不同粒度的概览可按需要生成，但本文不强制固定的团层级。

**同团不推出强联想，强联想也不要求同团。** 团不是意识单元，也不是网络中的必经中转站。

### 4.3 事件间的关联与证据依赖

联想联系直接发生在事件块之间，可以跨越任何团。联系可以表达相似问题、时间接续、同一人物、目标延续、承诺与履行、纠正、反例或类比。关系可能有方向：承诺容易唤起履行检查，并不意味着反向意义相同。

需要区分：

- **导航联系：**帮助发现可能相关的内容；
- **证据关系：**说明哪条主张由哪些来源支持、反驳或派生。

二者可以共用物理数据结构，但含义不同。类比可以有启发，却不证明两次经历原因相同；同一来源的多个摘要也不成为多份独立佐证。

### 4.4 当前情境与有限工作集

当前情境包括可获得的话题、目标、活动分支、已知事实、最近经历、未完成约定和刚刚被唤起的内容。无需假设能够读取宿主全部心理状态，也不要求每个字段始终存在。

有限工作集是本次向宿主提供的材料。它可包含少量团概览、关键事件、待核对线索和展开入口。记忆库里存在、被候选检索找到、实际进入宿主上下文、被宿主使用，是不同阶段。

### 4.5 四个量分别表达

| 量 | 问题 | 允许怎样变化 |
| --- | --- | --- |
| 长期联系 L | 经历之间长期怎样关联？ | 随新经历、明确反馈与整理修订 |
| 当前激活 a | 此刻什么更容易浮现？ | 随话题、分支、线索和回忆过程变化 |
| 选择概率 π | 候选本次被抽取的机会是什么？ | 随探索策略、预算与候选集合变化 |
| 证据状态 q | 这项主张有何支持、冲突和适用范围？ | 随新来源、核验、修正或重新评价而变化 |

π 可以是算法明确规定的取样概率，不需要被解释成现实事件的真值概率。若声称 q 是“正确概率”，才需要相应校准与验证。没有校准时应称为支持状态或分数。相似度、频率和激活不能换一个名称就变成可信度。

## 5. 一个可分析而不锁定实现的形式框架

本节是本文提出的形式化示例，用于检查关系是否闭合，不是已验证算法。

令长期状态为 M=(R,E,C,L,D,U,V)，分别表示来源记录、事件版本、团集合、联想联系、派生依赖、当前认识和修订历史。活动分支 b 的情境为 c(b,t)，可见且符合本次用途的候选集合为 K(b,t)。

团 c 的成员关系记为 m(i,c)，其概览为 g(c,v)，v 表示所依据的事件版本。成员关系 m 与联想联系 L(i,j) 分别定义：不由 m(i,c)m(j,c) 自动产生 L(i,j)。这是一项语义约束，不表示二者统计独立。

一个情境化关联函数可写成：

$$
A_{ij}(b,t)=F(L_{ij},c(b,t),e_i,e_j,h(b,t)).
$$

h 表示近期访问与反馈。F 允许当前情境改变联系的有效使用程度，而不要求每次改写持久 L。缺少预先保存的 L 不必永远禁止联想；F 也可以提出临时联系候选，是否持久化另行判断。

一次候选激活的示意更新是：

$$
a^{k+1}=\rho s+(1-\rho)P_{c,b}^{\top}a^k,\qquad 0<\rho\leq1.
$$

s 是从当前线索得到的归一化起点，P 是在候选集合内构造的非负行随机转移矩阵。上述条件下，带重启的线性传播可在有限候选集上收敛；这只是一种计算性质，不证明结果相关或可信。若加入动态抑制、非线性更新或每步重构图，该收敛结论不再自动成立。负面证据或“矛盾”关系不能直接作为负转移概率，应保留其类型并由查询策略处理。

概率探索可以采用一种示意策略：

$$
\pi_i=(1-\epsilon)\frac{\exp(z_i/T)}{\sum_{j\in K}\exp(z_j/T)}+\epsilon q_i^{explore},\qquad T>0.
$$

z 是综合使用得分，q(explore) 是同一候选集上有定义的探索分布。两部分均归一化，ε 位于 [0,1]。精确回忆也可以完全不使用取样，直接选取证据充分的候选。此式不是“人脑概率公式”，不要求每轮全库计算，也不使搜索具有无限覆盖保证。

最终提供的材料集合 W 还需满足容量 B：

$$
W=\operatorname{Select}(G_{background},E_{detail},H_{association};B).
$$

Select 同时考虑相关性、证据完整性、重复与细节需求。团概览与其事件重复出现时，应按同一来源谱系计算覆盖，而不是重复奖励。

**回忆不增加独立来源：**若操作只读取、转述或概括已有记录，没有新外部证据，则独立来源集合保持不变。重新推理可以改变对旧证据的解释甚至主观置信，但必须标记为重新解释，不伪装成新佐证。这一区分避免把“不得虚增证据”误写成“不得重新思考”。

## 6. 记忆的完整生命周期

### 6.1 经历形成

来源进入后，系统先保存可追溯内容或可访问引用，再形成事件。事件边界可参考目标变化、主题转换、行动结果和预测不一致；普通日常互动也可以逐渐形成认识，不能只保存显著工作成果。

新颖性或惊讶可以调节整理优先级，但不能成为唯一保留标准：稳定偏好、重复约定和低频重要经历可能并不新奇。NEMORI 与事件分割研究提供启发，而非唯一规则。[R11]

### 6.2 团生成与背景提供

系统按多个维度组织事件，生成带来源的概览。根据当前情境主动选择少量概览，必要时直接附关键事件，避免“概览过粗→必然再查一次”的固定流程。

一个团进入上下文不等于其所有事件均被激活。概览提供背景，具体线索才参与事件级联想。团也可成为找到相关事件的入口，但不限制跨团关联或原文精确搜索。

### 6.3 联想与主动回忆

先从当前线索产生候选，再通过关联或迭代查询补充其他经历。新取回内容可以更新当前情境，从而改变下一步访问方向。宿主主动搜索、后台准备和随请求自动提供都能使用这一机制，区别在目的、预算和输出粒度。

自由联想中的随机性只影响取出哪些已存在或明确标记的候选内容，不随机创造过去。候选被想起后仍可被判断无关。停止条件应考虑新增信息、重复、证据是否足够和资源使用；具体规则留给未来实验比较。

### 6.4 巩固、重解释与自检

系统可在后台整理事件、发现联系、更新概览、修订认识和用自生成问题检查可访问性。后台假想问题必须由现有资料支持答案，不能把自行生成的答案写作新经历。最终评测使用与维护探针独立的未来任务。

巩固不是层层摘要直到只剩一个故事。应保留反例、关键条件和可回查路径。若整理不能带来独立验证的收益，应允许减少或停止；频率与停止方式是研究变量，不预设必须模拟“睡眠”。[R18]

### 6.5 修正、失效与删除

修正一次错误解释、更新已经变化的事实、停止主动召回和删除内容，是不同操作。来源被修正后，依赖它的事件概括、团、认识或技能需重新评价，而不是只更新一处文本。

稳定来源不意味着永不删除。明确删除时，应处理本系统可控范围内的原文、派生内容和索引；历史记录不能保留本应删除的敏感载荷。外部副本、已经发送给宿主的内容或模型参数中的影响，不能靠本系统删除保证消除。具体保留范围与产品按钮本轮不锁定。

### 6.6 重新切分与迁移

同一段记录可以有不同事件解释。合并、拆分或更换整理模型时，应记录新解释依赖哪些来源，以及哪些旧投影已过期。允许多种有效切分并存，不强制唯一正确的事件粒度。

模型替换后，原始来源、关键解释版本和归属可迁移，向量及派生结构可以重建；重建不保证逐字相同或行为完全相同。需要同时评估恢复能力和变化，而不是把“文件还在”称为连续性已经得到保证。[R28]

## 7. 作为扩展投影的认识、个体理解与经验

### 7.1 当前认识与情境模型

当前认识回答“依据已知材料，目前怎样理解”；情境模型回答“这次正在处理什么、哪些事实暂时相关”。前者可以长期保留并修订，后者随活动切换。新消息不一定比旧证据更真实，不能只按最新时间覆盖。

概览和认识也要分开：“最近讨论过三次延期”概括经历；“我在承诺时间前应先核实依赖”是一种经验判断。二者可以同时提供，但来源与适用条件不同。

### 7.2 自我模型与关系理解

自我模型可以记录能力经验、习惯、承诺、倾向和对过去行为的解释。关于他人的模型记录对其偏好与关系的理解。这些均可修订，不要求人格数值、固定情绪轴或 MBTI 等分类。

“我曾认为某方法可靠，后来哪些经历让我改变”是可验证的叙事连续性。系统没有必要强行生成一条永远连贯的自传；尚未解决的矛盾也应成为当前认识的一部分。Sophia 提供持续自我建模参照，但其完整 Agent 执行与奖励机制不并入本文记忆边界。[R25]

### 7.3 重要性、情感评价与未完成事项

一个事件为什么值得注意，可以来自当前目标、长期约定、关系意义或使用者明确强调。可选的情感评价是有来源的解释特征，不是系统已经产生主观情绪的证明。它影响关注程度，不应单独提高事实可信度。

未完成事项保留“为何重要”和“在什么条件下应想起”。执行状态由其负责系统提供，记忆不另造一份可能漂移的完成状态。

### 7.4 前瞻记忆

前瞻投影把过去的约定与未来可观察线索相连。当线索出现，系统可以准备相关材料供宿主读取；在宿主缺少及时观察或调度时，记忆本身不能保证按时执行。

它的成功需分开测量：触发线索是否出现、记忆是否准备、宿主是否看到、宿主是否采取行动。这样才能沿用已确认的“记忆可整理，行动由宿主决定”边界。[R33]

### 7.5 经验与技能

经验保存“当时什么条件、采取什么做法、实际有什么结果”；技能是从一组经验中提炼的可复用方法。需要保留适用条件、失败例外和结果来源，不把一次成功变成普遍规则。

ReMe、ACE 和 MemRL 可分别提供经验蒸馏、增量手册和反馈选择的启发，但不能直接将它们的分数混合。记忆可以提出技能或修订建议，执行技能与修改宿主仍属于宿主行为。[R19–R21]

## 8. 一个个体、多个活动分支

本文默认分支是同一个体在共同现实中的多个活动上下文，**不默认是互斥世界、人格分裂或版本控制分叉**。共享经历与局部工作现场应同时存在。

例：分支甲已经发出一条消息，这是个体实际行动的记录，不需等主干“批准记住”才发生；分支乙尚未读取它，则属于“已记录但本分支未知”。甲在计划阶段写下“可能周五发送”，则只能作为计划记录，不能变成发送事实。

因此需要区分四件事：记录属于哪个活动、某个分支当前看到了什么、解释适用于什么范围、信息是否存在独立的可见性限制。分支归属本身不推出隐私隔离，也不要求所有分支每次读取全部历史。

共享真实经历可以进入主体历史；局部假设、模拟和计划保留明确状态。归并的是对经历的理解，而不是把已发生行动重新判成尚未发生。冲突先检查时间、对象与情境是否不同，再判断是否确有矛盾。

如果未来需要反事实模拟或独立身份分叉，应另行定义其世界范围；不能把这种额外功能偷偷写进普通活动分支。合并方式由语义决定，本文不预设所有合并都不满足交换律，也不把后写覆盖作为默认。

## 9. 条件可组合性与理论性质

### 9.1 可以组合的条件

不同机制可以共用来源、事件标识、派生关系、时间和活动范围。团生成、联想检索、认识维护、技能提炼可以采用不同算法，但必须说明消费什么、产生什么、何时生效。

组合后仍需要保留：

1. 来源可定位，或明确标记来源缺失；
2. 生成解释与原始记录的类型区别；
3. 更新、替代、冲突和删除的影响范围；
4. 候选被提供与宿主使用的区别；
5. 独立证据不因重复派生而增加；
6. 团成员关系不自动决定跨事件联想；
7. 活动归属不自动证明或否定事实。

这些是本文选择的语义条件，并非已经证明对一切记忆系统必要且充分的定理。

### 9.2 不宜直接拼接的机制

| 组合问题 | 可能后果 | 本文处理 |
| --- | --- | --- |
| 多个整理器同时改写同一份认识 | 互相覆盖、循环摘要 | 明确输入版本、更新范围与冲突；不禁止多方法比较 |
| 将相似度、激活和可信度直接相加称为概率 | 数值失去可解释含义 | 先定义各量和用途，再验证融合 |
| 只保留概览再依靠联想恢复细节 | 生成不存在的原文 | 允许原档回查，缺失时明确说明 |
| 每次回忆都强化证据 | 熟悉感变成真实性 | 访问统计与来源支持分离 |
| 给每种投影另造一套永久历史 | 重复、删除不同步 | 共享来源，投影保留派生关系 |
| 整体迁入认知架构或 Agent 框架 | 记忆项目边界消失 | 借机制与研究结果，不自动迁入行动执行 |

### 9.3 三个定义内性质

以下只是由定义推出的性质，不是本系统性能证明：

- **归属不蕴含联想。** 若 m 与 L 独立定义，则修改一个团的展示归属不必修改事件间联系；但相关概览是否重算仍取决于其输入。
- **重复派生不新增独立来源。** 若派生来源集合取输入来源集合的并集，则同一来源被多次摘要，其独立来源数量不会因此增加。真实来源独立性仍需核查，不能只数 ID。
- **有来源不等于推导成立。** 来源集合存在仅说明可回查，不能证明组合结论正确。要额外检验主张是否被这些来源支持。[R27]

## 10. 可检验研究假设

| 假设 | 预测 | 否定或收缩条件 |
| --- | --- | --- |
| H1 背景与联想可分离 | 团改善自动背景，事件联系改善间接召回，存在可分项观察的收益 | 同成本下单一结构完全替代二者，则只保留工程分工 |
| H2 情境调节有用 | 同一线索在不同活动中选出不同且适当的经历 | 差异只有随机噪声，没有相关性或使用收益 |
| H3 探索具有条件性价值 | 模糊问题中受约束取样提高有效联系的覆盖 | 收益来自更多尝试，或误关联代价抵消收益 |
| H4 展开改善证据使用 | 概览加可回查入口在相同预算下兼顾背景与精确细节 | 展开延迟抵消节省，或遗漏使完整原文更好 |
| H5 来源谱系减弱自我确认 | 重复转述不会显著提升无据主张的证据地位 | 仍出现同等错误强化或来源核对无实际增益 |
| H6 后台维护收益有界 | 自检和修订改善留出未来任务，但存在饱和或负收益 | 只改善自生成探针，未改善独立任务 |
| H7 分支情境减少错用 | 保留活动来源和局部已知范围能减少归因错误 | 只是过滤更多资料，合法共享与任务效果下降 |
| H8 认识修订支持连续性 | 更新后既能使用当前理解，又能解释旧理解的依据 | 只让叙述更流畅，真实更新题和行为无改善 |
| H9 模型可迁移性可提升 | 可追溯来源有助于换模型后的重建与核对 | 恢复失败或重建成本高于收益 |
| H10 经验需适用条件 | 带条件与反例的经验降低负迁移 | 无条件经验同样可靠且更有效率 |

随机取样的分布可以是合法的算法概率，而“某个联系有用”的预测仍需校准。评测时不能把两种概率混为一类。

## 11. 验证方案与结果边界

### 11.1 实验层次

第一层使用有明确来源和时间的受控历史，测试对象、版本、派生、来源删除和活动归属。第二层在固定宿主下替换记忆机制，观察记忆准备质量。第三层在完整活动流中评估宿主实际使用。第四层更换模型或宿主，评估记忆迁移与长期持续使用。

### 11.2 基线与消融

至少包含关键词／向量混合检索、完整原文（仅在预算容纳的子集）、普通摘要、概览团单独、关联网络单独、二者结合，以及独立的情境调节与概率探索开关。

核心采用“概览有无 × 事件联系有无”的因子设计，再比较动态与固定使用。以同一候选集比较 top-k、概率取样和多样性选择，避免把候选生成的改善误归因于随机性。纯随机可作为诊断对照，不作为合理产品基线。

预生成并固定事件与概览的实验用于隔离检索机制；另做完整写入链实验检验上游误差。不能只比较“全套系统”与“没有记忆”。

### 11.3 任务与指标

| 任务 | 观测重点 |
| --- | --- |
| 未主动查询时背景使用 | 相关约束是否进入上下文并被正确使用；无关背景比例 |
| 原话、日期与承诺 | 原文定位、上下文完整性、行动状态区分 |
| 跨主题关联 | 有效跨团联系覆盖、路径依据、错误类比率 |
| 相同线索不同情境 | 排序变化是否随任务而变，是否优于固定策略 |
| 当前、过去与变化经过 | 当前有效性、历史准确性、修订轨迹分别测量 |
| 多分支交错 | 归因错误、已知状态、共享事实召回和局部假设误用 |
| 反复回忆同一来源 | 独立来源计数与无据主张强化 |
| 后台整理 | 独立留出题收益、稀有事实丢失、过度合并与维护成本 |
| 纠正、撤回、删除 | 受影响派生处理、无关资料保留、后续重新学习 |
| 经验迁移 | 适用场景收益、不适用场景伤害、重复错误 |
| 跨模型接手 | 事实可恢复、认识差异、索引重建与总成本 |

LongMemEval 测事实与更新，LongMemEval-V2 补环境经验，LoCoMo-Plus 补隐式约束，EvalMem 补写入／检索／使用归因，PM-Bench 补前瞻回忆。[R29–R34] 它们作为不同测试面，不能合成一个未经定义的“个体意识得分”。

### 11.4 统计与成本控制

按完整历史或个体活动流划分训练、维护、验证和测试；未来测试问题不进入背景摘要或后台自检。记录模型、提示、索引、输入版本和随机种子。概率方法采用多次运行，报告均值、方差、区间和最差情形；多个探针共享同一历史时使用配对或聚类分析，避免伪增样本量。

预算至少同时报告：写入、后台维护、召回、原文展开与宿主读取的总计算；额外试验次数、延迟和存储也要计入。既报告同上下文预算，也报告同总成本，避免用更多模型调用制造结构优势。

“联想有用”用可核查的后续任务或盲评定义，不以新奇程度或句子流畅度替代。模型判定器需要抽查与版本记录；确定性事实尽量采用可重复规则。真实个人数据实验需另行取得相应同意，本轮不使用私人历史公开建集。

### 11.5 本文没有结果章节的原因

本轮没有实现联合框架或复现候选算法，因而不存在可以报告的对照成绩。前文是研究设计，不是实验已通过。工作稿可以公开作为理论提案；若希望按实证论文投稿，应补充共同条件下的原型、消融和长期实验。

## 12. 独立项目的意义与可复用路线

独立项目的价值应体现为：多个宿主能够使用同一种可理解的记忆语义，替换模型和索引后仍保有来源、经历、认识及变化历史。它不以是否比所有检索器更快或拥有更多模块作为唯一价值。

现成项目可提供不同机制，但没有必要整体叠加：

| 工程参照 | 可研究的部分 | 本文不自动继承 |
| --- | --- | --- |
| Hindsight | 事实／经历与综合认识、来源与整理 | 将服务自身反思视为宿主最终判断 |

## 13. 限制、未决选择与适用边界

本理论依赖可获取的观察和来源，无法恢复未记录、已删除或外部不可访问的细节；无法保证宿主按提供材料行动；无法从功能模拟推出意识。自然事件边界、有效关联和“有用背景”都具有情境性，需要基于任务定义而非假设天然真值。

多维概览可能重复，网络可能放大热门经历，后台整理可能强化早期误解，自我叙述可能抹平矛盾。本文用分项实验研究这些问题，不预设复杂机制必然优于简洁检索。某一功能若没有可重复增益，允许从实现中省去而保留其他关系。

仍需后续决定的政策包括：原始资料保留范围、认识与自我描述的自动更新程度、概览是否允许用户直接编辑、自由联想在不同场景中的容忍度、后台维护预算、对外通知是否需要单独宿主机制。它们不阻止本文定义理论，也没有因列入讨论就成为已批准功能。

已经确定的边界是：一个持续个体及活动分支、记忆可自行整理和联想、外部行动由宿主决定、支持本地运行且模型可替换、本文核心与扩展投影分层。本文选择的具体公式和机制组合尚待检验，不应称作用户已经批准的算法。

## 14. 结论

本文提出将持续个体的长期记忆组织为可追溯来源、事件解释、多维背景概览、跨事件关联及情境化使用过程。团回答“这方面大致有什么过去”，网络帮助回答“从这里还可能想到什么”；两者共享事件但不互相替代。长期联系、当前激活、实际取样与证据支持分别表达，允许动态联想与认识修订，同时防止熟悉感被误当成真实性。

已有研究为各部分提供了多种先例，尚不能据本轮调查宣称这一组合具有排他的原创性。可检验的贡献是联合框架、语义约束及对应实验。目标是使过去能够准确、灵活且可修正地参与当前理解，并为独立项目提供不绑定某个宿主或存储方案的理论基础。

## 附录 B：不受技术栈限制的研究问题
