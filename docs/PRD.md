# PRD｜Nexus 通用附件上传与文档读取

## 1. 需求与已确认范围

在普通会话和持久任务中上传、保存并使用通用文件附件。用户已选择：文件作为会话/任务附件保存，文本、代码、PDF、Word、Excel、PPT 的常见格式能够直接读取内容；其他格式保留原文件，按现有工具能力处理。目标是让附件真正参与 Agent 工作，并保留现有图片能力。

本轮办公文档的直接读取格式为 `.docx`、`.xlsx`、`.pptx`，PDF 读取文本层。扫描件无文本、密码保护、损坏文件、旧版 `.doc/.xls/.ppt` 等不能直接读取的情况必须如实显示限制，保留原文件供下载或现有工具处理；不将上传成功等同于解析成功。不新增 OCR、文档在线编辑器、云端文件服务或自动执行附件的能力。

## 2. 必须交付

- 通过选择、拖拽和粘贴添加文件，显示文件名、大小、处理状态，发送前可移除；支持只发送附件。
- 原文件归属对应会话或任务，同名文件互不覆盖，刷新和重启后可查看、下载并继续读取；删除会话或任务时清理所属附件。
- 文本/代码文件直接读取；PDF 按页、DOCX 段落和表格、XLSX 工作表/单元格与公式、PPTX 幻灯片文字和表格提供可定位内容。
- Agent 能发现本轮及历史附件，使用分页读取工具获取正文和原文件路径；不将整份大文档无条件塞进提示词。
- 普通会话原有图片视觉输入继续可用；持久任务支持文件附件，图片在模型具备图片能力时可随任务输入。
- 其他二进制文件保留原件与路径，不自动执行、不伪称已读懂。工具操作继续受现有权限控制。
- 超限、损坏、缺失、无可提取文本等情况清晰反馈；错误不丢弃用户尚未发送的文件或文本。

## 3. 验收

- [ ] 会话和任务均可上传、单独发送、多轮引用文件；刷新/重启后归属和记录保持正确。
- [ ] 各类支持格式实际提取正文，保留页/表/幻灯片位置；模型实际调用读取工具并使用结果。
- [ ] 同名文件不覆盖，错误会话/任务不能引用其他对象附件，文件名不会作为任意存储路径。
- [ ] 不支持、损坏、扫描或加密文档明确提示，原件仍可下载；超限请求正确拒绝。
- [ ] 图片及旧会话兼容，任务暂停/恢复、权限和消息持久化无回归。
- [ ] 自动化与必要网页操作验证通过，限制及未验证项写入交付记录。

附件大小、分页和提取上限属于本轮可调整的实现参数，须在界面与交付记录中说明；不改变既有用户数据格式或要求历史记录迁移。
