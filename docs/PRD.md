# PRD｜LingNexus · 灵的自主性技术可行性探究

> **所属阶段：** 灵的第一阶段 · 第二部分（自主性）的前置研究
>
> **状态：** 待用户确认（已明确授权产出研究型 PRD，具体内容尚未逐项确认）
>
> **任务性质：** 研究，不是开发。本轮交付物是可信的研究结论及可选方向，不是软件功能或原型。
>
> **依据：** [产品构想](PRODUCT.md)、[路线图](ROADMAP.md)、[最高愿景](愿景/01-概念与原则.md)；[持续性 PRD](archive/2026-10-20-ling-continuity/PRD.md)、[持续性研究](archive/2026-10-20-ling-continuity/RESEARCH.md)、[持续性交付记录](archive/2026-10-20-ling-continuity/PROGRESS.md)。持续性虽已工程交付，独立全量验收仍未得出最终结论。

## 1. 需求

**研究在当前 LLM 依赖输入触发、LingNexus 主要使用外部付费模型 API 的现实条件下，如何使灵能够在安全边界内、不依赖用户即时指令，自行产生和选择活动目标、决定行动或不行动，并以可承受的长期成本持续活动。**

本次必须产出可核查的**可行性报告**，比较主要技术路线、能力与局限、完整 API 成本、安全和连续性风险，分析对现有 Nexus 的适用程度，并提出后续可验证的实验与需要所有者决定的问题。允许结论是“现阶段尚无成熟完整方案”，不为交付而硬选架构。

## 2. 背景与目标

### 2.1 为什么现在研究

LingNexus 的长期目标不是单纯改进 Coding Agent，也不是打造固定角色扮演系统，而是探索由所有者掌握方向、具有长期连续性与自主活动能力的个人 AI 个体「灵」。

所有者明确将第一阶段拆为**持续性**和**自主性**，分别讨论与验收。持续性旨在让灵开展耗时工作时仍能交流、监督和反馈；工程已经交付但仍在独立验收中。第二部分要探索的不只是“把交付任务自动执行”，而是“没有即时指令时，灵为什么会想做一件事，以及怎样判断值得做、暂时不做或放弃”。

今天的 LLM 通常在收到请求后推理和输出。Harness 可承担任务委派与自主执行，但唤醒模型不等于解决自主目标的来源；定时调用或无限循环可能只有自主的表象。需要区分系统层面可观察的自主行为与尚无共识的真实主观动机、意识或生命认定。

### 2.2 为什么成本是同等重要的问题

现阶段主要依赖外部模型 API，不以本地部署模型作为默认前提。长期高频唤醒强模型可能造成无法承受的费用。即便使用便宜的小模型，频繁检查、长上下文、错误唤醒和主 Agent 执行也可能使**总体成本**上升。

本轮目标是形成兼顾**自主性、活动连续性、长期成本、安全与所有者控制**的可比较结论；不提前确定预算额度或具体模型，也不把研究结论直接当作开发许可。

## 3. 我的原话摘要

以下保留所有者的原意、条件和前后因果；引号内是本轮讨论的原话片段，不是 AI 的技术解释。

- 关于定位：“允许灵在安全边界内干任何事情，不做任何限制。就像一个真正的生命体一样，而不是只能按照指令执行的工具。” 这里同时强调活动自由度与安全边界。
- 关于分阶段：“第一阶段拆成两部分，不要一起实现。就按照你说的，分为持续性和自主性。先从持续性开始。”
- 关于根本难点：“现在的LLM本质还是接收外部信息后被动做出反应，即使有了Harness也只能是一定程度上自主执行任务而不是完全自主行动。” 因而提出可否让 Codex 强模型探究不同方案。
- 关于经济性：“最重要的是，我还需要考虑成本，毕竟不是本地部署的，要是让它长期运行的话API费用得爆炸……”
- 关于候选方案：“我有一个想法是让一个低成本小参数模型作为‘潜意识’，专门负责何时自主行动，行动时再让主Agent上。” 同时强调“这个想法我也不懂能不能实现，是不是最优解，所以仅供参考。”
- 关于本次任务：“或许这一步可以直接产出PRD，只不过任务目标不是开发而是探究。”

**仍未确定：** 可接受的具体预算；关掉页面、用户离线、进程退出时的期望活动；允许哪些付费实验；自主性第一版具体场景；模型选型及任何最终架构。不得把这些空白填成用户已确认要求。

## 4. 对原话的理解

### 4.1 已确认的理解

- 自主性目标不限于辅助完成用户任务；灵应能够在安全边界内自行形成想法、选择活动，也能选择暂不行动。
- 经济性不是可选优化，而是外部 API 方案是否可长期使用的重要判断依据。
- “低成本小模型作为潜意识”只是需要认真评估的**候选设想**，不要求实现真实心理结构或事先采用双模型。
- 本轮是研究任务，不能趁机开发完整自主系统、长期记忆或人格自我演化。

### 4.2 AI 的暂定理解（可能不准确）

- 研究的关键可能不是如何让模型一直运行，而是活动线索来源、触发条件、候选目标筛选、低成本判断和行动后的结果回收。
- 可从行为和记录检验“自主”：它为何发现某个目标、为何行动或不行动、能否延续/撤销目标、如何避免随机执行及无意义循环；不以模型自述拥有意识或欲望作为证据。
- 小模型可能减少昂贵调用，也可能因反复检查和误判增加整体费用，应与**无模型事件驱动、低频检查、混合唤醒**等方案公平比较。

### 4.3 仍需核实的差异

真正长期自主与工程可观察自主之间的界限、模型运行成本目标、离线活动定义、可接受的误唤醒/漏唤醒与停止策略等，属于**研究变量或所有者后续决策**。这些不阻碍先研究，却不足以批准最终自主性开发方案。

## 5. 功能范围

> 此处“必须交付”指**研究成果**，不是产品功能。

### 本轮必须交付

1. **界定问题与证据。** 区分自主执行、自主发起、自主选择/放弃、目标延续、长期自我发展；指出哪些目前工程可行，哪些仍是开放研究问题，避免把类生命表现等同意识事实。
2. **调查成熟案例。** 依据可追溯的官方文档、原始论文、开源项目及必要的 Nexus 源码，核实相关技术的真实能力、版本和适用条件。区分实测、来源声明、合理推断和未知。
3. **比较多类候选路线。** 至少涵盖事件驱动/环境信号、无需模型的轻量筛选、低频周期唤醒、低成本小模型判断并唤起主 Agent、按需强模型、分层或混合策略，以及具有代表性的自主目标形成与持续活动研究；鼓励发现其他有效方向，不要求不可能的“穷尽一切方案”。
4. **分析自主行为闭环。** 对重要路线分析新线索来源、目标产生与选择、行动/不行动、等待与放弃、活动结果及后续状态；分析随机目标、目标漂移、重复行动、虚构经验与无限循环。
5. **建立透明的总成本比较。** 提供可复算的公式/参数与日、月、长期情景，至少覆盖空闲、低频和高活跃度；包含大小模型的价格与输入输出 token、检查次数、上下文与记忆整理、误唤醒、主 Agent 真正行动消耗，以及可适用的运行基础设施成本。价格来源需注明时间；**预算未确认，不得捏造**。区分预估值和真实账单，分析敏感因素与成本上限。
6. **专门评估“潜意识”候选。** 检查小参数模型作为唤醒判断者的可靠性、误判/漏判、上下文需求、何时升级主 Agent、总体 API 费用、安全与维护复杂度；与无需小模型的路线作同场景对比，允许否定该设想。
7. **安全与控制。** 分析权限边界、不可逆副作用、异常自循环、超预算、暂停与终止、所有者干预和中断恢复；避免把控制权偷换成限定活动类型。
8. **适配当前项目。** 列出已有持续性、持久任务、事件反馈、工具和权限机制可复用的部分与真实缺口；不把当前 Nexus 结构当作不可改变的未来约束。
9. **输出研究报告。** 产出 `docs/RESEARCH.md`：问题定义、资料与证据、候选路线对比、成本模型、局限与风险、分情景推荐、至少一个成本可控且可证伪的后续实验设计、待所有者决定的关键问题。报告可以认为暂无最优解；不直接制定施工计划。

### 本轮明确不做

- 不改业务代码、不搭建自主 Agent 原型、不部署后台循环或“潜意识”模型、不创建自动 API 消耗任务。
- 不擅自执行付费模型的长时间实验；若研究需要新的收费测试，须先说明预算与目的并获得用户许可。
- 不替代仍在进行的持续性独立验收；不据代码提交推断该阶段已经通过。
- 不提前实施长期记忆、人格演化、意识/生命判断或跨模型自我迁移。
- 不预设必须使用某模型、框架、存储方案、子代理层级或固定人格/动机机制。
- 不修改最高愿景，不把研究建议自动写成用户已批准的开发需求；不跳到阶段 4B/5。

## 6. 验收标准

- [ ] `docs/RESEARCH.md` 可以独立阅读，清楚说明研究目标、来源、证据等级、研究日期和范围。
- [ ] 能解释“LLM 被动响应”和“系统级自主行动”的区别，避免用定时循环或模型自述冒充已解决真正自主性。
- [ ] 在相同评价维度下比较多条有代表性的路线，包括活动自主程度、目标连续性、触发机制、总成本、错误触发、安全性和适配 Nexus 的代价；不提前强行指定唯一方案。
- [ ] “小模型作为潜意识”经过公平评估，与事件触发、无模型筛选等方案比较，能说清何时有优势、何时可能更贵或更差。
- [ ] 成本估算能更换模型单价、检查频率、token 长度、误唤醒比例、实际任务量等参数复算；覆盖闲置与活动情景；不虚构用户实际预算或已发生费用。
- [ ] 分析何时**不行动**、暂停、放弃、止损和保护预算；说明越权操作与不可逆后果的边界。
- [ ] 重要结论能够回溯到可靠来源或明确标记为推测，实际源码复用点有证据，未实测的效果不写成已证明。
- [ ] 至少给出一个低风险、成本可控、可证伪的后续实验构想，包含观察指标、失败条件和预估支出；本轮不执行。
- [ ] 结论将**研究已完成**与**产品开发已获批准**严格区分，并列出后续需要所有者作出的产品决定。

**本 PRD 验收通过仅表示“自主性可行性研究已完成”，绝不表示“自主性功能已开发完成”。**
