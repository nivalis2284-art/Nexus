# Nexus

Nexus 是运行在个人电脑上的 Agent 底座。通过主交流入口“灵”交代需求，后台工作独立推进，
结果、问题和待批准的操作回到主交流。

## 安装与启动

主要面向 Windows，需要 Python 3.12。未安装时，从
[Python 官方网站](https://www.python.org/downloads/) 安装 Python 3.12。

1. 将整个发行文件夹放到可写的位置。
2. 双击 `start.bat`。首次启动会创建 `.venv` 并联网安装依赖。
3. 打开终端输出的本机地址，通常为 `http://127.0.0.1:8766`。
4. 在设置中填写模型协议、Base URL、API Key 和模型，选择思考强度。
5. 在“灵”中发送消息或交代工作。

保持启动窗口打开；关闭它会停止服务。发行文件不包含可用的模型密钥，需要自行配置。

默认数据目录为发行文件夹内的 `.nexus-data`。可以在启动前设置 `NEXUS_HOME`，或通过
命令行指定其他位置；同一数据目录只运行一个实例。

```powershell
.venv\Scripts\python.exe -m nexus --home .nexus-data --workspace . --no-browser
```

直接运行 `python -m nexus` 而不指定数据目录时，默认使用 `%LOCALAPPDATA%\Nexus`；
它不会自动迁移 `start.bat` 使用的数据。

## 使用

- 主交流运行时可以继续补充消息、图片和文档；输入先保存，在后续模型请求边界送入。
- 耗时工作可由灵交给后台处理，最多三个并发执行。同一 Git 项目中的修改串行进行。
- 关掉网页不会停止已接收的工作；停止服务会中断执行，重启后需要明确继续。
- “停止当前交流”停止主交流及其直接委派的子代理，独立后台工作继续。
- 工具审批和问题在主交流中处理。默认 `ask` 对文件修改和命令执行逐项审批；
  `yolo` 允许直接执行这些操作，文件工具仍受工作目录边界约束。
- 工作详情保存结果、工具记录和待确认操作。补充要求、暂停、恢复或取消从主交流交代。
- 主交流忙时暂不能归档、恢复归档或删除工作记录，需等本轮结束后操作。
- “上下文管理”可编辑所有者指令、角色规则及历史摘要，也可删除近期消息。
  主交流运行时需先停止或等待结束，才能修改历史。
- 编辑消息后重新发送会替换其后的交流记录；已经执行的工具、文件修改和后台工作不回滚。

## 模型与扩展

支持 Anthropic Messages、OpenAI Chat Completions 和 OpenAI Responses 三种协议。
模型能力和思考强度以实际提供商支持为准。上下文窗口设置用于本地容量管理，
不会扩大提供商的实际上限。

Skill 管理支持个人技能和项目技能；MCP 管理可连接本地进程或 HTTP 服务。
插件单独发布，本发行版只提供插件宿主、管理页面和公共 UI 资源，不捆绑插件程序、
SDK 示例或手机端。

## 数据与分享

模型凭据、会话、工作记录和附件都保存在数据目录。可在服务停止后备份整个数据目录，
保留文件及其关联。

实际运行后，文件夹会新增虚拟环境、数据和插件。对外分享时使用未运行过的干净发行副本，
不要把自己的 `.nexus-data`、`credentials.json`、会话、附件、日志或已安装插件一起复制出去。
