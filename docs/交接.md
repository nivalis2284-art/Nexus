## 这是什么

`..`（本仓库根目录，即 `Nexus/`）是**从旧项目 LingNexus 重构出来的新 Agent 系统**。旧项目位于 `../Ling`，保持原样，只作参考，不再改动。

它现在的定位：一个干净的最小 Agent（循环 → 模型 → 工具 → 回灌 → 停止）。没有数据库、没有记忆、没有人格。

**但长期方向不是 coding agent**，而是一个持续存在的 Agent。所有者原话见 `暂缓项.md` 第二条。这一点影响很多设计取舍——比如不需要多会话管理。

---

## 怎么跑

```
双击 start.bat
```

首次会自动建 `.venv` 装依赖，然后开 `http://127.0.0.1:8766`。

**首次使用必须先配 API Key**，否则所有请求返回 400「还没配置 API Key」。点右下角「设置」填 Base URL、模型名、Key。

数据目录：由 `NEXUS_HOME` 决定；未设置时在 Windows 上取环境变量 `LOCALAPPDATA` 下的 `Nexus` 目录（实际路径因人而异，可用 `.venv\Scripts\python.exe -c "from nexus.core.config import default_home; print(default_home())"` 查）。里面有 `config.json`、`credentials.json`、`sessions/*.jsonl`、`skills/`。删掉它等于全新开始。

运行测试：

```
.venv\Scripts\python.exe -m pytest tests -q
```

## 踩过的坑（省得重踩）

**写文件必须截断。** `open_file(path,"write")` 在已打开的 fd 上包 `"wb"` **不会截断**，只设置模式。写短内容会残留旧尾部——这是个真实的数据损坏 bug，已修（显式 `ftruncate` + `lseek`），并有 7 项回归测试。**改这块代码时不要退回原写法。**

**工具在 worker 线程执行。** `asyncio.to_thread` 意味着 `ask_user` 等在子线程里跑，可能和事件循环同时写 socket。`emit` 有每轮一把锁，别去掉。

**人工确认必须可取消。** 提问/审批会阻塞。如果客户端断开而等待没被唤醒，运行锁会被占住很久，所有新消息 409。`Approvals.cancel_all()` 是唯一释放点，chat 的 `finally`、断开、中止三处都会调。

**测试里读 chunked 流别用 `urllib`。** 它拿不到事件但也不报错，会让人误判成"服务端没发"。用原始 socket。

**Windows 上 `npx` 是 `.cmd`**，`subprocess` 不能直接执行，报错还是误导性的"找不到文件"。`mcp.py` 的 `resolve_command()` 处理了。

**测试 fixture 要钉协议。** 默认 profile 是 Anthropic，假造 Chat Completions 帧时必须显式指定 `api_family`。

## 已知的限制（不是 bug，是还没做）

- **没有沙箱**：`yolo` 模式等于完全放手，没有中间档
- **没有 LSP**：改代码靠 grep
- **`websearch` 只有接口**，没接端点；`webfetch` 需配置白名单才出现
- **没有成本统计**：只记用量，不算钱
- **会话格式未版本化**：JSONL 格式没做过迁移

这些都记在 `暂缓项.md` / `待定项.md`，不要重新提出讨论，除非有新的实际需求。
