## 各文件夹的用途

| 文件夹 | 用途 |
| --- | --- |
| `愿景/` | 长期方向：`01-概念与原则` 是最高宪章，`02-具象理想` 是当前认知与技术限制下的理想形态，不是任务清单。 |
| `当前阶段/` | 目前阶段的任务文档：需求、研究、交付与验收都放这里。阶段结束后不再逐份整理，整个文件夹的内容直接打包移入 `参考/archive/<日期>-<阶段>/`。 |
| `参考/理论/<主题>/` | 理论与研究材料，按主题分文件夹存放；其中已过时的材料放该主题下的 `历史参考资料/`。 |
| `参考/其他/` | 不便归入理论的参考材料。 |
| `参考/archive/` | 历史阶段归档：每个子文件夹是一个已完成或被取代阶段的完整快照。保留当时结论；归档不代表验收通过，不作当前约束。 |

## 文档应该放在哪

- 当前阶段的任务文档 → `当前阶段/`；
- 理论与研究材料 → `参考/理论/<主题>/`；过时后移入该主题的 `历史参考资料/`；
- 不好归类的参考 → `参考/其他/`；
- 阶段完成或文档被取代 → 移入 `参考/archive/<日期>-<阶段>/`，归档时不重新整理内容；
- 移动任何文档时同步修正指向它的链接，不改写文档当时的结论。
