后台任务的产品语义按本会话确认：**同一会话跨轮保留，服务退出时结束，不做重启恢复**。子代理启动的任务归属父会话。停止当前 Agent 不等于停止已经登记的后台任务，后者可以继续在该会话中查询并用 `job_kill` 停止。

原始会话与模型工作上下文分开处理后，保留了旧 JSONL 的读取兼容性；没有做破坏性迁移，也没有用摘要覆盖完整历史。已有没有结构化状态的旧工具记录仍按兼容回退显示，不能据此恢复当时未保存的真实错误状态或参数。

## 4. 资源优化的前后证据

原 Agent 在每次模型请求期间把全部 ModelEvent 存入 `turns` 列表，后续从未读取。现仅保留业务需要的文字、思考、完整工具调用和本轮待保存消息，底层协议 continuation 保持不变。

可复现脚本：

```powershell
.\.venv\Scripts\python.exe tests/benchmark_stream_capture.py
```

脚本从 Git 基线 `6c3729f` 加载旧 Agent，和当前 Agent 在同一解释器中分别消费相同 30,000 个文字片段；预热后各测 3 次。网关为模拟实现，不含真实网络、提供商等待和协议解析；用 tracemalloc 计 Python 分配峰值。

| 版本 | 三次峰值（bytes） | 中位数 |
|---|---|---|
| 基线 | 6,741,925 / 6,740,683 / 6,740,763 | 6,740,763 |
| 当前 | 2,685,441 / 2,687,012 / 2,685,131 | 2,685,441 |

该合成路径峰值下降约 **60.2%（约 4.06 MB）**。这是无效事件保留减少的证据，不是整个进程 RSS、所有长会话内存或模型响应速度的承诺；耗时不作为产品提速结论。

后台任务的改进另有功能证据：无换行输出可以在进程结束前读取；分块 UTF-8 不损坏；已退出任务的后代不再继续持有输出管道；裁剪后 cursor 不会漏掉最新输出。这些属于资源管理和结果正确性改善，不编造吞吐提升比例。

研究阶段的会话列表合成测量尚未证明真实使用存在瓶颈，因此保留现有 JSONL 列表读取，不增加缓存/索引/数据库。没有为了性能取消 fsync，也没有更换前端框架。

## 5. 本地参考与重要方向调整

- 确认本机 OpenCode 部署入口 `...\Programs\@opencodedesktop\resources\opencode-cli.exe`，版本输出为 `opencode v2.0.30`。它是打包分发，未将其二进制内部实现当作已经审阅的源码。
- 实际阅读本机 DSH 的 `...\Programs\DSH Desktop\resources\app\node_modules\@deepseek-ai\dsh-session-persistence-jsonl\lib\index.js`：它将持久化事件与读取投影分开处理。此处借鉴职责边界，用最小的本轮消息记录修正保存，不照搬其格式迁移、所有权和缓存体系。
- 实际阅读 DSH 的 `dsh-user-questions/lib/index.js` 中 `TimedQuestionWait` 及 `dsh-subagent/lib/index.js` 中取消/父运行约束：人工等待与子运行应受父运行生命周期约束。Nexus 采用现有授权通道和共享 Event，没有引入 DSH 的插件系统或远程协议。
- 阅读 DSH `dsh-compaction-basic/lib/index.js`，核对其工具配对边界与上下文职责；沿用 Nexus 已有摘要结构和阈值，以本项目真实内部消息形状修复估算和裁剪。

全局方向没有偏离：保留模块化单体、标准库 HTTP、原生前端、HTTPX/Pydantic、JSONL 和独立 HTML 文档。没有制定或执行大规模框架迁移。新增启动 helper 是为修复已证实的入口失效和 Windows 引号问题，前端改动局限于原有图片与工具展示。

相比研究清单，增加了开发中实际发现的新文件创建失败、全新 home 无法加载设置、断流后悬空工具交换、重命名与追加覆盖以及退出登记窗口的修复；均服务于既有关键路径，未新增业务能力。没有强行清理所有重复代码或把愿景材料加入需求。

## 6. 当前限制与保留债务

- **真实提供商尚未验收。** 三协议及思考/工具/图片仍以 fixture、模拟服务及真实本地 MCP stub 验证；未使用真实账户、计费服务或付费模型，真实兼容网关仍需按实际配置复核。
- **停止仍有明确边界。** 前台命令可响应停止事件，人工等待会被唤醒，父子在检查点共享停止；已经开始的文件写入允许结束。等待真实模型或 MCP 响应时仍可能受其响应和超时约束，不保证即时撤销外部操作。
- **摘要不替代原始会话。** 本轮压缩后的结果保存已修复；摘要质量、真实 token 成本及跨轮复用摘要尚未实测。仍从完整会话重建工作上下文，可能重复摘要，不以删除历史来规避。
- **POSIX 路径未在本轮实机运行。** 进程组清理已实现，但本轮进程树实测环境为 Windows；不把 Windows 结果扩写为 Linux 全面兼容。
- **未做断电/崩溃恢复验收或新并发体系。** 保留现有服务级单运行锁，不增加计划模式、跨会话并行或重启恢复后台任务。运行中的会话不能删除，以免正在保存的消息被删除操作覆盖。
- **低价值整理保留。** `_fold` 与同步摘要入口的局部重复、hash 检查重复，以及未证实瓶颈的会话列表/前端流更新成本，未机械重写。后续需要新证据才扩大处理。
- **环境备份保留。** 本机旧环境位于 `.venv.invalid-20261019-150010`，已加入忽略规则；当前 `.venv` 可用。没有删除用户数据或旧环境，备份是否日后清理由所有者决定。
