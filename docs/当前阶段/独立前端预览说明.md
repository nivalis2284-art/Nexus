## 打开

在仓库根目录执行：

```powershell
.venv\Scripts\python.exe -m http.server 8767 --bind 127.0.0.1 --directory redesign-preview
```

浏览器访问 `http://127.0.0.1:8767/`。也可双击 `redesign-preview/start-preview.bat`；同一端口已有服务时无需重复启动。

## 预览路径

| 入口 | 可操作内容 |
| --- | --- |
| 主交流 | 发送、模拟流式回复、停止、输入排队、恢复、选择模型和强度、关联工作 |
| 消息操作 | 复制、编辑重发、删除、撤销；已压缩消息通过摘要管理 |
| 附件 | 选择、拖放、粘贴图片、数量与大小限制、本地保存、查看、下载 |
| 灵岛 | 工作列表、快览、展开详情、全部挂起、回到关联工作输入 |
| 工作详情 | 状态、目标、约束、模型、父子关系、步骤验证、证据、记录、附件、未确认事项 |
| 主交流待处理事项 | 问题选项／自由输入、审批允许／拒绝、结果待核对 |
| 上下文 | 指令增删改、三个角色全文、自动组装来源、摘要编辑、历史全选／多选删除／撤销 |
| 设置 | 多提供商、三类协议、模型及上下文窗口、密钥、基本原则、权限与工作目录 |
| MCP | stdio／HTTP 字段、连接状态、工具数、错误、增删改、启停、重连、托管服务 |
| 技能 | 个人／项目／内置，覆盖关系、只读、新建、编辑、删除、刷新 |
| 插件 | 发现、演示包导入／替换、加载、停用收尾、停止在途、重载、卸载、详情、设置与功能页入口 |
| 请求记录 | 活动与类型筛选、详情、参与材料、最终 JSON、加载更早 |
| 右上角预览控制 | 空态、交流、流式、审批、未知结果、子代理／排队、完成附件、挂起、连接异常、重置 |

后台行为是有限的本地模拟：在主交流交代“阅读／整理／检查”等要求可派发工作；选择工作后可输入“挂起／恢复／取消”。预览控制可直接进入验收场景，不运行真实工具。

消息和设置保存在 `localStorage` 的 `nexus-redesign-preview-v1`；选择的文件保存在 IndexedDB 的 `nexus-preview-files`。清除浏览器站点数据会清除预览；正式 Nexus 数据目录不受影响。所有密钥和请求记录均为演示值。

## 文件

- `index.html`：页面骨架与图标。
- `ling.css`、`motion.js`：附件继承的样式与弹簧曲线。
- `preview.js`、`preview.css`：主交流、工作、公共弹窗、本地状态、蓝紫主题和响应式。
- `settings.*`、`extensions.*`、`context.*`：管理模块。
- `roles.js`：从当前项目默认角色生成的预览内容。
- `assets/`、`vendor/`：本地字体与项目已有 Markdown、安全清洗、代码高亮库。
- `check.cjs`：隔离浏览器配置中的关键流程检查，不调用模型。

本轮不包含真实模型调用、服务连接、插件安装、系统文件操作或原生手机 APP。真实执行结果用演示状态呈现。
