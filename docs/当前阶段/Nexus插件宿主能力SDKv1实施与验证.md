# 插件宿主能力 SDK v1 实施与验证

日期：2026-10-29。范围：宿主 SDK、语言无关桥接和 Python／Node 示例，不迁移记忆插件、不实现 QQ 或人物团。

## 实现

插件通过公开命名空间选择能力，不导入 Application 私有状态。`requires_host` 独立声明能力版本，保留 `api_version: 1` 和所有旧入口。接口、示例与恢复协议见 [SDK 文档](../../mobile-bridge/sdk/v1/README.md)。

- 模型服务复用 ModelGateway、现有协议转换与原生续接；嵌入使用独立配置入口。模型密钥不返回给插件，调用不自动继承主交流材料。
- 独立对话不经过 LingInbox 或 Agent 执行队列，每次只执行一轮生成；插件显式提交工具结果。共享分块摘要组件，完整原始历史保留。
- 主交流继续保存 JSONL，通过记录 ID 和内容版本建立历史快照与变化登记。旧文件首次迁移保留备份，位置及检查点 through 语义不变；缺失时间不伪造。
- 插件作业、对话、操作和变化事件保存到 plugin-runtime.sqlite3。作业使用独立执行位、版本化处理器、显式 recover 与尝试标识；取消不恢复，旧尝试不能覆盖新结果。
- 本机桥接独立于 Web Handler，凭据绑定插件与加载生命周期。远程服务通过现有 MCP 入口接线，支持无 Python 入口的 Node 插件。SDK 自动传递服务调用链及适用的作业归属。
- 插件设置和凭据分开保存。服务按提供插件命名、版本发现和调用；不共享其他插件内部数据库。
- 宿主插件详情可查看能力、依赖、服务、对话和作业，支持查看历史、取消和重试。没有增加另一个用户聊天入口。

## 约束

这是可信插件能力契约，不是进程沙箱。取消是合作式的，本地处理器应有限时间返回，长任务使用 jobs。重启恢复仅调用注册的 recover，不恢复语言调用栈、不承诺外部副作用自动幂等。独立语言运行时由使用者安装。

## 定向验证与交付

65 项相关 Python 检查通过，包括三种协议、本地模型 HTTP、真实 MCP、纯 Node 插件、历史迁移、恢复与取消，以及旧插件、应用、会话和主交流压缩。收尾对历史时间修正仅复测受影响项。前端行为脚本 6 项通过，隔离 Chromium 验证新增管理流程。

只使用临时数据与模拟提供商。没有操作日常实例，未进行真实云端调用或 Windows 实机验收，未执行全量回归、压力测试。SDK、两个可安装示例和包校验信息见 [发布说明](../../mobile-bridge/docs/HOST_SDK.md)。旧发布包及记忆包未改动。
