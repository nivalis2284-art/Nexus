## 动效改造

针对“不够灵动、不够丝滑”，逐项处理：

1. 消息入场从 700ms 雾化改为 300–380ms 位移/透明度；用户消息保留轻微回弹。
2. 流式文字改为逐片段追加纯文本，光标跟字尾；结束时交叉淡入完整 Markdown，避免每 20ms 重排整段。
3. 消息列表增量渲染，只追加新节点；阶段内新增步骤就地插入，不再 `replaceChildren` 整段搬运。
4. 请求栏显隐时用 FLIP 让交流区滑移；页面切换改为旧页先退场、新页再逐组件浮入，避免两页重影。
5. 折叠区使用 `::details-content` 高度过渡（渐进增强）；弹窗、菜单、文件预览补上退场动画。
6. 交互反馈与形变分开：悬停/按压 180–240ms，灵岛与液滴继续使用弹簧；弹窗改用更短的 pop 弹簧。
7. 补齐原稿的日期分隔、编号脊柱、派发小片、结果卡、朱砂“决”印；处理中显示液态三点。
8. 气场换色在 `body` 上过渡；灵岛形变期间加 `will-change`，结束后清除。
9. 管理页更新时保留滚动位置，且只在首次进入时播放错峰入场，避免编辑后整页重播。
10. 上下文页单独编排：标题下落、概览浮入、量表分段生长（scaleX）与百分比递增、页签墨迹滑动、指令行/角色卡/组装段依次登场；入场总时长约 0.8s。
11. 标题、卡片、行、按钮使用不同方向（下落 / 上浮 / 左滑）和不同时长，避免整页一个淡入。
12. 主交流补充：新回复的 Markdown 块逐段浮现；发送键波纹与输入舱回弹；后台回报到达时左侧短暂留一道墨线；空态光球缓慢浮动；消息头/气泡悬停微动。
13. 主题系统：两套双色主题（暖色灵青·朱砂、冷色浅蓝·淡紫），每套都有浅色与深色；冷色套同时替换纸、墨、灵岛为冷色中性；气场由主色/强调色与纸色混合推导，光球、量表、派发环、技能字形全部跟随主题。
14. 动效速度：快 ×0.72 / 适中 ×1 / 慢 ×1.35，统一作用于页面切换、消息入场、灵岛形变、折叠区、弹窗、流式节奏与悬停反馈；实测页面入场 432 / 600 / 810ms，错峰延迟 24.5 / 34 / 45.9ms。
15. 界面设置即时生效并持久化；明暗切换从按钮圆形扩散，主题色从色卡圆形扩散，避免整页突然换色。

## 界面设置与主题

- 设置页新增「界面」：动效速度（快/适中/慢，含预览）、明暗模式（浅色/深色）、两套主题色卡（双色色带 + 选中态）。
- 配色原则：暖色套用互补色（约 156°）制造冷暖对比；冷色套用邻近色（约 35°）保持安静，再用明度差让强调色仍可分辨。强调色只用于待决定、提醒与朱印。浅色下 `--jade-ink` / `--cinnabar-deep` 达到约 4.5:1；深色下主色/强调色提亮，并用 `--on-primary` / `--on-accent` 决定彩色面上的文字明暗。
- 暖色套保留纸/墨中性色；冷色套把纸、墨、灵岛也替换为冷色中性，避免“冷强调色压在暖底上”。每个主题的浅色和深色都单独取值，不是简单反相。
- 主题与速度保存在 `localStorage`，刷新后保持；预览重置会恢复默认（灵青·朱砂 / 浅色 / 适中）。

- `node nexus-preview/check.cjs`：主流程、六页、提供商/MCP 对话框、夜间、手机截图，通过。

- `node nexus-preview/themecheck.cjs`：两套主题、浅/深切换、速度倍率（页面入场 432 / 810ms）、刷新持久化，通过。

## 取舍与边界

- 工作详情沿用原稿的灵岛大面板（手机全屏），而不是正式前端的侧栏面板；这是设计稿已确认的承载方式。
- 手机端插件列表为横向卡片，请求记录为上下布局；字段与操作不减。
- 插件功能页用本地 `srcdoc` 演示页，不读取真实插件文件；请求记录、模型回复、工具执行均为演示状态。
- 未接后端、未改正式前端 `nexus/web/`；真实模型、真实工具、插件安装与持久化未验证。
- 直接双击 `index.html` 可预览；`start-preview.bat` 仅用于本地静态服务。
