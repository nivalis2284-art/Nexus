# Nexus 插件页面统一渲染 v1 实施与验证

日期：2026-10-30。交付：宿主页面渲染协议、公共组件、Python／纯 Node 示例及 1.1.0 包。保留旧 HTML 模式，不迁移记忆插件，不安装到日常实例，不提交或推送。

## 实现与契约

- 复用现有页面声明与 `PluginManager.call`，新增按已声明页面分发的 HTTP 入口，保持原有生命周期租约。`ui v1` 作为可发现的能力依赖，旧宿主明确拒绝新示例。
- 插件返回版本化 JSON 页面，宿主校验组件、字段及标识后渲染。支持行列、分区、文本、标签、代码、表单、按钮、列表、表格、分页、编辑弹窗和确认操作。不执行插件 HTML／脚本，不接收自定义 CSS 或动画。
- 新页面直接在宿主 DOM 中渲染，继承主题及控件样式；首次内容入场复用 cascade，列表增删使用公共动画函数，弹窗使用提取后的公共开合入口，响应动效速度及减少动态效果。
- 稳定组件 ID 复用元素，普通宿主状态刷新保留页面、输入与焦点。提交期间显示状态并阻止重复提交，错误后保留草稿。退出页面、切换插件或停用后释放页面及弹窗，取消前端等待并忽略迟到响应。
- 页面上下文只保留当前页面状态；插件持久化仍由插件处理。关闭页面不承诺撤销已提交的业务操作，首版无后台推送或实时流式页面传输。
- 两个示例使用相同的内容声明、各语言的页面控制器；保留模型、服务、作业和独立对话演示。新增备注编辑只存示例自己的设置，不操作记忆库。

完整格式、默认值和组件属性见[页面协议](../../mobile-bridge/sdk/v1/UI.md)。安装包与校验信息见[发布说明](../../mobile-bridge/docs/HOST_SDK.md)。

## 最小充分验证

- `tests/test_host_sdk.py`、`tests/test_plugin_manager.py`、`tests/test_plugin_http.py` 共 31 项不同检查最终通过。首次新增用例错误使用了不存在的卸载方法，改为已有管理入口后仅复测受影响项。收尾兼容调整及协议校验定向复测 5 项通过，不重复累加。
- `node tests/frontend_behavior.cjs`：7 项通过，包含实际发现的全局点击处理器干扰其他页面按钮状态的回归检查。
- 临时 Application、临时插件目录、本地 SSE 模型与实际 Chromium：Python 和纯 Node 页面打开、独立对话发送、收集流式事件、备注编辑及字段校验、焦点恢复、状态刷新保留草稿、重复提交阻止、错误后保留输入、关闭后忽略迟到响应。
- 浏览器定向检查数字／布尔／选择值保持类型、列表增删及草稿焦点；关闭页面可取消它打开的宿主确认框。首次内容调用公共入场动效，普通数据更新不重播整页入场。
- 检查昼夜与配色切换、宿主动效速度、减少动态效果及 390px 窄屏布局。实际查看主题切换结束后的桌面与窄屏截图，外观与宿主一致。
- 新发布 ZIP 的 CRC、页面声明、文档和文件清单通过检查；不含凭据、数据库或缓存。旧 1.0.0 三包及记忆插件包 SHA-256 均保持不变。

没有执行全量回归、压力测试或另建构建测试设施；没有真实云端调用和 Windows 实机验收。验证通过后停止，不重复运行已通过的检查。
