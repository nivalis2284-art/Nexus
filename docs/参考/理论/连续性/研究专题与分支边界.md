# 连续性研究专题与分支边界

更新：2026-10-26。

状态：理论研究的专题划分与会话入口，不是已经成立的理论、实施计划或功能清单。各专题可以修订本划分，不要求最终对应独立模块、数据库或服务。

## 一、共同目标与已确定的边界

- [《01-概念与原则》](../../../愿景/01-概念与原则.md)是最高标准；[《02-具象理想》](../../../愿景/02-具象理想.md)提供当前愿景。
- 所有者以记忆、自我、人格等数据资产及其积累与演化的延续判定同一性，不以“是否还是同一个意识”重新提出前置要求。各专题研究数据的内容、延续方式与实际作用，不另设意识判据。
- 当前 Nexus 已收敛为主交流与即时后台工作的承载底座。旧记忆、人设、自主活动和时间业务已退出日常运行；研究不自动授权恢复旧业务、修改代码或开展模型训练。
- 当前硬件与模型 API 条件，以及不以所有者持续组织微调代替自主成长的选择，沿用 02。不能把生成自我描述、随机话题、计划或定时唤醒直接宣称为连续性、自主学习或成长。
- 后续每个专题使用一个分支会话探索；本文先划定问题及衔接，不要求现在同时创建或启动全部会话。

## 二、先研究数据，再研究各类延续

此前讨论把记忆、认识、自我等作为研究对象，但还需要先回答：**受当前 LLM 使用条件限制，连续性究竟需要保留什么数据，如何从可获得的上下文与原始材料中形成这些数据？**

上下文是模型当次可见的材料，不等同于全部历史或完整世界状态。它可能同时包含原始消息、附件片段、工具请求与结果、规则、当前任务、旧摘要和模型推断。重复进入上下文的内容不代表新发生了一次经历；上下文里提到一项行动，也不证明行动已经执行。

“从上下文转化”先作为研究问题，不预设所有内容都必须经过同一轮抽取、摘要或结构化：

- 已保存的消息、文件或工具原件，可以继续作为来源；不一定要从拼装后的上下文反向提取一遍。
- 一些用途可能需要概括或解释，同一来源也可能支持不同用途的数据表达。
- 一次转换可能丢失条件、归属或不确定性；后续也可能需要从来源重新解释，而非不断压缩旧摘要。
- 宿主无法获得的模型内部状态不能假定可被完整导出；模型关于自身过程的文字也不能直接作为该内部过程的记录。

因此，共同来源与各专题的数据表达需要分别研究；是否需要统一的中间表示、哪些内容可以共享，都保持开放。

## 三、专题总览

下表的“候选数据”是待比较的语义内容，不是规定字段、格式或必建的数据层。

| 编号与会话主题 | 核心问题 | 候选数据与研究产物 | 不由本专题直接解决 |
| --- | --- | --- | --- |
| **00 连续性的数据基础：从上下文到可延续资料** | 连续性需要什么信息？来源是什么？哪些应原样保留、选择性解释或暂不转化？ | 来源与上下文的区别、信息类别、转化候选、遗漏与失真案例，以及后续专题可使用的少量共同样例 | 不预先建立万能数据模式，不替各专题定义全部表达方式 |
| **01 经历的组织、回忆与情境使用** | 哪些材料构成一段经历？过去怎样在当前情境中被适当地取回和使用？ | 事件经过、时间、参与者、行动归属、背景与来源；明确概览、精确回忆、联想分别需要什么 | 不把召回正确当作认识或行为已经改变 |
| **02 当前认识的形成与修订** | 什么经历支持什么判断？新证据、纠正或所有者新决定出现时，当前认识如何变化？ | 事实主张、经验判断、依据、适用条件、反例、未决问题与认识变化；区分不同更新理由 | 不把最新文字一律视为更可信，不把认识修订直接称为人格成长 |
| **03 自我模型与关系理解** | 关于自身能力、限制和所有者的理解，怎样形成、使用与纠正？ | 能力判断、已知失误、对自身的认识、对他者的理解、共同经历及关系变化；比较自述与行为依据 | 不研究意识同一性，不把人物标签或自我介绍当作充分结果 |
| **04 人格与行为倾向的延续和变化** | 除了复述设定，哪些稳定而可变的选择方式值得称为个体倾向？ | 初始设定、所有者原则、模型既有倾向、经历形成的倾向与跨情境行为；研究这些内容如何区分和相互影响 | 不预设固定性格量表，不把权威规则降为普通偏好，也不要求凭空长出无先验人格 |
| **05 持续意图、承诺与关注** | 一件尚未完成的事、疑问或关注，怎样跨时间保留意义，并被继续、修订或结束？ | 意图的来源与理由、承诺内容、仍然成立的条件、进展、撤回及关注变化；区别“记得”与“决定行动” | 不恢复定时业务，不以触发方式解决动机问题，不宣称已经形成自主兴趣 |
| **06 多活动分支的经历归属与整合** | 主交流、后台工作和其他活动之间，哪些经历可以共享，谁实际经历或知悉了什么？ | 行动与观察的归属、计划与结果、假设与实际事件、材料交付情况、不同分支认识的差异及整合理由 | 不默认多分支等于多人格，不预设集群架构，不把全局有记录当作各分支都已理解 |
| **07 跨上下文与跨模型的重建、迁移** | 上下文清空、压缩、换模型或换宿主后，哪些数据应延续，怎样再次发挥作用？ | 需要延续的资产、可替换的解释或索引、重建材料、迁移前后可观察的保留与变化 | 不重新讨论是否同一个意识，不承诺不同模型表现一致，不以资产可加载证明使用效果相同 |

## 四、专题 00 的起始研究范围

这是第一个分支的主问题，不要求一开始回答全部专题。

### 1. 需要什么数据，由用途来判断

用几段相同的交互材料，分别问：为了回忆经过、修订认识、认识自身、延续行为倾向或保留意图，需要保留哪些信息？哪些信息必须共享，哪些可以不同？不先规定“一条记忆”必须长什么样。

可先区分并比较以下内容，而不要求每段上下文都生成全部类别：

- 谁在何时表达、观察、尝试或实际完成了什么；
- 当时处于什么条件，为什么作出选择，结果如何；
- 哪些是所有者的指令、原则或偏好，哪些只是对事实的说法；
- 哪些属于推断、假设、计划、引用或未核实结果；
- 哪些是旧材料被再次读取，哪些是新出现的信息或变化；
- 哪些仍是短期现场，哪些可能值得跨周期保留。

### 2. 比较转化方式与信息损失

至少讨论原始记录直接保留、自然语言笔记或摘要、较明确的结构化表达，以及保留来源并允许多种解释这些候选。比较它们分别适合什么用途，不预设一种形式普遍最好，也不因更结构化就推定更准确。

重点观察：压缩是否抹掉转折、自动抽取是否误把推测变成事实、是否把旧规则当成现行要求、相同材料是否被重复算作多份独立经历，以及后续还能否纠正最初的解释。

### 3. 用连续案例明确待检验主张

可围绕“接受工作—尝试失败—重新解释原因—所有者修改目标—后续相似情境”构造少量明确标记的研究案例。案例不冒充灵的实际经历，也不作为已经有效的实验结果。

先说明不同表达保留和丢失了什么、它可能怎样影响后续专题；实际模型能否稳定完成转化、成本是否可接受，留作后续验证问题，不能仅凭文字示例宣称已解决。

本专题的阶段产物是：问题边界、几种候选表达的比较、共用样例，以及需要后续专题继续决定的数据要求。无需先确定数据库、接口、抽取模型或自动运行方式。

## 五、研究顺序与会话间衔接

1. **先开展 00。** 得到可供讨论的数据问题与候选表达，不要求先建成统一数据底座。
2. **接着研究 01 与 02。** 两者可以分别讨论，但需区分“过去如何提供”与“当前如何判断”，避免互相假定对方已经解决问题。
3. **再按问题进入 03、04、05。** 可以从自己的例子研究所需数据，并反向修订 00；不需要等待完整记忆系统完成。
4. **06 与 07 贯穿核对，深入研究按需要展开。** 初期保留必要的时间、归属和来源问题即可，不为后续迁移或多分支预建复杂体系。

以上是研究顺序建议，不是所有特质必须按单一路线实现的依赖证明。专题可以并行阅读资料，也可以得到“现有条件下暂不成立”的结论。

为避免会话相互污染，每个会话聚焦一个专题；跨专题影响在该专题研究稿中简要标出，后续会话从需要的结论与样例接续，不默认继承其他会话的全部假设。未验证结论与已确认的所有者选择应分清。

## 六、与已有记忆研究的关系

[《持续个体记忆理论 V0.3》](../长期记忆/历史参考资料/持续个体记忆理论-V0.3.md)是重要参考：第 4.1、4.4、6.1 节涉及来源、事件、情境与摄入；第 7 节涉及认识、自我、前瞻及技能；第 8 节涉及活动分支；第 10—11 节给出假设与验证设计。

它已提供一套语义与机制候选，不是本轮从零发明这些问题。但事件块、多维团、派生投影、来源谱系及各机制的组合，不能仅因已写入论文就成为各专题必须接受的前提。可以复用、澄清、简化、反驳或提出替代解释；暂不改写原论文，也不以新专题数量推动版本升级。

原型迁出只改变日常运行状态，不等于理论已被证伪或已获验证。需要引用旧成果时，分别说明理论提案、原型实际行为与实测结果的依据。

## 七、每个分支共用的研究入口

开始会话时，指定本文件及专题编号，沿用以下范围：

> 以 01 为最高标准，02 为愿景背景，只研究本次指定专题。先明确它试图延续什么、需要什么数据、怎样从可获得材料形成，以及哪些证据可以支持或否定候选解释。已有论文仅供参考，不预定架构、字段或工具。区分所有者的价值选择、文献结果、研究假设和未解决问题；不以自我叙述或形式上的流程完成宣称能力达成。本轮以理论为主，未另行授权前不接回业务、不修改运行代码、不提交或推送。

研究结果留在本目录下对应专题的研究稿中；只在确有跨专题结论时更新本文的边界或导航，不为每个专题预建重复的计划、进度和验收文档。
