# 多维记忆组织系统

**概念起点：** 记忆空间是事件块、记忆团、关联、维度状态及其他记忆表达共同存在的整体。事件块是对一段可独立辨认、语义完整的已发生事件所作的客观压缩记录，是记忆空间中的最小基础单位。维度围绕一种记忆用途，规定如何选择、组织和更新事件块，以及如何以适合该用途的形式表达它们；不同维度可以采用不同表达形式。

**版本：** 0.3，专题研究稿；六个研究问题的首轮设想。

**日期：** 2026-10-26。

**前版：** [专题研究稿 0.2](多维记忆组织系统-研究稿.md)。从该版复制后迭代；此后每轮建立独立版本副本，不覆盖既有稿件。

本文从[持续个体记忆理论 V0.4](../历史参考资料/持续个体记忆理论-V0.4.md)中收敛出独立专题，按本次讨论重新明确概念与边界。[持续个体记忆理论 V0.3](../历史参考资料/持续个体记忆理论-V0.3.md)、V0.4 已归档且保留原文。专题原稿也按原文保留，其中归档前的相对链接以本版提供的新位置为准。本文不预设依附于 LingNexus，不是实现方案，也不宣称所述机制已经验证有效。

本稿继承 V0.4 中有关事实与理解分层、共享事件、组合与关联的区别，以及更正和理解修订的概念基础，并按本专题范围重新表述。这些内容用于明确研究对象及其关系，不作为聚合、关联或维护方法已经有效的实验证据。

## 1. 前提与研究范围

> **事件块已经由外部提供。本文研究这些事实单元进入系统之后，如何被组织、组合、关联、解释和修订。**
>
> **记忆如何被取出和使用不在本文研究范围内。**

本文关注事件块进入记忆空间后的内部组织：维度如何规定组织方式，事件块如何聚合，记忆团如何形成主题理解，关联如何构成网络，以及这些结构如何随新事实和认识变化而修订。

从上下文或其他来源提取事件块、触发写入、接入 LLM、提出查询、检索与排序、联想路径的实际访问、输出组装和宿主使用，均不在本文展开。其他研究可以使用这些内部结构，但其取出和使用方式不由本文规定。

“维度规定使用规则”中的使用，指事件块在该维度中承担什么作用、形成什么记忆表达；本文只讨论与内部组织有关的部分，不据此扩大到调用者如何使用记忆。

## 2. 概念及其边界

| 概念 | 本文采用的表述 | 需要避免的歧义 |
| --- | --- | --- |
| 记忆空间 | 事件块、记忆团、关联、维度状态及其他记忆表达共同存在的整体 | 不仅是存放事件块的容器，也不预设采用某种数据库 |
| 事件块 | 对一段可独立辨认、语义完整的已发生事件所作的客观压缩记录，是记忆空间中的最小基础单位 | 客观记录与上层理解分开；最小单位不等于最短句子 |
| 维度 | 围绕一种记忆用途，规定选择、组织、更新和表达规则 | 不等同于向量坐标、标签、图层或记忆团的分类目录 |
| 记忆团 | 多个相关事件块围绕某个主题形成的组合及其概括性理解与总结 | 不仅是成员集合；概括不需要逐条重述具体事件 |
| 关联网络 | 记录事件块之间可辨认联系及其可选强度的结构，允许通过共同中介形成间接关联 | 连通或相似不自动代表因果，也不自动支持同一解释 |
| 维度状态 | 某个维度当前保有的组织结果和理解状态 | 不要求每个维度都有独立进程、数据库或固定格式 |

### 2.1 “完整事件”与“最小单位”

完整指压缩后保留理解和辨认该事件所必需的信息，如相关人物、行为、对象、时间、条件和结果；仅在实际已知且与事件有关时保留这些信息，不补造缺失内容。完整不要求把一项长期事务的全部过程装进一个事件块。

最小指本文在组织层面将事件块作为基础单位。本文不研究如何拆分或生成事件块，也暂不把“一段完整事件”额外限定为“只能包含一个事实命题”。这一粒度与 V0.4 的单事实原子表述存在需要进一步统一的地方，本稿先明确保留该问题，不通过换词假定已经解决。

事件块只压缩发生过的事实，不添加动机、意义或一般规律的解释。“某人提出了一个判断”可以记录为事件；该判断是否成立，不能仅凭它被说过就认定。

### 2.2 共享基础与不同表达

同一个事件块可以参与多个记忆团，也可以同时被多个维度使用，不因每次参与而成为一个新的事件。例如，人物主题、时间主题和事务主题可以引用同一事件块，而不分别形成三个事实版本。事件块的共享身份与某个主题怎样理解它，是不同信息。

不同时间重复发生的相似事件仍是不同事件；表述相同也不意味着指向同一次发生。本文保留这些身份区别，不在此研究自动识别重复事件的方法。

维度高于具体组织形式。它可以使用记忆团，也可以直接使用事件块形成其他表达，不要求所有维度都采用“事件块聚合为记忆团”的过程。

事件块、记忆团和维度之间不构成互斥归属的单一树。维度 A 中的多个主题可以共享成员，其他维度未来也可以采用不同表达；本稿仅保留这种可能性，不提前展开其他维度的规则。

### 2.3 事实记录与上层理解

事件块保留外部提供的客观记录，记忆团承担对相关记录的理解与概括。一次观察、一次发言与由此得出的判断分别表达不同内容：“某人说事情已完成”记录的是完成报告的发生，不能仅凭这次报告就概括为事情确已完成。

记忆团可以包含解释、假说和待确认的认识，但应区分哪些内容直接见于事件块，哪些是组合后形成的判断。对动机、意义和规律的理解属于上层；重新整理这些理解，不会使它们自动变成新发生的事件。

同一事件块被多个团引用、同一概括被反复改写，都没有增加新的独立事实依据。概括之间可以相互参考，但不能通过循环引用使缺少依据的判断成为已证实事实。

记忆团的理解发生变化，不等于事件本身被改写。对同一事实形成不同理解时，先检查各自关注的主题、适用条件和依据；表达不同不必然意味着事实冲突。

## 3. 当前研究的维度 A

**暂沿用名称：长期记忆。候选名称：经历记忆。正式名称待定。**

“长期记忆”体现持续保存，但不足以区别本维度与未来其他同样长期保存的维度。“经历记忆”更突出对已发生事件的主题理解和关联；它在本文中只是候选名称，不直接套用其他学科对同名术语的定义。

当前仅展开维度 A，研究其中两种组织机制：主题聚合与记忆团、事件关联与网络。二者可以共享事件块，不要求形成彼此隔离的两套资料。

### 3.1 主题聚合与记忆团

事件块可以依据语义相似性、共同人物、共同事务、时间范围或其他有意义的联系，参与一个或多个主题聚合。一个事件块符合多个主题时，可以同时参与多个记忆团；不要求在团之间进行互斥分配。

“被多个记忆团吸引”在本文中表述为：**同一事件块可以依据不同的主题相关性，参与多个记忆团。** 这里不预设物理吸引模型、具体聚类算法或固定归属数量。

记忆团承担对相关事件的主题性理解与概括。例如：

| 主题 | 可以形成的理解与总结 |
| --- | --- |
| 持续事务 | 事情怎样开始，经历了哪些转折，目前进展到哪里 |
| 时间范围 | 某段时间发生了哪些主要事情，有哪些变化或贯穿线索 |
| 人物 | 有事实依据的基本情况、相关经历概览及变化 |
| 其他主题 | 根据实际材料和用途提出，不预先列成必需类别 |

记忆团以主题概览为主，不要求逐条描述具体事件；但其概括应当与构成它的事件块保持依据关系。概括中包含的理解、解释或推断仍属于上层认识，不能反向成为事件块中的客观事实。

记忆团不仅表达“哪些事件在一起”，还表达“围绕什么主题，以及从这些事件中形成怎样的理解”。人物、时间、事务等标签可以帮助组织成员，但仅有共同标签还没有表达主题理解。

相同的事件块集合也可以形成不同记忆团。例如，一组任务中的尝试、失败和重试事件，可以分别形成事务进展概览和协作过程概览。差异来自主题与有依据的理解，而不只是更换标题、改写措辞或调整展示顺序。

主题概括可以突出不同线索，但不能因此逆转已知发生顺序，或将共同出现直接解释为因果。为了形成概括究竟需要保留哪些组织关系，仍属待研究问题，不要求每个团具有同样细致的角色或关系结构。

“吸收到足够多的事件块”更准确地表述为：**当相关材料足以支持某种概括时，形成或更新该主题的理解。** 是否足够取决于材料覆盖和支持程度，暂不规定事件块数量阈值，也不要求材料不足时生成完整叙事。

### 3.2 事件关联与网络

事件块之间可以因明确的共同线索建立直接关联，也可以经由共同人物、事务、情境或其他中介形成间接关联。主题上看似无关的事件，也可能因此处于同一关联网络中。

原先“事件应该如何联立起来”的表述，在本文中改为：**事件块之间可以依据哪些联系建立关联，以及这些关联如何共同构成网络。**

原先“按照概率互相关联”的表述，先改为：**关联可以具有强度或置信程度；是否采用概率表达，以及该概率描述什么，留待研究。** 关联存在的可信程度、联系的强弱与某次访问时选择该关联的概率不是同一概念。本文研究前两者的组织含义，不研究访问时的概率选择策略。

网络结构可以为未来的联想提供基础，但“给定问题如何沿网络展开，以及应当联想到多大范围”属于取出和使用研究。本文只讨论哪些联系被记录、联系表达什么，以及它们如何变化。

### 3.3 记忆团与关联网络的区别

两者可以先理解为**主题内聚**与**联系组织**的区别：

- 记忆团回答：这些事件围绕某个主题，可以形成怎样的总体理解与总结？
- 关联网络回答：这些事件之间存在什么联系，能否通过中介形成更远的联系？

提出者强调的“直接联系与间接联系”，体现了主题聚合与跨主题联想的不同侧重，可以保留为研究线索；暂不将其设成排他定义。网络也可以包含直接关联，记忆团也可能基于间接线索形成主题理解。是否同团与是否存在关联，分别表达不同信息。

同属一个记忆团，不意味着任意两个成员之间都有强关联；存在较强关联，也不要求两个事件属于同一个团。主题归属和事件关联可以相互提供线索，但不能仅凭其中一种就认定另一种成立。

内部组织还需要区分以下三种关系含义：

| 关系含义 | 表达什么 | 不能直接推出什么 |
| --- | --- | --- |
| 主题组合 | 哪些事件参与某个主题，以及这些事件怎样支持主题概括 | 任意两个成员之间都存在强关联 |
| 事件关联 | 事件之间存在什么可辨认的联系，或经什么中介形成间接联系 | 关联就是因果，或事件共同支持同一个结论 |
| 概括依据 | 某项理解根据哪些事件及其条件形成，更正哪些记录可能影响它 | 列出事件引用就已足以证明概括成立 |

这些是语义职责的区别，不要求实现为三张图或三个组件。网络连通、主题相近与结论得到支持应分别判断；关联的强弱也不能直接替代概括获得支持的程度。

## 4. 变化与修订

### 4.1 三类变化分别处理

本专题区分三类变化；不同变化不应都被描述为“更新记忆”：

| 变化 | 发生了什么 | 对内部组织的含义 |
| --- | --- | --- |
| 增加事件块 | 外部提供了新的事件记录 | 可能补充已有主题、促成新主题或改变关联；事情后来进入新状态，不表示过去状态从未存在 |
| 外部更正事件块 | 已提供记录被外部纠正 | 重评依赖被更正内容的记忆团、关联及当前组织状态；如何发现来源错误不在本文展开 |
| 修订理解与组织 | 既有事实未变，但比较方式、主题概括或联系判断改变 | 可以调整成员、概括或关联，不将新的理解伪装成新增经历，也不为了符合解释而改写事实 |

### 4.2 更正影响与依据关系

共享事件块使多个组织可以复用同一记录，也意味着一次更正可能影响多个结果。影响范围应根据实际依赖被更正内容的组织判断；它可能包括多个记忆团，也可能包括没有经由记忆团建立的事件关联。

重评不等于机械删除所有相关结论。需要分别判断：更正是否涉及该概括或关联所采用的内容，是否仍有其他支持，以及原有适用条件是否改变。共享某个事件块，不要求所有主题都作相同幅度的修订。

仅修改某个记忆团的解释，不要求无关记忆团或关联同步变化；某个依据不再成立，也不自动否定仍有其他依据支持的内容。依据关系应能够区分这些情况，具体记录形式留待研究。

### 4.3 理解变化与组织延续

新增事件可以改变概括，重新比较既有事件也可以改变概括。后者需要说明形成了什么新的比较或理解，而不能仅因生成了另一段文字就认定出现了新认识。

当前采用的理解及其形成依据应能被区分。先前基于什么记录形成概括、哪些记录后来被更正，会影响该概括现在是否仍适用；较晚写出的旧解释不能仅凭写入更晚就覆盖已依据更正形成的理解。这是修订的语义要求，不预设版本存储、并发控制或任务队列方案。

是否由管理 Agent、规则或其他方法完成整理，暂作为实现选择。本文先研究整理应产生什么变化、变化依据是什么，不预先确定执行者、调用模型或整理周期。

## 6. 六个问题的首轮设想

以下是可添加、改写或否定的研究候选，不是已经确定的算法。本轮查阅为问题导向的一手论文与项目官方文档核对，阅读范围见第 8 节；未进行实现、复现或模型实验。文献提供局部方法，本文的组合与取舍是据此提出的设想。

所有问题限定在记忆空间内部。不将 LLM 接入、召回效果或长期个体成长纳入本专题的完成条件，也不以结构更复杂直接认定研究取得进展。

### 6.1 什么样的主题相关性值得形成记忆团？

**设想 A：围绕一个可说明的关注范围成团，用相似性和显式联系寻找候选。** 一个候选主题应能说明它关注谁、什么事务或什么时间范围，以及准备概括哪方面的经历。候选主题可以从事件中提出，不要求所有主题预先列好；提出后需要明确含义，才能判断成员与概括是否合适。

| 线索 | 可以承担的作用 | 单独使用时需要辨认的边界 |
| --- | --- | --- |
| 语义相似 | 发现措辞、问题或情境相近的事件 | “同意”和“不同意”可能谈论同一件事；相似不说明状态相同，也不说明属于同一事务 |
| 共同人物 | 形成某个人的经历主题，或提供跨事务联系 | 同一个人在两个项目中活动，不代表两个项目的进展应混为一谈 |
| 时间关系 | 形成一周、一阶段等时间主题，或组织事务的先后变化 | 同时发生的不同事情可以共同出现在时间概览中，但不能因此被解释成同一过程或互为原因 |
| 事务关系 | 将同一事项的发起、尝试、转折和当前状态组织起来 | 同一事务可以包含多个子主题；是否需要进一步分团取决于概括需要 |

可先区分两个问题：一组事件能否按某个范围归组，以及它们是否已经支持有意义的主题概括。前者可以先成立；若目前只能重复标签或罗列成员，可以暂保留为候选分组，不必宣称已经形成理解。时间概览和人物经历本身都可以是合法主题，不要求每个团都具有共同因果链。

**替代设想 B：先采用允许重叠的语义聚合，再为结果形成主题与概括。** RAPTOR 使用软聚类，允许同一片段参与多个簇，并对聚合材料形成摘要；这提供了可借鉴的组织路径。[S1] 链路社群研究也表明，可以从关系的组织形成重叠归属，而不将节点强制分入互斥分区。[S2] 两者都没有证明聚合结果已满足本文的事件语义和概括要求。

本轮不选择 A 或 B 为唯一方式。值得比较的是：主题范围参与组织，是否比事后命名更能减少主题混杂；语义聚合又是否能发现显式人物、时间或事务规则遗漏的主题。不能为了偏向 A，给 B 更少材料或更弱的概括能力。

### 6.2 何时增员、分化、合并或修订概括？

**设想 A：根据主题范围与内容变化区分操作，不以事件数量或摘要相似度单独决定。**

| 候选操作 | 可以考虑的条件 | 暂不作为充分理由的情况 |
| --- | --- | --- |
| 增加成员 | 新事件在当前主题范围内，并补充了经历或依据 | 只是人物相同、时间接近或文本相似，但不符合该主题含义 |
| 分化主题 | 一个团包含可分别说明的子主题，单一概括反复混淆其不同过程或条件 | 成员变多、摘要变长；它们可能只需要更合适的概括 |
| 合并记忆团 | 两团主题范围相容，形成的理解基本重复，合并后能保留各自的时间、条件和依据 | 成员重叠很多；同一批成员也可能支持两个有意义的主题 |
| 修订概括 | 当前状态、阶段、适用条件或解释确有变化 | 仅增加一条重复支持材料，或者换了一种措辞 |
| 保持现状 | 新材料不改变该团的成员范围与理解 | 不要求每次整理都产生可见变化 |

这里的分化、合并作用于主题组织，不拆分或合并外部已提供的事件块，也不把多个不同发生的事件合成一个事实。父主题与子主题可以同时有意义；出现子主题不要求删除原来的宽范围概览。

**新增材料、新增理解和重复改写分别记录。** 增加依据而结论未变，属于材料更新；增加了有依据的阶段比较、条件限定或修正了原解释，才可称为内容上的理解变化；只换标题、顺序或近义表达，属于表述变化。这是可观察的内容区分，不据此证明系统具有某种内在理解能力。

All-Mem 提供 Split、Merge、Update 三种结构操作；Hindsight 则在相似候选上进一步核对完整内容，再决定合并还是保留区别。[S3][S4] 可借鉴操作分类与“相似候选不等于可以合并”的思路，但它们的单元、目标和阈值不直接等同于本文记忆团。本文不采用它们的固定操作顺序、置信门限或整理周期。

**替代设想 B：先保留稳定主题，每次更新时重新概括其完整成员。** 这一简单方案可以作为对照；只有在它确实混淆不同内容、丢失条件或产生过多重复时，才有依据讨论引入额外拆合。何时分化或合并通常没有唯一答案，需说明具体解决了什么组织问题。

### 6.3 什么样的中介支持事件关联？

**设想 A：先说明联系的含义，再检查两端与中介之间是否都有依据。** 可以先用文字表达“事件甲—共同人物／事务／其他事件—事件乙”，不要求立即建设统一知识图谱。

| 中介或联系 | 可以支持的关联 | 不能自动升级成的解释 |
| --- | --- | --- |
| 同一人物或对象 | 两段经历涉及同一对象；它们可以跨主题相连 | 两事件属于同一事务，或后一次行为由前一次导致 |
| 同一事务及其明确环节 | 两事件属于同一过程，或处在该过程不同阶段 | 已经确定了环节之间的唯一因果关系 |
| 相近时间 | 同一时段发生，可参与时间组织 | 同时发生即相互影响 |
| 相似情境或关系模式 | 可以提出一个跨事件类比候选 | 类比两端具有相同原因、结果或普遍规律 |

可辨认的关联应能说明“具体通过什么联系”；解释性类比还应保留其假说地位。材料不足时可以提出待核关联，不需要在“立即采信”和“禁止联想”之间二选一。仅说“二者似乎有关”，尚不足以说明关联含义。

**设想 B：考虑中介的区分能力。** 几乎所有事件都涉及的“我”“工作”等宽泛中介，可以支持很宽的共同归属，却不应单凭连接数量制造大量强关联。可将“所有共同中介同等计数”与“常见中介较弱、具体联系另行说明”比较。局部链路预测中的共同邻居与资源分配方法为这种比较提供参照；它们处理的是网络链路预测，不证明事件联系的语义或因果。[S6]

间接链路可以作为一条有中介的路径保留，不必立即新增两端之间的强直接边。例如甲与乙、乙与丙分别有联系，不代表甲与丙具有同一种联系。哪些路径值得固化为新关联、怎样避免组织被宽泛中介主导，仍是开放问题；不在此研究访问路径或联想展开范围。

### 6.4 关联强度或置信程度如何定义，是否需要概率？

**设想 A：暂不用统一数值，先分别表达联系的内容、强弱与依据把握。**

| 表达 | 回答的问题 | 示例 |
| --- | --- | --- |
| 联系类型 | 两个事件通过什么联系？ | 同一人物、同一事务、时间相近、情境类比 |
| 关联强度 | 按该联系的定义，两事件联系有多紧密？ | 属于同一事务的连续环节，与仅涉及同一人物可以不同 |
| 置信程度 | 对“存在所述联系”这一判断有多大依据？ | 共同人物由输入明确给出；共同动机只是推测 |
| 概括支持 | 哪些事件和条件支持某项总结？ | 这是记忆团的依据问题，不直接等同于边的强度 |

一个共同人物关联可以有充分依据，但对区分事务作用很弱；一个值得探究的深层类比也可能暂缺依据。不同关系类型的强度不必能直接比较，更不必先压成一个总分。

初期可以用带说明的定性判断，或干脆只记录关系及依据。新的独立材料可以增强某项判断，反例或外部更正可能降低它的把握；同一依据被转述、重组或多次引用，不自动增强置信。没有新材料也不意味着联系必然按时间衰减。

**替代设想 B：当任务确需区分程度时，再定义数值或概率。** 如果引入概率，应明确它估计的是“给定材料下，某种已定义联系成立的可能性”，并有适合该问题的独立标注与校准检查。相似度、聚类归属值和模型自报的数值，都不能仅因处于零到一之间就作为该概率。校准研究可以提供评估观念，但已有分类模型的校准方法没有替本文解决关联定义。[S8]

本轮不选定概率模型、不规定数值阈值，也不引入访问概率。可先比较：显式关系及依据是否已足以处理材料；定性强弱或置信是否增加可辨认的信息；只有后者仍不足时，再研究数值形式。

### 6.5 新事件与事实更正后，哪些内容变化？

**设想 A：从概括采用的内容及关联依据定位影响，再决定保留、限定或修订。** 不只问“哪个团包含这个事件”，还要问“该团的哪些理解实际依赖被改变的部分”。这是语义要求，初期用人工表也能研究，不规定主张必须拆成特定字段。

| 输入变化 | 可能需要变化的内容 | 原则上不随之自动改变的内容 |
| --- | --- | --- |
| 新事件属于原主题 | 成员；若补充了新阶段或条件，则更新相应概括 | 过去已发生事件的记录、无关主题 |
| 某项事实由外部更正 | 依赖被更正内容的概括、关联及相关支持判断 | 同一事件的其他未变内容、无关联系、仍有其他依据的认识 |
| 出现较晚的新状态 | 当前状态及阶段概括，必要时表达状态变化 | 先前状态在当时成立的历史 |
| 仅重新解释既有事件 | 相关主题概括、比较关系或关联假说 | 事件本身及独立于该解释的其他概括 |

需要区分事件发生时间、材料进入系统的时间与更正时间。较晚收到一条旧事件，不意味着它代表最新状态。记录某人报告“成功”的事件，也不能在另一条结果记录被更正时，自动改写成“他当时报告部分成功”。

来源、派生与修订的区分可参考 PROV-DM；Hindsight 的综合表达则提供了按相关材料变化更新并保留依据的参考。[S7][S5] 本文借鉴这些关系含义，不要求实现完整规范或复制其问答形式。

**替代设想 B：对受影响主题重新概括完整成员。** 局部修订与主题整体重写都允许保留依据、处理反例。值得比较的是二者的漏改、误改、条件保留和成本，而不是预设局部修订必然更好。局部修订若遗漏分散的依赖，整体重写可能更合适；整体重写若改变无关内容，则需辨认这种变化是否有理由。

### 6.6 如何比较组织方法？

**设想：先做固定事件块的小规模纸面比较，分别检查组织、关联与修订，不合成一个万能成绩。**

首先区分两个实验问题：给定一个明确主题说明时，成员和概括是否符合该说明；不预设主题时，方法能否提出有意义的组织。前者可以有部分明确预期，后者允许多个合理答案。不能只用预先指定主题的测试，就声称解决了主题发现。

可比较三种组织思路：

1. **显式关系组织：** 按事务、人物、时间等明确范围归组，允许重叠，并形成有依据的概括。
2. **语义聚合：** 从语义相近材料形成允许重叠的候选组，再确定主题及概括。
3. **混合组织：** 从语义或显式关系发现候选，再结合明确主题范围检查成员和理解。

三者使用相同事件、相同阶段顺序、可比的概括能力及整理预算；混合方法不额外获得人工答案。比较关联规则时先固定分组，比较修订方式时先固定初始组织，尽量避免把多种变化混在一起。

每种方法只需提供：主题及其范围、成员事件、概括及依据；事件关联的含义与中介；收到更新后改变了什么及理由。事件可以暂不成团或仅参与关联，不以强制全部成团计算覆盖成绩。

| 检查方面 | 可有限核对的内容 | 暂不能据此唯一判定的内容 |
| --- | --- | --- |
| 组织覆盖 | 指定主题下，明确相关事件是否遗漏、无关事件是否混入；事件是否仍有清楚身份与状态 | 唯一最佳主题清单、每个事件必须属于几个团 |
| 概括支持 | 事实内容、否定、时间和条件是否保留；是否把发言当作被证实的结果 | 唯一最佳叙事或所有解释的客观排序 |
| 关联依据 | 中介两端是否有材料，是否把连通性直接升级为因果 | 所有合理弱关联是否都必须保留、统一强度真值 |
| 修订结果 | 已明确依赖的旧主张是否残留，无关内容是否被误改，仍成立的依据是否保留 | 一切修订的唯一幅度、何时拆合的通用阈值 |
| 组织成本 | 整理次数、材料处理量、存储；实际调用模型时另记时间与费用 | 没有实测时推断哪种方法必然便宜 |

评价依据应在查看方法输出前说明。可区分“符合预期”“违反明确约束”“存在多个合理答案”，对争议解释保留理由；不把流畅度、团数量、边数量或文字变化量直接视为理解质量。

构造案例用于暴露局部缺陷，不能据此证明方法普遍优越。若进入真实方法实验，需要加入未用于设计规则的其他事件序列，并报告困难材料和判断分歧；本轮只建立比较入口，不建设测试平台。

## 7. 构造材料：检查六个问题怎样落到具体内容

以下完全为纸面构造，不是用户的经历，也没有运行组织算法。事件块已经由外部给定，本文不研究它们如何从上下文提取。

| ID | 给定事件块 |
| --- | --- |
| E01 | 3 月 1 日，林在项目 P 周会提出方案 X。 |
| E02 | 3 月 2 日，陈在项目 P 群聊说“方案 X 已通过评审”。 |
| E03 | 3 月 3 日，项目 P 评审会决定方案 X 未通过，理由为成本超预算。 |
| E04 | 3 月 5 日，林和陈在项目 P 完成方案 Y 第一轮试验，未达预定指标。 |
| E05 | 3 月 7 日，林在项目 Q 与赵讨论预算模板。 |
| E06 | 3 月 7 日，赵在项目 Q 提出在预算模板中增加汇率栏。 |
| E07 | 3 月 8 日，王在项目 P 会议宣布等待成本复核后再选方案。 |
| E08 | 3 月 9 日，项目 P 的方案 Y 第二轮试验全部指标达标。 |
| E09 | 3 月 10 日，陈在项目 P 群聊说“方案 Y 第二轮试验成功”。 |
| E10 | 3 月 11 日，林在项目 Q 再次提出在预算模板中增加汇率栏。 |
| E11 | 3 月 12 日，赵批准项目 Q 的预算模板增加汇率栏。 |

同一轮材料中的月份与年份背景一致；本例只比较给定时间的相对顺序，不补充未提供的其他经历。先提供 E01—E07，再提供 E08—E11。最后提供一条外部更正：E08 应为“一项指标达标、一项未达标”；更正的是结果记录，不是 E09 所记录的发言。

### 7.1 主题与关联的区分

可以提出“项目 P 的方案进展”“项目 Q 的预算模板变化”“林在三月的工作经历”等主题。它们不是唯一合法分组；一旦选定含义，就能逐项核对成员。例如，E05 可以进入林的工作经历，却不应仅凭林出现就进入项目 P 的方案进展。

E01 与 E05 经由林存在可辨认的联系，不因此属于同一事务。E03 的成本问题与 E05 的预算讨论也可以产生比较线索，但仅凭现有材料不能写成 Q 的预算讨论导致了 P 的评审结果。E06、E10 文字相近，仍是不同人物在不同时间作出的两次提议，不能作为重复记录合并。

### 7.2 概括与更正的区分

P 的主题概括可以保留“先出现通过的报告，后来有未通过的正式决定”，不能将报告直接替代决定，也不能仅凭后来的决定推断陈此前故意说谎。它们的内容及时间关系均需保留。

E08 更正后，“Y 第二轮全部达标”的概括需要修订；E09 的发言仍然发生过，不能替代被更正的试验结果，作为第二份独立核验继续支持全部达标。Q 的事务概括与 E08 无关，不应因此一起重写。P 的人物参与、方案 X 的提出等内容，若不依赖被更正部分，也仍然保留。

### 7.3 本例尚未回答的问题

两次提议是否值得另成一个“汇率栏提议历程”子团，或者只放在 Q 的主题中，没有本例给定的唯一答案。把同一事实改写得更顺畅，也不能证明产生了新理解。本例可以检查身份、范围、条件和更正影响，却没有证明某种自动聚合、间接关联或概率模型有效。
