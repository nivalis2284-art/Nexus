# 旧自主性系统归档

基线提交：`2d99159`。`source-2d99159.zip` 保存该提交完整受版本控制的源码、测试和文档；解压到单独目录即可查看原实现。归档不含本地凭据与未跟踪文件，不提供日常新旧切换入口。

新实现位于 `nexus/automation/`，不再加载旧自主性运行时。旧专属源码和验证脚本已从活动目录移除。原阶段需求及证据仍保留在已有文档目录。

使用新版本首次启动有旧自主数据的数据目录时，会先在该数据目录的 `archive/autonomy-original/` 保存数据库、会话及监听目录，暂停旧自主工作并清除其自动安排。旧历史不自动转换成新计划。新实现使用独立的 `automation.sqlite3`。

本次分两阶段：第一阶段开发和基本 bug 修复；所有者确认后，第二阶段再做正式验收、日常实例启用与收尾。源码快照不是验收通过记录。
