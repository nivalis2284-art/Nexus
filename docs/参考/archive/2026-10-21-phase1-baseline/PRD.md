# PRD｜LingNexus · 第一版自主性雏形

> **阶段：** 第一阶段 · 第二部分（自主性）
> **状态：** 所有者于 2026-10-21 正式确认开发范围，进入阶段 5；尚未通过阶段 6 独立验收。
> **性质：** 面向正式实现的产品需求契约。所有者最新明确指令覆盖本次流程：两轮 4A 后确认 A1，**跳过 4B，直接阶段 5 开发 → 阶段 6 独立验收**。不再设置计划审批关口。
> **依据：** [PRODUCT](PRODUCT.md)、[ROADMAP](ROADMAP.md)、[最高愿景](../../../愿景/01-概念与原则.md)及[抽象需求](../../../愿景/02-具象理想.md)；旧研究型 PRD 与两份研究见 [自主性预研归档](../2026-10-20-autonomy-prestudy/)。历史研究供参考，不得覆盖最新需求。

## 1. 需求

**2026-10-21 已确认的实施边界：** 采用唯一灵主 Agent、有界审议、持久关注与真实反馈的 A1，三源触发共存；独立 MCP 首批观察获准本地文本/Markdown，允许灵管理监听；Nexus 保留重要经历、目标、消息和所有者控制，不建设完整插件系统，Jev 非必要；服务运行时可自主活动，关闭网页不停止，消息持久补看，不增加站外推送。授权内自主读取、研究和保存成果可执行，外部写入/越权及新增付费实验另行授权，用户可配置 Token 消费额度，禁止无上限后台调用。开发采用独立测试资料；自动化通过不代替真实主 Agent、监听/工具与 UI 的成功、失败及反例验证。细化依据见[补充 PRD](PRD-AUTONOMY-SUPPLEMENT.md)与[增量研究](RESEARCH-AUTONOMY-SUPPLEMENT.md)。

**交付一个可实际使用、可独立验收的「灵的自主性雏形」，而不是仅产出报告或自动化演示。** 具备两项可分别验证、又能相互衔接的核心能力：

- **自主发起交流：** 当所有者较长时间没有主动联系灵时，灵能根据经历和当前情况，自行决定**是否、何时、为何值得主动向所有者发送消息**；没有合理理由时也能安静等待，不能把超时固定问候冒充自主判断。
- **自主形成与延续目标：** 没有新的明确用户任务时，灵能从真实经历、未解问题或获准的观察中产生**有根据、有意义的新候选目标**，自主选择开展、进一步调查、等待或放弃；实际结果能使灵修正认识，进而改变之后的选择与行为。

只有**一个灵的主 Agent**负责最终目标决策、主动回复及与你的交流；可以调用现有工具或辅助判断能力，但辅助模型不成为第二个对外交流主体。

## 2. 背景与目标

Nexus 已经具备交流、持久工作、任务控制、重要事件通知等工程基础，但已有活动大多由用户下达的目标或确定的任务事件引发。进一步增加定时提醒、自动排队或模型路由，不等于让灵拥有自主活动的起点。

前期研究已提出从经历形成开放问题、决定行动/等待/放弃、保存再考虑条件、将真实结果用于下一次判断等机制，但讨论一度过度侧重 Jev/Flash 分工与 API 成本。**本阶段首先追求用户实际体验和自主行为是否成立，随后才考虑成本优化。** 真实授权、可停止性与不伪造行为结果仍是底线。

本阶段只要求**最小但完整的自主行为闭环**，不试图一次完成完整长期人格、永久持续的内部思维或不受边界限制的通用自主智能体。

## 3. 我的原话摘要

以下忠实概括所有者历次明确表达的意思和纠偏，并非将 AI 的设计推论写成用户原话：

- 长期希望灵在安全边界内不再只等新命令，而能够自己形成想法、选择活动、积累经历；自主性与此前的持续性分开推进。
- 对此前研究的批评是：先后顺序和侧重点反了；应当先说明**自主性究竟是什么、工作原理、最终可见的体验及能做什么**，而不是优先比较价格、唤醒与多模型分工。
- 下一步不应跨得太大：先实现**长时间未主动联系时灵自主决定何时和为何联系**，并证明**无新任务时基于旧经历形成有意义的目标、决定开展或暂缓、让实际结果影响未来行为**。
- 与用户交流的灵只有一个主 Agent；Jev 可作为简单判断辅助，但不是已定架构。约 27B 的 Flash 原意是后台观察与自由联想，不是另一名对话或决策者；考虑到持续思考机制尚未解决，已明确暂缓。
- **先确保产品达到要求，再优化成本。** 这次 PRD 面向正式实现，不是继续把研究本身当成最终产物；希望 Astra 能自由探索可实现方案并清楚解释取舍，不由需求文档过度规定做法。
- 仍未明确指定：多久算长时间、具体判断/唤醒机制、页面关闭后的站外送达方式、每类自主行动可获哪些长期授权、最终技术选型与预算数值。

## 4. 对原话的理解

**已确认的理解**

- 灵只有一个主要对外交流与最终决策主体。辅助模型可以提供信号，既有工作 Agent 可以依授权执行，但不得各自独立代表灵与用户主动交流。
- **主动联系和自主探索不是同一件事。** 发现新问题可以先调查或等待而不打扰用户；主动沟通未必伴随一次工作任务。合理沉默是合法结果。
- 新目标需要可追溯的真实经历或问题背景，不要求所有者逐项交代，也不限制为某一种预写待办或编程任务。
- 本阶段评判**行为效果、可靠性与用户体验**，不以 Token 节省比例或多模型架构是否接入作为成功标准；Flash 常驻思维不在本版范围内。

**AI 的暂定理解（阶段 4A 可复核）**

- “长时间没联系”是允许系统主动考虑是否交流的情境，**不是自动发消息的充分理由**。
- 第一版可先利用现有灵交流入口产生、保存和呈现自主消息；是否必须在页面关闭时仍通过系统推送送达，属于尚未决定的产品扩展，不擅自加入短信、邮件等站外通信。
- 自主性必须有跨次运行的真实记录与反馈，而不是单次提示词生成“我发现了问题—我完成了任务”的故事。

**仍需确认的差异**

- 自主交流的时机与打扰边界、最低送达体验、哪些环境信息可以观察、哪些活动可在无需即时询问的情况下执行。阶段 4A 应对真正影响第一版效果的产品取舍提出可选项；非关键实现细节由 Coding Agent 自主决定。

## 5. 功能范围

**本阶段最终必须交付**

1. **有理由地自主联系。** 无新的用户消息时，灵能根据实际经历及当前条件决定是否主动交流；有价值时通过获准的灵交流渠道发出与事实相关的消息；无理由时保持安静。消息可被用户实际看到、追溯，不能以一次定时生成文本冒充已经发送。
2. **自主形成候选目标。** 依据之前的交流、获准观察或自己未解决的问题，在没有新任务指令时产生至少一种真正由灵提出的目标，说明来源与提出理由；区分可靠事实、外部说法和猜想。
3. **自主选择与必要行动。** 能在开展/调查、等待、放弃之间取舍；适合行动的目标可在已有授权范围内取得实际可核查的进展；等待和放弃保留理由及重新考虑条件，不制造重复无意义工作。
4. **反馈改变后续行为。** 当调查失败、证据冲突、新结果出现、目标完成或被所有者撤回时，灵后续的选择能相应改变；跨消息及必要中断后，仍能识别同一问题和真实已完成的事情。
5. **稳定交互与所有者干预。** 唯一主 Agent 与现有聊天、持久工作体验保持协调；所有者可以了解重要自主活动的依据，暂停、终止或调整自主部分。暂停后不能由普通新事件偷偷恢复；不能重复对外执行已生效的动作。

**本阶段明确不做**

- 不将完整人格进化、完整长期记忆平台、真正机器意识、永不停歇的模型推理、常驻 Flash“潜意识”或无限开放世界探索作为第一版的前提。
- 不预设必须使用 Jev 或任何特定模型、框架、调度算法、模块划分或多级 Agent；只有一个主 Agent 代表灵对外对话与做最终决定。
- 不把按时寒暄、模板提醒、自动搬运用户已有待办，或只写一份计划但没有实际经历反馈当成自主性完成。
- 不擅自增加站外推送、邮件、短信、不可逆外部操作或超出当前授权的能力；确为第一版体验所必需的新增边界，应在 4A 明确呈报取舍。
- 本阶段不以节省 API 费用取代体验达标；也不批准无约束、无限额的后台付费模型实验。

**面向正式实现的 4A 准备要求（不等于本阶段最终产品交付）**

Coding Agent 应阅读本 PRD、实际源码、历史预研，产出 `docs/RESEARCH.md`：复核产品理解和可复用能力，**至少提供一个具体且可实施的完整方案候选**，说明原理、最后呈现的用户体验、可能的交付边界、关键难点与风险、怎样验证；若有其他有竞争力的方向，比较优缺点和取舍；如果只剩一个可行选项，也要说明其他方向为何不适用。需给出推荐及理由、仍需用户决定的问题，足以支撑阶段 4B 规划；不强制凑方案数量或提前把架构写进 PRD。

## 6. 验收标准

- [ ] **主动联系正例：** 在有真实相关经历、确有值得交流的理由且用户没有新指令的可控场景中，灵能自行发出与依据一致、时机合理的消息；用户能在实际产品界面查看及追溯，不必先发起对话。
- [ ] **主动联系反例：** 长时间无联系，但没有值得表达的内容，或事项已经过时/处理完毕时，灵能合理保持安静，不机械寒暄或重复打扰。
- [ ] **目标形成：** 没有新的明确任务时，灵能从真实历史经历或观察中提出有根据的**非预先写死、非用户逐项指定**候选目标，并保留来源。
- [ ] **完整行为闭环：** 至少存在一条能核验的“产生目标 → 自行取舍 → 调查/行动或等待 → 新结果/条件变化 → 后续选择改变”的真实过程，而不只是模型叙述。
- [ ] **异常与修订：** 证据不足、调查无进展、失败、冲突、撤回时，灵能等待、放弃或修订目标，不重复捏造成功或无限循环。
- [ ] **跨时间与干预：** 经适当时间推移、界面重开或受控中断恢复后，关键目标、来源与状态仍可找到；暂停/终止保持有效，不越权且不重复外部副作用。
- [ ] **用户真实验收：** 需使用实际灵主 Agent、实际交互与可检查的结果完成正反例；允许模拟时间加速，但不能靠硬编码示例、纯定时器、假模型脚本或只读研究报告宣称功能达标。

**本 PRD 约束未来产品的最终体验与验收结果；4A 完成只意味着研究和路线准备就绪，不等于自主性功能已完成。**
