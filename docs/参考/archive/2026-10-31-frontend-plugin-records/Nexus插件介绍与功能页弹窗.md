# 插件介绍与功能页弹窗

实施日期：2026-10-30。

插件管理在加载／停用、卸载旁提供“查看介绍”，无需加载插件即可读取根目录 `README.md`。介绍与功能页分别使用网页内大弹窗，管理页保留选中项与滚动位置。HTML iframe 和宿主统一渲染页面继续使用现有协议。

只读接口为 `GET /api/plugins/{plugin_id}/readme`，返回 `{content: Markdown字符串或null}`。缺失、空白文档返回 `null`；未知插件、非法编码、读取失败及越过插件目录边界沿用管理接口错误响应。UTF-8 BOM 可正常读取。

介绍正文复用 Markdown 渲染与内容清理，相对链接及图片按插件目录解析，不使用主交流的工作区文件预览入口。读取失败可以重新读取，关闭后取消等待并忽略迟到响应。

关闭功能页会销毁页面、未保存输入和页面内部弹窗，取消前端等待；再次打开重新初始化。管理列表刷新不重新挂载功能页，插件停用或卸载时清理对应页面。关闭页面不撤销插件已经提交的后台操作。

新开发规范和统一打包器要求非空 UTF-8 `README.md`，说明用途、用法、配置和实际限制。宿主仍接受缺少 README 的旧包。旧 `mobile-bridge/` 验证插件没有因本次功能而修改或重新打包。

验证结果：

- README HTTP 与打包定向检查：7 项通过，覆盖未加载读取、缺失、读取失败、非法编码、目录边界、共享 SDK 打包和缺失／空白介绍拒绝。
- 现有前端行为检查：13 项通过。
- 隔离 Edge 浏览器检查通过，使用实际网页文件与测试 HTTP 数据，覆盖 Markdown、相对资源、错误重试、迟到响应、两类功能页刷新保留与重新初始化、停用清理、Esc／遮罩关闭和焦点恢复。
- 已检查 1440×1000 桌面及 390×844 窄屏截图，截图保存在本地 `.artifacts/plugin-dialogs/`。
- 界面扫描报告了原有全局界面的对比度、装饰及动效问题，本次未扩大到全局视觉调整。

没有启动日常 Nexus 实例，没有安装或加载用户插件，没有运行全量回归或真实外部服务验收。
