# 最简自主雏形 · 交付记录

> 本文记录迁移至独立 MCP 调度服务之前的阶段。后续架构、验证和启动方式以 [MCP 重构记录](MCP-PHASE1.md) 与根目录 README 为准；下文保留当时的实现与验收事实。当前阶段状态见[路线图](../../其他/ROADMAP.md)。

当前范围：归档旧自主性，交付普通定时任务、间隔唤醒、每日规划、公开网页变化唤醒及回复/一句话静默；复用主会话工具、Skill、MCP 和持久工作。

定时支持一次性、间隔、每日、每周。用户与灵均可管理全部安排和网页监听。网站使用 Playwright 和本机 Edge 读取渲染正文，首次建立基线，后续文本变化再唤醒。无需新增监听 MCP 服务。活动记录可查看静默句与错误；正式回复进入主会话并显示页内未读提示。

新数据首次初始化自动活动关闭；60 分钟间隔、每日 09:00 规划随后 24 小时、5 分钟网页检查均已预填，独立可调。交付实例按已确认默认值启用。本机时区生效；网页关闭不停止服务端。关闭自动活动不停止独立工作。

必要状态保存在独立 `automation.sqlite3`；旧代码恢复入口见 `archive/2026-10-21-autonomy-original/README.md`。不迁移旧目标/计划，不保留旧预算和专用授权机制。

真实模型验收使用隔离数据与已配置 DeepSeek 模型，覆盖明确提醒、规划时合理不新增安排、灵自行安排并实际执行、网页无变化不唤醒、重启保留基线、正文变化后唤醒、工具与静默。验收中没有把“规划必须创建新安排”当作硬性要求；灵可以合理地保持空计划。

第一阶段基本检查：新增闭环检查 4 项通过（实际 Agent 循环＋本地脚本模型，覆盖回复、静默上下文、网页变化合并与用户输入等待）；普通任务相关基本回归由子代理完成 20 项通过。Python 编译及致命错误/未使用导入检查、前端脚本语法检查通过。独立临时数据目录启动、关闭状态默认值、管理接口保存定时安排和前端静态资源读取通过；未发起真实模型请求，未启用日常实例，网页浏览器读取尚未实际验收。

第二阶段验收：真实 Edge 实际页面通过（含 JavaScript 正文、导航移除）；本机系统临时目录对 Playwright 返回 EPERM，网页读取改为在 Nexus 数据目录内使用每次运行独立临时目录，连续重启浏览器验证通过。页面真实 Edge 创建安排和监听通过，无脚本错误。全量 Python 回归 471 passed、1 skipped。发现并修正浏览器配置残留、页面测试改正文未生效、静默摘要误算未读提示等验收问题。

交付状态：日常数据目录 `.nexus-data` 已启用间隔 60 分钟、每日 09:00 规划和 5 分钟网页检查；未创建测试监听或测试提醒，日常灵历史未写入验收消息。服务端保持运行，地址以启动终端为准。
