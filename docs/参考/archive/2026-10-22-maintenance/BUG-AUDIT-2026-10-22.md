# 全项目功能 Bug 审查 · 2026-10-22

本轮在已有持续性和界面改动之上审查。重点是影响正常使用、能够从源码或模拟调用确认的问题；没有把长期愿景扩大成新功能清单。四个 DeepSeek high 子代理分别处理任务与持续性、MCP 与调度、前端交互、文件工具与启动配置，主代理检查模型与会话链路并整合。

## 已修复的功能问题

| 问题 | 影响与修复 |
| --- | --- |
| 取消任务被收尾流程覆盖 | 取消一个尚未退出的任务线程时，清理流程仍尝试把任务改为挂起。现在只对仍处于执行、暂停途中或排队状态的任务补写挂起，保留取消结果。 |
| 大文件后半部分无法按行读取 | 读取工具先截取文件开头，再解释行号，后面的行永远不可达。现在先定位请求的行，再限制返回内容大小；继续保留完整文件的哈希。 |
| 子代理最终报告混入暂定判断 | 工具调用之前的文字与最终答复被拼接返回，可能向父代理提供互相矛盾的结论。现在工具调用时清掉中间文字，最终报告与工具记录分别保留。 |
| 切换页面后阅读位置错误 | 隐藏的聊天容器位置覆盖了先前保存的位置；通知较慢时还会在用户滚动后再次跳回。现在忽略隐藏容器的无效位置，保存是否位于底部，并在加载通知之前恢复会话位置。会话和任务入口负责显示各自的阅读区。 |

## 删除的冗余与测试修正

- 删除 Agent 工具调用中从未使用的 `yield_event` 参数及网页中只返回 `session.items` 的透传函数。
- 删除没有生产调用的重复 `Retry-After` 解析函数及重试策略展示函数。已有解析测试改为检查模型网关实际使用的解析器。
- 删除 MCP 中没有实际调用的旧配置检查器、工具名称反向拆分及注册表摘要函数。配置校验继续使用已有的 `ServerConfig.from_dict`，不保留两套规则。
- 修正 HTTP 集成测试的启动数据：使用隔离的状态并初始化空 MCP 注册表，避免依赖其他测试残留的数据。
- 旧的重复工具失败测试改为模拟模型主动调用 `task_pause`，验证错误记录和挂起理由能保存；没有恢复连续失败计数或强制停止规则。
