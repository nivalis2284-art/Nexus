### `63d91cc` 测试 fixture 钉协议

**目的**：默认 profile 换成 Anthropic 后，假造 Chat 帧的测试失效。
**改了什么**：fixture 里显式指定 `api_family=OPENAI_CHAT_COMPLETIONS`。
**问题**：测试依赖了默认配置，配置一改就红。
**修复**：测试不再依赖默认值，改为显式声明。

### `1f7c70d` 多提供商、五档思考强度、新界面

**目的**：能配置多个模型；思考强度可调；界面像样。
**改了什么**：Provider/Model 分层配置、`effort.py` 五档映射、两层折叠界面。
**问题**：四个协议兼容性坑——流式 tool_calls 不带 `type`；Responses 最终事件换了 item id；带 reasoning 时首帧 id 为空串；finish 帧把 reasoning_content 发成空串。
**修复**：全部放宽解析并加回归测试，都是对着真实接口跑出来的。

### `0c2c941` 思考与工具的两层折叠

**目的**：一整个阶段的思考和工具调用收进一个可折叠块。
**改了什么**：外层「思考完成（已思考 N 秒）」，内层每步一行摘要。
**问题**：一条消息同时带思考和正文时，正文被吞掉——最终答案整段消失。
**修复**：分组逻辑区分「只有思考」和「思考+正文」，后者正文继续渲染。

### `6e6ed92` 四个新工具、清单驱动装配、重试、中止

**目的**：补齐工具；机制加固。
**改了什么**：`todo_write`/`ask_user`/`webfetch`/`websearch`；`ToolSpec.requires` 条件注册；指数退避重试；`/api/chat/abort`；权限规则可配置。
**问题**：解析 `reasoning_effort` 时把 `"off"` 当字符串发出去，被网关拒绝。
**修复**：`normalize()` 统一把 off/空/default 归一成 None，不发字段。

### `0a132a1` 压缩、子代理、Skill、MCP、后台任务

**目的**：补齐通用 Agent 的基础设施。
**改了什么**：两级压缩（裁剪→摘要）；子代理带深度限制；`SKILL.md` 发现；手写 MCP stdio 客户端；后台任务四个工具。
**问题**：单条超长消息无法压缩——它占满保留尾部，导致没有内容可折叠。
**修复**：保留尾部只剩最后一条时，改为只保留最新消息、其余进入摘要。

### `8cf0821` 人工确认不再占住运行锁；真实 MCP 验证

**目的**：修上一个提交遗留的锁问题；用真实服务器验证 MCP。
**改了什么**：`Approvals.cancel_all()` 唤醒等待者；token 区分审批/提问形状；`resolve_command()` 处理 Windows `.cmd`。
**问题**：客户端在提问期间断开，等待不会被唤醒，锁被占满整个超时；`npx` 在 Windows 无法直接执行，报错误导为"文件不存在"。
**修复**：中止/断开/`finally` 三处都调 `cancel_all`；命令解析优先走 `node + npx-cli.js`，否则经 `cmd.exe`。实测断开后 1 秒恢复。

### `bb87146` 用量面板、图片、patch、多轮提问、重命名

**目的**：补齐用量可见性与几个实用工具。
**改了什么**：`_usage` 保留缓存字段；上下文按系统/工具/对话拆分；三协议图片支持；`apply_patch`；`ask_user` 支持一次多问；会话重命名；`emit` 加写锁。
**问题**：**`open_file(path,"write")` 不截断**，写短内容残留旧尾部，`write_file` 和 `edit_file` 都会静默损坏文件。
**修复**：`ftruncate` + `lseek` 后再写，加 7 项回归测试。这个 bug 是在接第二个写文件的工具时才暴露的。
